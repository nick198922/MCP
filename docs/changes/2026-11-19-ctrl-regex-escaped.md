# 2026-11-19 · Регулярний вираз `_CTRL` без невидимих символів (пункт 407)

Пункт 407 [постійної картки](../ideas/IDEA-20261102-standing-improvements.md), знахідки 5–6 [рев'ю DefiLlama-пулів](../reviews/2026-11-19-defillama-pools-review.md).

- **Один спільний `CTRL_RE`** у новому `src/tradedesk/analytics/_text.py`. `analytics/yields.py` і `analytics/pendle.py` тепер беруть його звідти (`from ._text import CTRL_RE as _CTRL`). Раніше в обох файлах був свій вираз, і в ньому стояли буквальні zero-width / bidi-символи (U+200B…U+200F, U+202A…U+202E, U+2060…U+2064, U+FEFF), яких у diff не видно.
- **Символи записано іменованими escape-послідовностями** (`\N{ZERO WIDTH SPACE}`, `\N{RIGHT-TO-LEFT OVERRIDE}` тощо). Форма «backslash-u + код» не підійшла: інструмент запису файлів агента сам перетворює її на буквальний символ, і новий охоронець це одразу впіймав. Набір символів, які вираз прибирає, не змінився: тест перебирає всі символи до U+FFFF і порівнює їх зі старим набором.
- **Хибний коментар прибрано.** У `yields.py` коментар стверджував «escaped so a diff shows them», хоча символи були буквальні. Новий коментар у `_text.py` перелічує діапазони кодами.
- **Docstring `providers/defillama.py` вже правильний.** Речення «Field names checked live on 2026-11-19; the documentation … was not fetched» з'явилося ще під час повторного рев'ю (п. 5 закрито), тож тут нічого не змінено.
- **Новий тест `tests/test_no_invisible_chars.py`:**
  - очищення рядка з ZWSP, RLO, BOM, word joiner, LRM, `\x00`, `\x9f` в обох модулях; кириличний та ASCII-текст лишається без змін;
  - охоронець: у `src/**/*.py` немає символів категорії Cf чи bidi-керування, список винятків порожній;
  - самоперевірка сканера на штучному рядку.
- **Охоронець справді падає.** Додав тимчасово ZWSP і RLO в `_text.py`, і тест упав на обох (`analytics/_text.py:1 U+200B`, `U+202E`). Після цього файл повернуто, тест знову зелений.
- У `tests/` буквальні невидимі символи ще є (13 файлів, здебільшого тестові дані санітайзерів). Охоронець їх не перевіряє, бо пункт стосується лише `src/`.
