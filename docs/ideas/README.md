# Ідеї стратегій

Картки ідей, які пише скаут і проходять конвеєр із `docs/AGENTS.md`. Шаблон — `TEMPLATE.md`, файл картки — `IDEA-РРРРММДД-slug.md`.

Статуси: `proposed` (запропоновано) → `accepted` / `rejected` (тріаж критика) → `testing` → `confirmed` / `rejected` / `inconclusive` (бектест кванта і рев'ю критика) → `built` (є інструмент у MCP).

Уже перевірене до появи агентів (звіти в `docs/verification/`): SFP і рейнджі з лекцій — ✗; cash-and-carry на мейджорах — дрібний плюс; carry на альтах — ~3–5 % на капітал; перп-перп carry — сильний, але хвостовий; VRP на BTC — розрив IV−RV на DVOL ✓, але на реальних марках `inconclusive` (прибутку не видно).
