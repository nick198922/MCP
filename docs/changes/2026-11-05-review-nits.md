# 2026-11-05 — зауваження «не блокує» з рев'ю 02–05.11 (пункт 9)

Пункт 9 [постійної картки](../ideas/IDEA-20261102-standing-improvements.md). Переглянуто `docs/reviews/2026-11-0[2-5]-*.md` за «не блокує / пізніше / nit / дрібниц». Кожне зауваження звірено з кодом. Те, що вже закрили кола [0405](2026-11-05-review-nits-0405.md), [друге](2026-11-05-deferred-review-nits-2.md), [третє](2026-11-05-review-nits-0505.md) і [0511](2026-11-05-review-nits-0511.md), не повторював. Реєстрації, пороги, колектори, заморожені форварди й `execution/` не змінено.

- **Здоров'я колекторів: «60 хв» замість «1 год»** ([рев'ю](../reviews/2026-11-05-report-inputs-tests.md), п. 3). `collector_health.fmt_dur` для 3570–3599 с округлював хвилини до 60 і друкував «60 хв». Тепер, якщо хвилин після округлення 60, тривалість іде в гілку годин («1 год»). Інші значення не змінились. Тест `test_fmt_dur`: 59 хв 29 с → «59 хв», 59 хв 30 с і 3599 с → «1 год».
- **Рядки стійкості вердикту Polymarket звіряються повністю** ([рев'ю](../reviews/2026-11-05-report-inputs-tests.md), п. 2). У `test_render_robustness_lines_labels_and_numbers` рядки 2–9 перевірялись лише через `startswith`, тож зміна хвоста (CLV / P&L блоку) лишалась непоміченою. Тепер кожен рядок звіряється цілком, а три блоки мають P&L, відмінний від CLV, тому переставлений чи загублений хвіст валить тест. Код `pm_gap_report` не змінено.
- **Сховище переживає `Runtime.aclose()`** ([рев'ю](../reviews/2026-11-05-provider-lifecycle-guard.md), п. 6). `test_store_survives_runtime_aclose` проганяє одну БД через три сесії: `store.init()` (як у `server.lifespan`), запис funding, `rt.aclose()`. Після закриття старе з'єднання справді закрите, а сховище без `init()` відмовляє явно (`RuntimeError`). Наступна сесія пише знову й бачить рядки попередніх. Так колектор після перепідключення MCP не втратить записи мовчки. Код `src/` не змінено.
- Решту відкритих зауважень (панель «Демо», текст про `n_expiries` на панелі, докстрінг `classify_expiry`, дубль `sign_before`, дрібниці тексту звітів і бази знань) записано одним рядком у BACKLOG 6.22.
