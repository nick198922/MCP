  - П'ять копій: `adx_di_cross.dmi`, `holy_grail_pullback.dmi`, `stochastic_pop.dmi`, `hlhb_rsi_ema_adx.adx_wilder` (однаковий код, далі «`dmi`») і `freqtrade_adx_sma_cross.adx_wilder`. Вони розходяться лише тоді, коли сегмент починається з k нульових TR (high = low = попереднє закриття). Бар із сумою TR = 0 `dmi` пропускає, а `freqtrade` рахує йому DX = 0.
  - Уточнення до запису 6.9: розбіжність є вже від k = n, а не від 2n − 1. Коли n ≤ k ≤ 2n − 2, перший ADX у `dmi` — середнє лише визначених DX, у `freqtrade` — їхня сума / n. Приклад: n = 3, k = 3, далі рівний тренд: `dmi` дає 100, `freqtrade` 66,67, потім обидва сходяться до 100. Коли k ≥ 2n − 1, `dmi` дає `NaN` до кінця сегмента (сигналів на ньому немає), а `freqtrade` дає числа (n = 3, k = 5: 0; 33,3; 55,6 …)
  - Яка копія права: TA-Lib (`src/ta_func/ta_ADX.c`, рядки 378–391 у `main` на 07.11): бар із TR = 0 додає до суми 0, перший ADX = сума DX / n, тобто так само, як `freqtrade`. Розбіжність усіх п'яти копій із TA-Lib, яка лишається: коли +DI + −DI = 0, TA-Lib тримає ADX, а наші копії згладжують із DX = 0. Тут копії між собою збігаються.
