# Звіт контрольної точки: власні журнали карток `forward` і список «форвард без збору» (пункт 312)

Джерело: тижневий аудит 10.11, [`BACKLOG`](../BACKLOG.md) «З тижневого аудиту 2026-11-10», пункт про `checkpoint_report.py`. Картка: [IDEA-20261102-standing-improvements](../ideas/IDEA-20261102-standing-improvements.md), пункт 312.

- Було: для карток зі статусом `forward` звіт рахував лише плани з тегом `idea:`. У всіх 24 карток їх 0, тож звіт не показував, чи форвард узагалі щось збирає.
- Стало: новий рядок «Картки forward: власні журнали» (`scripts/checkpoint_report.py`, `CARD_JOURNALS`, `load_journals`, `journal_row`, `build_report`). Для 8 карток, чий журнал — таблиця колектора, яку картка сама називає, виводяться лише лічильники: спостережень на дату звіту, перше й останнє, мінімум для вердикту і дата вердикту так, як їх пише картка. Дати рахуються від першого спостереження або від зареєстрованого T0. Ось ці картки й таблиці:
  - `option_xvenue_snapshot`: годинні знімки BTC;
  - `coingecko_trending`;
  - `hl_oi_cap_snapshot`;
  - `trader_positions` HL для `hl-whale-liquidation-magnet`;
  - `pm_gap_snapshot` для трьох карток: v1 від T0, v2-g від T0 v2-g і `static-noarb-ladders`;
  - `cp_cycle` для carry.

  Ціни, події й результати не читаються. Події з журналу, як і раніше, визначає крок аналітика картки.
- «Форвард без збору (N)» — картки, у яких немає ані журналу колектора, ані жодного плану `idea:`. Сюди ж потрапляє картка, чий журнал порожній, відсутній у БД або мовчить понад 2 доби. Якщо в картки є план `idea:`, вона вважається такою, що збирає дані. Збій запиту однієї картки названо в її рядку («запит до …»), і решту карток він не ховає.
- БД відкривається лише на читання (`mode=ro`). Мережі немає, `execution/` не змінено. В `analytics/checkpoint.py` змінено одне речення примітки рядка планів: раніше там було написано, що журнали «звіт не рахує».

Скрипт на фікстурі: рахуються лише годинні знімки BTC до моменту звіту, ціни не потрапляють у текст, БД не змінюється. Ще один тест перевіряє, що кожен ключ `CARD_JOURNALS` — картка з `docs/ideas/`.
