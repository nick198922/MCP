## Зауваження

1. **[блокує] Провал (в) для carry A переказано як «описово, папір іде далі», а за реєстрацією це «не узгоджено».** У реєстрації ([IDEA-20261017-forward-paper-carry](../ideas/IDEA-20261017-forward-paper-carry.md), рядок «Підсумок») сказано: «„узгоджено“ = усі перевірні критерії пройдено». Звільнення «провал (в) читається як нестаціонарність» записано лише для B (розділ «Як читати (в) для B»), а для A його немає: там очікуване покриття 90 % і хибний провал ≈ 7 % при n 10. Колонка «ні → що робимо» для A перетворює зареєстрований критерій на описовий, тобто змінює правило до даних без позначки. **Що виправити:** для A — «(в) не пройдено → позначка „ні“ (не узгоджено). Дія: розбір funding-даних і рушія; не „вбити“, бо „вбити“ — лише (б) / (г) за розділом „Критерій «вбити»“». Для B лишити як є.

2. **[блокує] Критерій (г) переказано неточно, і `checkpoint_report.py` може реалізувати його неправильно.** Зараз у тексті «0 ліквідацій / ходів ≥ 0.50 між циклами». За реєстрацією для A подія — це хід перпа проти шорта **з < 0.25 до ≥ 0.50 між двома сусідніми 8h-циклами**.
