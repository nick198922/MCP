# Тріаж огляду «On-chain сигнали» (defi.md, скаут 19.11)

Вердикт: **changes** (огляд придатний, але кандидати A і B мали завищену потужність / оптимізм; B знімаю, A лише з переробкою, C приймаю як forward-правило).

## Take / drop по кандидатах

| Кандидат | Вердикт | Причина |
|---|---|---|
| A. Стиск пропозиції стейблів | **take з переробкою** (довга ставка, єдина з карток) | Механізм слабкий («випуск ≠ біржовий баланс»), але режим-гіпотеза тестується: історія `stablecoincharts/all` є в провайдері, дублікатів у `docs/verification/` нема (найближче: USDe → funding ✗ r −0.114, M2 → BTC ✗). Потужність скаута завищена: 20–25 «епізодів» — це перекриті 30-д вікна; стиски кластеризуються у 3 режими, незалежних ≈ 6–10, MDE напряму ≈ 13–17 п. п. проти очікуваних 3–5: напрям не вирішуваний. Приймати лише якщо основна мета — майбутня реалізована воля, з обов'язковим контролем trailing-дохідності й trailing-воли BTC (стиск настає після падіння, інакше результат кругової). Lookahead: точка d−1, поточний вінтаж DefiLlama (історію могли переписати, коли додавали монети) — застерегти у реєстрації. Побічно: зараз −5.4 % за 30 д, тож стан «стиск» активний, форвард-запис можна вести вже. |
| B. Нагороди пулів → шорт токена | **drop** | MDE ≈ 5.6–6.3 п. п. проти очікуваних 3 → inconclusive за конструкцією; найближчий аналог (анлок, 534 події) дав +1.8 п. п., t 1.68 ✗, а емісія за графіком ще сильніше «в ціні»; survivorship: `yield_pool_history` лише живих пулів, зсув неміряний; `first_date` — дата пулу, не початок нагород. Форвард не годиться: тригерів на рік одиниці. |
| C. Стрес стейблів | **forward** (правило ризику) | Подій одиниці, бектест неможливий; ціна — нуль. Знахідка: агрегована ціна DefiLlama не побачила б жовтневого USDe (депег на одній біржі), тож для USDe потрібен окремий тригер. Для картки forward: тригер (`price` < 0.995 або `change_1d` ≤ −3 %), план (плече / розмір вниз на добу), запис (дата, ціна, наслідок для BTC), n — до першої реальної події, kill — два хибні спрацювання без руху. Тег `idea:<slug>` даватиме координатор. |

Таблиця drop (нетфлоу бірж, кити, комісії / мемпул BTC, hash ribbon, TVL ланцюга) — згоден. Додатково: «дохідність стейб-пулів як ставка кешу» — take як контекст, без картки.

## Правки, які я зробив у defi.md і README.md

1. A: додано критичну оцінку незалежних епізодів (6–10, MDE ≈ 13–17 п. п.) і обов'язковий контроль trailing-дохідності / воли.
2. C: додано застереження про USDe і агреговану ціну.
3. Рядок «стейб-пули як ставка кешу»: уточнено, що carry +0.3 % у другій половині вікна.
4. Таблиця B: позначка скаута «take» замінена на «drop» з причиною; у рядку README B перенесено до drop.
