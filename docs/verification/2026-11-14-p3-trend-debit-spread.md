# P3: 200-денний тренд → вертикальний дебетовий спред (BTC, 2021–2026) — ✗ NOT CONFIRMED

Дата: 2026-11-14 · картка: [IDEA-20261114-options-playbook](../ideas/IDEA-20261114-options-playbook.md), пункт 4, розділ 4.1 · правило: [P3 у плейбуці](../knowledge/options-playbook.md#p3-200-денний-тренд--вертикальний-дебетовий-спред)

## Коротко

Правило P3 так, як його надсилає генератор (`option_ideas.trend` на SMA200 з нахилом за 20 д → bull call / bear put spread, куплена |Δ| 0.40, продана 0.15, експірація ≈ 13 д), на історії BTC після витрат **втрачає**: середній R = **−0.183** (R = P&L / дебет, тобто дохідність **на капітал**), 95 % CI [−0.415; −0.007] по кластерах-епізодах, n = 197 угод / 16 трендових епізодів, 2021-01-02 … 2026-10-03. IS −0.195, OOS −0.173; стрес половини спреду 3 в.п. −0.252. На номінал: −0.53 % спота на угоду. Повна втрата дебету в 66 % угод, R > 0 у 25 %.

За зареєстрованим правилом вердикт **✗ NOT CONFIRMED**: правило так, як його торгують (з витратами Bybit), перевірено, переваги нема. До витрат (чисті марки) результат **◯**: −0.098, CI містить 0, а верхня межа з поправкою на малу кількість кластерів +0.148 (+0.196 без 2021), тобто перевагу механізму «тренд → напрям» до витрат не доведено й не виключено (див. «Чесна примітка»). Статус P3 у плейбуці й у `RULES` змінено з «не перевірено» на ✗; генератор більше не надсилає P3 як угоду.

## Метод (реєстрація — у картці, розділ 4.1, коміт `4d839099`, до будь-якого P&L)

Реєстрацію після коміту не змінено. Прогін `--stage full` зроблено окремим кроком після коміту реєстрації й стадії 0 (покриття).

- **Вибірка:** BTC, входи щосуботи 09:00 UTC, 2021-01-02 … 2026-10-03 (301 субота: bull 152, bear 86, neutral 63). ETH не покрито: кеш поверхонь `put_skew/snapshots_v2.json` має лише BTC.
- **Тренд:** `option_ideas.trend(closes, sma=200, slope_days=20)` на денних закриттях Binance BTC/USDT до п'ятниці включно (закриття п'ятниці відоме о 09:00 суботи); «neutral» → угоди нема.
- **Конструкція:** `choose_expiry(snap, 14, 7, 24, "nearest")` (медіана DTE 12.96 д); страйки за дельтою з посмішки дня, кожна нога — найближчий страйк зі свіжою маркою в межах ±1.5 % спота від цілі; 1 BTC на ногу.
- **Ціни й витрати:** марки Deribit (поверхня 09:00), куплена нога за mark IV + 1.5 в.п., продана за mark IV − 1.5 в.п. (припущення половини спреду Bybit; Black-76, r = 0, форвард поверхні); комісії Bybit (тейкер 0.03 % спота ≤ 7 % ціни опціону на ногу; поставка 0.015 % ≤ 12.5 % внутрішньої вартості); розрахунок за ціною поставки Deribit.
- **H1 (первинна):** тримати до експірації, середній R > 0. **H2:** вихід на денному зрізі при ≥ 70 % максимального прибутку або коли спот пройшов продану ногу. **H3:** парна різниця R(за трендом) − R(дзеркальний спред проти тренду).
- **Статистика:** кластерний бутстреп (кластер = трендовий епізод), 10 000 вибірок, seed 20261114; блоковий бутстреп по тижнях (блок 4); неперекривні підвибірки (кожен другий вхід); Холм на H1–H3; MDE = 2.8 × кластерна SE.
- **Ворота покриття:** ≥ 60 % трендових субот зі знайденим спредом. Факт: 197 / 238 = **82.8 %**, пройдено.
- **Рівень цін (зареєстрована перевірка «|різниця| ≤ 2 %»): формально не пройдена.** Закриття Binance (п'ятниця) проти спота поверхні (субота 09:00), n = 301: медіана 0.33 %, **максимум 11.12 %** (а не 12.6 %, як було в рядку «Стадія 0» картки: те число й дати 2021-02-23 / 2024-08-05 прийшли з іншого розрахунку, і ці дати — не суботи). Максимум припадає на суботу **2021-12-04**: закриття п'ятниці 2021-12-03 — 53 601 (кеш Binance), різниця 11.12 % дає спот ≈ 47.6 тис. о 09:00 суботи, тобто рівень після справжнього нічного обвалу BTC 4 грудня 2021 (скрипт дату максимуму не друкує; її встановлено за кешем, без нового прогону). Розрив між п'ятничним закриттям і суботою 09:00 — це 9 год реального руху, а не колізія тикерів чи одиниць (медіана 0.33 % це підтверджує). На угоди це не впливає: страйки й дебет рахуються від спота поверхні, закриття Binance — лише для мітки тренду.

### Правило вердикту H1 (цитата з реєстрації)

> ✓ — CI нижня межа > 0 і p за Холмом < 0.05, OOS-середнє > 0 і середнє при половині спреду 3 в.п. > 0; ≈ — середнє > 0 у всій вибірці, IS і OOS, але CI містить 0; **✗ — CI верхня межа < 0, або середнє ≤ 0 і верхня межа < +0.15 R** (перевагу, вартую зусиль, виключено); ◯ — інакше (CI містить 0, верхня межа ≥ 0.15 R: замало даних).

Перевірка, що це ✗, а не ◯: **вердикт тримається на зареєстрованій умові № 2** (середнє ≤ 0 і верхня межа < +0.15 R). Умова № 1 (верхня межа < 0) — **гранична**: за зареєстрованим кластерним бутстрепом верхня межа −0.007 < 0, але інші CI її перетинають (блоковий бутстреп +0.049, CR1-SE з t(15) +0.023, jackknife по кластерах з t(15) +0.038; перерахунок критика з `trades_h1.json`). Умова № 2 стійка за всіма CI у всіх варіантах **з витратами**: максимум верхньої межі +0.097 (модель «сторона», jackknife-t), +0.080 без 2021. ◯ за текстом — лише «інакше», тобто коли жодна з умов ✗ не виконана. Холм p = 0.085 на ✗ не впливає: правило ✗ не вимагає значущості, Холм потрібен лише для ✓.

Вердикт для правила з витратами не залежить від вибору CI: за блоковим бутстрепом −0.183 [−0.415; +0.049], за неперекривними підвибірками −0.209 [−0.477; +0.031] і −0.156 [−0.405; +0.082], за jackknife-t [−0.403; +0.038]. У всіх 13 варіантах чутливості з ненульовими витратами середнє < 0 і верхня межа < 0.15 R за зареєстрованим CI. Варіант «половина спреду 0» (без витрат) теж формально проходить умову № 2 за зареєстрованим бутстрепом (+0.102), але за jackknife-t — ні (+0.148, на межі; +0.196 без 2021), тому для нього висновок ◯, а не ✗ (див. нижче).

Тобто «правило гарантовано втрачає й до витрат» ці дані не показують. **До витрат результат ◯:** середнє −0.098, CI містить 0; верхня межа +0.102 за зареєстрованим кластерним бутстрепом, але перцентильний бутстреп на 16 дуже нерівних кластерах (один епізод — 38 угод, шість — по 1–2) схильний до завузьких інтервалів, і з jackknife по епізодах (t(15)) вона +0.148, а без 2021 — +0.196. ## Застереження

1. **Лише BTC.** ETH не перевірено (у кеші поверхонь лише BTC). Розширювати вердикт на ETH можна лише як апріорі, не як результат.
2. **Ціни Deribit, не Bybit.** Генератор торгує за bid / ask Bybit; історії Bybit нема. Марки Deribit з поправкою ±1.5 в.п. — припущення про половину спреду Bybit; чутливість 0 / 1.5 / 3 в.п. і модель «сторона» це покривають, і жоден варіант не дає плюса.
3. **Розрахунок за ціною поставки Deribit** (середнє індексу перед 08:00), а не Bybit; обидві — середнє індексу, різниця має бути малою, але її не перевірено.
4. **2021 покрито слабко:** 15 угод із 34 трендових субот (бракує свіжих страйків проданої ноги). 2021 — найгірший рік (−0.755); без нього середнє було б менш від'ємним, але жоден інший рік не додатний.
5. **Мало епізодів:** 16 кластерів-епізодів (bear — лише 3). Кластерний бутстреп на 16 кластерах схильний до вузьких CI; блоковий бутстреп (+0.049) і jackknife-t (+0.038) ширші, але й вони < 0.15 R з витратами. Без витрат jackknife-t дає +0.148 (+0.196 без 2021), тому до витрат — ◯. Ефект до ≈ 0.29 R (MDE) у будь-який бік ця вибірка окремо не розрізняє; висновок ✗ — про відсутність переваги ≥ 0.15 R у правила з витратами, не про точну величину.
6. **Повна втрата в 66 % угод**: розподіл R дуже скошений (5 найкращих угод +3.3…+5.0 R, усі bull 2023–2024); без них −0.284.
7. Тренд-фільтр перевірено лише в цій формі (SMA200, нахил 20 д, суботній вхід); інші горизонти чи інші конструкції на тренді — нова картка з механізмом, не висновок цього прогону.

## Що змінено

- Плейбук: P3 «Докази» → ✗ з посиланням сюди; P3 — у списку «не робимо»; черга пункту 4 починається з P1′.
