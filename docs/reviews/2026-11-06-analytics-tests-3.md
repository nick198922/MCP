## Еталони й мутації (за міркуванням)

- Еталони пораховано вручну в коментарях: `0.0003*1095` (APR), `0.25/0.25/-0.5`, `0.005 / -0.00175` для кошика, `0.0001*100/2 = 0.005` для `funding_r`, `crc32("123456789") = 0xCBF43926`, дати останніх п'ятниць із перевіркою `weekday() == 4`. Це незалежні числа, а не копія виводу коду.
- Мутація «знак у `signed_notional` для short» ловиться (`-1500`). Мутація «365 → 360 у `tau_of_hours`» ловиться (`pytest.approx(1.0)` при 24*365). Мутація «`>` замість `>=` на межі MIB у `fmt_bytes`» ловиться (`fmt_bytes(MIB) == "1 МБ"`). Підміна «strictly after» на «≥» у виплатах carry ловиться межею `last = 2B`. Підміна знака для short у `funding_r` ловиться.
- Прогалина, не блокер: `last_friday` не перевіряє місяць, де 31-ше є суботою або неділею, але п'ять випадків різних днів тижня покривають логіку.
