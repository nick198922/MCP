- Новий інструмент `pendle_yield_curve` (Фаза 5.4, лише читання): терм-структура implied APY для активу по активних ринках Pendle, відсортована за експірацією; дні до експірації, implied/underlying APY (десяткові частки), зміна vs попередня експірація, ліквідність/TVL, мережа, прапорець `thin` для тонкої ліквідності.
- Без інтерполяції: лише спостережені точки; у `warnings` — implied APY ринковий, не гарантований, крива не arbitrage-free. Чиста функція `build_yield_curve` в `analytics/pendle.py` (час через `now`), той самий провайдер `pendle` і його ліміт.
- Для кожної експірації береться одна репрезентативна точка (найбільша ліквідність); зміна vs попередня експірація і форма кривої рахуються лише між ними (форма порожня, якщо збіглося кілька назв). Невідома ліквідність → `thin=null` з попередженням; `min_days > max_days` → `invalid_argument`.
