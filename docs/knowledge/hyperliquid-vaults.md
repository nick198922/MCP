# Волти Hyperliquid і оцінка трек-рекордів (копітрейдинг)

## Суть
- Волт HL: публічний рахунок лідера з капіталом учасників (комісія лідера ~10 %). Усе видно: `vaultDetails` (капітал, PnL, ~тижневі точки), `userFunding` (денні розміри позицій), `userFillsByTime` (угоди, лише останні ~2 місяці), ledger (депозити/виведення без адрес).
- Розібрано: BredoStrategy і CryptoBred Vault (`../library/LIB-20261023-cryptobred-vaults.md`). Скрипт `scripts/research/vault_profile.py <адреса>` дає капітал і притоки, плече, бету й механічні еталони, епізоди, контекст входів.
- Метод автора (за його словами): фундаментальні проєкти, вхід біля дна, докупівля на просадках по 5 %, фіксація по 10 %, без стопів; перетерпіти просадку.

## Механізм (чому це не альфа)
- Результат +$3M ≈ бичачий рух альтів × плече ≈ 3.2x × гроші учасників. Бета на альт-кошик 2.6, альфа t = 0.2; «кошик 3x і тримати» +119 % / просадка 72 % проти його +117…+145 % / 50-60 %.
- При виведенні учасником HL закриває пропорційну частку всіх позицій (62 % закриттів лідера за 2 місяці були такими) — це не рішення лідера.
- Ухил вижилих: дивимось на тих, хто в плюсі.

## Що показали наші перевірки
- Прямих перевірок немає. Суміжні: `2026-10-17-smart-money-persistence` (◯ inconclusive за потужністю), `2026-10-15-alt-downside-beta-basket` (асиметрія є, угода ✗), `2026-10-15-daily-residual-reversal-perps` (картка rejected за витратами).
- Картка: `IDEA-20261023-alt-basket-leverage-benchmark` (proposed): еталон «кошик × плече» на 2021-2026.

## Відкриті гіпотези
- H1 бета-репліка + хвіст вікон: картка вище.
- H2 ребаланс смугою («+5 % після падіння, −10 % після росту»): картки нема. У його ж даних щотижневе повернення до 3x дало −1 % / 79 % проти +119 % без ребалансу, тобто на цьому кошику ребаланс шкодить; на 8 місяцях, одному режимі, перевірки не варто (замало незалежних даних).
- H3 добір у червоні дні кошика: картки нема. Крос-секційну версію вже відхилено (`IDEA-20261015-daily-residual-reversal-perps`, витрати з'їдають ефект); часова версія на кошику має MDE ≈ 0.65 %/добу (≈ 400 червоних днів, SD 3.5 %) проти очікуваних 0.2-0.4 %, тобто не перевіряється. Його власна кореляція −0.30 (n = 63) розвідувальна.

## Як користуватись зараз
- Перед копіюванням будь-якого лідера: профіль волта (бета, плече, частка прибутку від 1-2 монет, частка закриттів через виведення) і порівняння з механічним «кошик × плече».
- Трек-рекорд без альфи після віднімання беті не копіювати; доборів лідера як сигналу не брати (альфи t ≤ 1).
- Правила власника (ризик $100 на угоду, стопи) несумісні зі стилем «без стопів, 3x, просадка 50-79 %».
