# P12: залізний кондор з 25Δ шортами, BTC 2021–2026 — H1 ✗ NOT CONFIRMED (з витратами Bybit), H2 ◯, H3 ✗

Дата: 2026-11-14 · картка: [IDEA-20261114-options-playbook](../ideas/IDEA-20261114-options-playbook.md), пункт 4, розділ 4.3 · правило: P12 у [плейбуці](../knowledge/options-playbook.md)

## Коротко

Кондор P12 (продані пут і кол |Δ| 0.25, крила на 3 % спота далі, експірація ≈ 13 д, вхід **щосуботи 09:00 UTC без умови**, до експірації; марки Deribit ± 1.5 в.п., комісії Bybit) на історії BTC **збитковий**: середній R = **−0.149** на максимальний збиток (капітал під ризиком), 95 % CI [−0.229; −0.065] (об'єднання кластерного й блокового бутстрепу), n = 203 у 70 чотиритижневих блоках, p 0.001 (Холм на 9 тестів 0.003). IS −0.141, OOS −0.155. На номінал це −0.41 % спота на угоду. Мінус є в кожному році (2022 −0.016, решта від −0.11 до −0.23) і в кожному з 16 зареєстрованих варіантів без умови DVOL. Верхня межа CI нижча за нуль, тож за зареєстрованим правилом **H1 ✗**. Ворота хвоста пройдено (82 збиткові угоди в 51 з 70 кластерів), тож бутстреп тут бачить хвіст, і проблеми P1′ немає.

Механіка проста: 60 % угод у плюсі із середнім виграшем +0.250 R, але 40 % збиткові із середнім збитком −0.738 R (43 з 82 — майже повний збиток, R ≤ −0.9). Беззбиткова частка виграшів дорівнює **74.7 %**, а фактична становить 59.6 %. «Премії в крилах», про яку йшлося в розвідувальній підказці (+0.73 % спота, n = 40), на марках з витратами немає. До половини спреду (комісії Bybit лишаються) результат −0.023 [−0.119; +0.077], тобто до спреду ◯ (розвідувальна мітка, не зареєстрована гіпотеза): перевагу не доведено й не виключено, а значущий мінус дають витрати 4 ніг. 25Δ не кращий за 15Δ на тих самих суботах: парна різниця −0.025 [−0.089; +0.033].

**H2** (той самий кондор лише при перцентилі DVOL ≥ 0.8, умова P2): +0.302 [+0.085; +0.682], n = 19 у 7 серіях, Холм 0.044, OOS +0.192, стрес 3 в.п. +0.126. Механічно це ✓ (лише завдяки трьом виродженим p = 0 від P1′ у Холмі; без них ≈ 0.077), але **ворота хвоста не пройдено**: збиткових угод лише 2 (потрібно ≥ 5), а P(ресемпл без збиткового кластера) = 0.095 > 0.05. Тому за реєстрацією вердикт **◯**. Параметричний хвіст (зареєстрований) дає стрес-середнє −0.099. **H3** (вихід за курсом 80 % кредиту або дотик проданого страйку): −0.215 [−0.270; −0.156] → **✗**, гірше за утримання.

## Метод (реєстрація — у картці, розділ 4.3, коміт `7ca7c755`, до будь-якого P&L)

Реєстрацію й код після коміту не змінено. Повний прогін `--stage full` зроблено окремим кроком після коміту реєстрації та стадії 0.

- **Вибірка:** BTC, суботи 09:00 UTC 2021-01-02 … 2026-10-03 (301). Кондор побудовано 203 (**покриття 67.4 %**, ворота 60 % пройдено); 2021 рідкий (15 / 52). ETH не покрито (кеш поверхонь лише BTC).
- **Конструкція:** `choose_expiry(snap, 14, 7, 24, "nearest")` (DTE 12.96 д); продані |Δ| 0.25 за посмішкою дня (фактично медіана 0.249, p10–p90 0.227–0.273; від спота медіана 5.97 %), крила — проданий ∓ 3 % спота (фактично 3.10 %, 1.54–4.48 %); кожна нога — найближчий свіжий страйк у межах ±1.5 % спота від цілі; кредит після комісій у (0; ширина) (медіана 0.190 ширини); 1 BTC на ногу.
- **Ціни й витрати:** продані за mark IV − 1.5 в.п., куплені за mark IV + 1.5 в.п. (Black-76, r = 0, форвард поверхні); комісії Bybit `option_ideas.fee` на кожну ногу на вході й на достроковому виході; поставка 0.015 % ≤ 12.5 % внутрішньої вартості; розрахунок за ціною поставки Deribit.
- **R** = P&L / (ширина ширшої сторони − кредит після комісій), тобто дохідність **на капітал під ризиком**. Маржа Bybit на проданий опціон крилом не зменшується, тож дохідність на фактичну маржу за модулем менша (і для збитку теж).
- **H1:** щосуботи без умови, до експірації. **H2:** лише перцентиль DVOL ≥ 0.8 (`vrp.trailing_percentiles`, свічка п'ятниці). **H3:** як H1, вихід на денному зрізі при ≥ 80 % кредиту або коли спот дійшов до проданого страйку.
- **Статистика:** кластерний бутстреп (H1, H3: 4-тижневі календарні блоки; H2: серії ≥ 0.8), 10 000 вибірок, seed 20261114; для вердикту — об'єднання з блоковим бутстрепом по тижнях (блок 4); дві неперекривні підвибірки; Холм на партію пункту 4 (P3, P1′, P12 по H1–H3, разом 9); MDE = 2.8 × кластерна SE.
- **Ворота хвоста (урок P1′):** ≥ 5 збиткових угод (R ≤ 0) і (1 − k/K)^K ≤ 0.05. Якщо не пройдено, ✓ / ≈ неможливі і вердикт ◯. Параметричний хвіст звітується завжди: частка збиткових — одностороння 95 % верхня межа Клоппера — Пірсона на гіршій неперекривній підвибірці; розмір збитку — середній збиток вибірки (якщо < 5 збитків — H1).

### Правило вердикту (цитата з реєстрації)

> ✓ — нижня межа CI > 0, p за Холмом < 0.05, OOS-середнє > 0 і середнє при половині спреду 3 в.п. > 0; ≈ — середнє > 0 у всій вибірці, IS і OOS, але CI містить 0; ✗ — верхня межа CI < 0, або середнє ≤ 0 і верхня межа < EDGE_R; ◯ — інакше; ✓ / ≈ з непройденими воротами хвоста → ◯. EDGE_R = 0.05 R.

Розбіжність коду й тексту (рев'ю, п. 4; тут не спрацювала): `condor_25d.verdict` повертає ≈ і тоді, коли нижня межа CI > 0, але Холм ≥ 0.05 або стрес витрат ≤ 0 (так закріплено в `tests/test_condor_25d.py`). Текст реєстрації вимагає для ≈ «CI містить 0», тобто такий випадок мав би дати ◯. У цьому прогоні жодна гіпотеза в цю гілку не потрапила (H1 і H3 ✗, H2 ◯ через ворота хвоста), тож зареєстрований код не змінено. У наступній реєстрації текст правила й функцію треба узгодити.
