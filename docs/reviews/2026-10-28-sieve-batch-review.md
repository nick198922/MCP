### 2. `strat_212_reversal` — ok
- Нумерація барів (1/2U/2D, рівність = не пробито) збігається зі сторінкою LuxAlgo. 2D-1-2U лонг, 2U-1-2D шорт; стоп = інший бік inside-бару (`lo[b]` / `h[b]`), ціль = екстремум бару перед inside (`h[a]` / `lo[a]`) — як на сторінці.
- Причинність: бар `i` бачить `i-3..i`, `pos[i] ≥ 3` гарантує, що `a-1` у тому ж сегменті.

Наслідок для інтерпретації (medium): ризик вимірюється від закриття третього бару до `lo[b]`, а ціль `h[a]` часто поруч, тож R:R структурно гірший за джерельний; негативний результат не спростовує оригінал. Це треба сказати у звіті прогону, правки коду не потрібно.
- Крайній випадок `close == lo[b]` дає невалідний сигнал, сито його відкидає (`Signal.valid`); нешкідливо.

### 4. `consecutive_high_close_short` — fix
Проблема (medium): правило скидання лічильника не збігається з жодним верифікованим джерелом.
- Код StockSharp 1601 (єдиний повністю прочитаний): `if close > prevHigh: count++; if close < prevLow: count = 0;` — бар, що не пробив high і не закрився нижче low, лічильник не чіпає. Спека ж скидає лічильник на будь-якому такому барі («строго поспіль»). Це третє, вигадане читання; у каталозі «джерела розходяться» подано так, ніби спека вибрала одне з них, а це не так. Сторінку TradingView я не зміг завантажити (порожня відповідь), тож «ведмежий бар» залишається непідтвердженим.
- **Exact fix** (`consecutive_high_close_short.py`, рядок з `count = count + 1 if ...`): замінити на
  ```python
  if bars.c[i] > bars.h[i - 1]:
      count += 1
  elif bars.c[i] < bars.low[i - 1]:
      count = 0
  ```
  і переписати абзац docstring і примітку в каталозі: правило скидання взято з коду StockSharp, TradingView не перевірено. Якщо харвестер вважає суворе читання «справжнім» — залишити, але тоді в каталозі прямо написати, що воно не є правилом жодного джерела. Перерахувати `--limit` (кількість сигналів зміниться).
- Для звіту після прогону (без правки коду): StockSharp у коді застосовує EMA-фільтр обов'язково (`close < EMA`, період 50, текст каже 200), TradingView — «optional». Спека його не застосовує, тож тестується нефільтрований шорт після трьох закриттів вище high, у висхідному тренді це фактично шорт проти імпульсу. Негативний результат не спростовує джерело. Також дефолтний таймфрейм StockSharp — 4h, сито має лише 1d/1h; варто дописати в рядок каталогу.
- Причинність без зауважень (лічильник і `h[i-1]` лише до `i`; обнулення на `pos==0`).
