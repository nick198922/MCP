## Коректність математики (звірено читанням і по тестах)
- `mid = (bid+ask)/2` лише за обох сторін; `spread_pct = (ask-bid)/mid*100`, перевірено на 1485/1490 (0.336 %).
- `spread_iv = ask_iv - bid_iv`, лише за обох IV. `num` дає None для «0», і це відповідає поведінці Bybit (IV «0» = немає). Є тест на стороню без bid.
- ATM — найближчий до медіани `underlyingPrice` експірації, при рівності нижчий (`atm_strikes`). Без базової ціни центр — медіанний страйк, `atm_*` = None (тест).
- OI рахується по всіх страйках експірації, не лише показаних, невід'ємний, нуль — значення (тест).
- ATM IV — медіана двох значень, тобто середнє колу й путу.
- Лише USDT: USDC-символи не змішуються зі страйками USDT, є попередження (тест: дані з дублями побайтно рівні даним без них).
