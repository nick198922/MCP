# Відбір критика A: досьє S12 (v4, пункт 8 картки, крок 7a)

Вердикт: **approve** (до 7b передано 5 гіпотез з 12; H11 і H12 не модулі, поза Холмом).

1. **Take (5):**
   - H1 (CLV свічки дотику): v4 входить за закриттям цієї свічки, її форма не міряна ніде; неперервна, |ρ| ≥ 0.04–0.06 на n ≈ 27 тис. (2021+).
   - H2 (ранній 1h-вхід замість закриття 4h): парна різниця, MDE ≈ 0.04–0.05R; механізм — ціна входу, а не фільтр над лімітом, тому не дублює S28 H6 ✗. Це єдина «довга ставка» (апріорі ≈ 8 %).
   - H3 (ширина гепу / ATR): неперервна, булева версія ✗ (крок 4) не повторюється.
   - H5 (лише `edge_touch`, знак від'ємний; `age` лише описово).
   - H8 (`dry` = обсяг відкату / обсяг імпульсу): напрям визначений теорією, на відміну від відкинутих двозначних обсягів (S3 H3, S38 H2, S28).
2. **Drop (5):**
   - H4: булева 30–50 %, невимірна окремо; родина вето за трендом / S28 H4; вільні k і вікно.
   - H6: частота 10–15 %, MDE ≈ 0.25R; лише форвард.
   - H7: найближчі тести від'ємні (S40 H1, btc-shock-alt-lag), BTC-режим ✗, подвійний вибір β.
   - H9: покриття 5m невідоме, близький тест liquidation-flush `rejected`, пороги довільні.
   - H10: родина відкинутих цілей (S3 H9 / S38, S39 H5, поріг R:R); дві вільні межі 1.2R / 3R і вибір між «хай свічки 2» та «найвищий хай 3 свічок».
3. **Не модулі:** H11 (ранжування слотів) залежить від ознаки; після того як одна з H1/H3/H5/H8 пройде плацебо, лише описова симуляція слотів без вердикту (паспорт слоти не моделює). H12 (2h / 8h / 12h, шорти) — правило підтвердження для тих, що пройшли на 4h, без перепідбору порогів; вердикт за 4h.
4. **Холм на 5** (H1, H2, H3, H5, H8). Не прибирати жодного без нового рішення. Знаки до прогону: H1 +, H2 Δ > 0, H3 +, H5 (`edge_touch`) −, H8 (`dry`) −.
5. **Потужність** (за числами картки, мною не перераховано): SD одного R ≈ 1.1, n 26 965, SE ≈ 0.022 (тижневі блоки). Неперервні ознаки: |ρ| ≥ 0.04–0.06 ≈ 0.07–0.10R між половинами; парна H2: MDE ≈ 0.04–0.05R; OOS (n 6 431) ≈ 0.25R для булевих, неперервні там майже невимірні — «невимірно», не «ні». База ≈ 0, плацебо ≈ 0, тож реалістичний вихід — `inconclusive`; сумарна апріорна ймовірність для п'яти низька (≈ 5–10 % на модуль).
6. **Виправлення в картці (для кванта, обов'язкові):**
   - **H8, знак.** У «Умовах для кванта» п. 1 H8 записано «додатний», але ознака `dry` = відкат / імпульс, а теорія (малий обсяг відкату → продовження) дає **від'ємний** ρ(dry, R). Фіксувати від'ємний. Вікно відкату — свічки після третьої до свічки дотику включно (у тексті «від 3» перетинається зі знаменником).
   - **H2, заглядання.** Усі фільтри v4 (денний тренд, EMA21, ATR, відбір R:R ≥ 1.5, стоп ≤ 10 %) і сама множина угод мають визначатися лише даними на момент 1h-входу (попередні закриті 4h-свічки). Якщо множину визначає закриття поточної 4h, це заглядання; потрібен тест причинності. R:R і стоп перераховуються від фактичної ціни входу; угоди із запасним входом (за v4) — окремий рядок, не складати в Δ.
   - **H1, механічність.** R рахувати від реальної ціни входу до стопу, ознака — у межах множини, що пройшла відбір R:R (інакше ρ механічно від'ємна через гірший R:R при високому закритті); плацебо — з тим самим `clv`; нижня тінь лише описово.
   - **H3, механічність.** Ширина гепу пов'язана зі стопом у % ціни; плацебо з тією ж `gap_atr` і звіт з контролем відстані до стопу; H3 і H5 показувати разом (перекриття).
   - **H5.** У Холмі лише `edge_touch` (−); `age` без апріорного напряму — описово, двосторонній тест додав би Холм-кошт.
7. **Умови для кванта (доповнення до п. 1–11 картки):**
   - (а) База v4 на списку демо (вхід за закриттям, 7 діб, БУ, відбір за балом) з плацебо тієї самої геометрії — **перед усім**; паспорта v4 нема, а «≈ 0» стосується v7. Без бази модулі не мають еталона.
   - (б) E[R] > 0 після витрат ×1.5 обов'язково; «менший збиток» не ідея.
   - (в) Відкинуте не повторювати (вето за трендом / BTC-режим, імпульсні FVG за тілом, структурний стоп, вихід за 6 год, БУ +1R, часткові виходи, поріг R:R).
   - (г) IS + OOS разом, OOS окремим рядком, одна версія, без сіток; сума R за рік, E[R], n, % ціни, CI тижневим блок-бутстрепом.
   - (д) H1, H3, H5, H8 перекриваються: комбінацію показувати разом, Δ не складати.
8. **Ризик:** якщо жоден не пройде плацебо, S12 лишається `inconclusive`. Рішення «чи лишати v4 на демо» не залежить від цього відбору.
9. Змінено лише позначки «Критик A» у розділі «Досьє S12» картки та додано підсумковий рядок після неї. Рядки скаута не чіпав; пункт 8 не відмічено. Прогони й тести не запускались, цифри картки не перераховувались.
