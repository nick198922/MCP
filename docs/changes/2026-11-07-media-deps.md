# Залежності медіа-скриптів (пункт 189, BACKLOG 6.38)

- Медіа-скрипти `scripts/` (`tg_export.py`, `tg_videos.py`, `yt_asr.py`, `yt_frames.py`, `lesson_sheets.py`, `yt_transcript.py`) без потрібного пакета більше не падають з `ImportError`: кожен імпорт `bs4`, `faster_whisper`, `imageio_ffmpeg`, `PIL`, `youtube_transcript_api` загорнуто в `try/except ImportError`, і скрипт завершується (код 1) з точною командою запуску `uv run --no-project --with ...` з власного docstring. У `yt_transcript.py` перевірка переїхала з `main` у `fetch` (повідомлення те саме).
- Extra `media` у `pyproject.toml` **не додано**. Цих пакетів немає в `uv.lock`, отже нижньої межі «з `uv.lock`» немає. Без оновлення lock-файлу extra додати не можна (`uv run` сам переписав би lock), а `uv lock` у цьому прогоні заборонено. До того ж скрипти задумано запускати ізольовано (`--no-project`, `python -I`), тож extra проєкту вони б і не використовували. Якщо extra все-таки потрібен, власник виконує `uv lock` (`faster-whisper` додасть у lock `ctranslate2`, `onnxruntime`, `av` тощо).
- `scripts/deps_check.py` тепер розпізнає `if find_spec("x"):` і `if importlib.util.find_spec("x") is not None:`: імпорт саме модуля `x` у тілі такого `if` вважається умовним. Так `mlx_whisper` у `yt_asr.py` (лише Apple Silicon) потрапляє до інформаційного списку. `matplotlib` в `assistant_brief_tg.py` не змінено: без нього бриф і так іде текстом.
- Результат `deps_check` на репозиторії: у `scripts` неоголошених безумовних імпортів 0 (було 6), умовних (лише інформація) 7. У `src` без змін: 0.
- Тести в `tests/test_deps_check.py` (було 6, стало 15): охоронець `find_spec` (той самий модуль, інший модуль, `else`, неконстантний аргумент); регресія «у `scripts` 0 неоголошених»; кожен скрипт без свого пакета виходить через `SystemExit` з командою `uv run --no-project --with`. `make lint` пройшов.
