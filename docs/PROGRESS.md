# Прогрес до готового продукту

Етапи продукту поза картками ідей. Панель проєкту (`scripts/dashboard.py`) рахує загальний прогрес так:
- кроки розділу «Прогрес» у кожній картці власника;
- плюс пункти з цього файлу.

Кожен пункт важить однаково. Коли з'являються нові картки чи кроки, загальна кількість росте, тож відсоток може й зменшитись — це чесно.

Позначає зроблене той, хто зробив: агенти — лише пункт, який закриває їхній злитий PR; власник і Claude — решту.
Мета продукту — асистент, що знає ринок і допомагає власнику торгувати (`docs/AGENTS.md`, «Візія»).
