# Волти Hyperliquid і оцінка трек-рекордів (копітрейдинг)

## Суть
- Волт HL: публічний рахунок лідера з капіталом учасників (комісія лідера ~10 %). Усе видно: `vaultDetails` (капітал, PnL, ~тижневі точки), `userFunding` (денні розміри позицій), `userFillsByTime` (угоди, лише останні ~2 місяці), ledger (депозити/виведення без адрес).
- Розібрано: BredoStrategy і CryptoBred Vault (`../library/LIB-20261023-cryptobred-vaults.md`). Скрипт `scripts/research/vault_profile.py <адреса>` дає капітал і притоки, плече, бету й механічні еталони, епізоди, контекст входів.
- Метод автора (за його словами): фундаментальні проєкти, вхід біля дна, докупівля на просадках по 5 %, фіксація по 10 %, без стопів; перетерпіти просадку.

## Механізм (чому це не альфа)
- Результат +$3M ≈ бичачий рух альтів × плече ≈ 3.2x × гроші учасників. Бета на альт-кошик 2.6, альфа t = 0.2; «кошик 3x і тримати» +119 % / просадка 72 % проти його +117…+145 % / 50-60 %.
- При виведенні учасником HL закриває пропорційну частку всіх позицій (62 % закриттів лідера за 2 місяці були такими) — це не рішення лідера.
- Ухил вижилих: дивимось на тих, хто в плюсі.

## Що показали наші перевірки
- **`2026-10-23-alt-basket-leverage-benchmark` (confirmed: H1 ✓, H2 ≈, H3 ✓; лише частоти; калібрування, не альфа).** Кошик топ-12 альтів Binance за 30-денним обігом (з делістнутими), рівні ваги, cross-маржа, повернення до L раз на 30 днів. 222 восьмимісячні вікна 2021-11 … 2026-09, n_eff ≈ 7.4. Результати при L = 3:
  - ліквідація у 50 % вікон за закриттями (нижня межа) і у 78 % за intraday-мінімумами (верхня межа; last price, а не mark price, тож ризик завищено);
  - DD ≥ 70 % або ліквідація — у 98.6-100 % вікон;
  - дохідність ≥ +100 % (3.2-6.8 % вікон) дало лише одне скупчення стартів (літо 2023, SOL/TRB) з ≈ 7 незалежних вікон, тож точна частка не визначена;
  - медіана −99 … −100 %.
  
  «Купити й тримати» (розвідувально): ліквідація 63-76 %, ≥ +100 % у 12-13 % вікон (знову переважно старти 2023). Ребаланс руїну не підвищує, але зрізає правий хвіст.
  
  Базові рівні: при L = 2 DD ≥ 70 % у 82-94 % вікон; при L = 1 медіана −17 %, DD ≥ 70 % у 17 % вікон; BTC 3x: медіана +21 %, ліквідація у 16-26 % вікон.
  
  Порівняння з волтом: кошик за правилом під 3x «купи й тримай» 2026-02-17 … 09-30 дав +132 % (DD 62-73 %) ≈ результат волта. Перцентиль його +117 … +145 % залежить від механізму: проти 30-денного ребалансу 95-97-й, проти «купити й тримати» (стиль волта) ≈ 88-й, тобто ≈ 1 вікно з 8. Волт стартував одразу після обвалу 31.01-06.02.2026, і його вікно 226 днів, а не 243.
- **`2026-10-23-vault-sizing-i1` (✗ NOT CONFIRMED).** Добори й фіксації BredoStrategy (плече проти руху, кореляція −0.4…−0.5) на тих самих дохідностях не кращі за постійне плече того самого рівня: 65-74-й перцентиль серед циклічних зсувів шляху плеча; «тримати 3.4x» на його монетах +168 % / DD 49 % проти його +143 % / DD 60 %. Меншу за «кошик 3x» просадку дав нижчий за бетою склад (0.79 на кошик), а не розмір. Методична примітка: денний капітал волта рахувати від останньої офіційної точки + перерахований PnL (`vault_sizing.anchored_equity`); інтерполяція офіційного PnL (`daily_equity`) затягує майбутнє і ламає компаундинг (+11 % замість +145 %).
- Суміжні: `2026-10-17-smart-money-persistence` (◯ inconclusive за потужністю), `2026-10-15-alt-downside-beta-basket` (асиметрія є, угода ✗), `2026-10-15-daily-residual-reversal-perps` (картка rejected за витратами).

## Відкриті гіпотези
- H1 бета-репліка + хвіст вікон: перевірено (вище, confirmed).
- H2 ребаланс смугою («+5 % після падіння, −10 % після росту»): картки нема. У його ж даних щотижневе повернення до 3x дало −1 % / 79 % проти +119 % без ребалансу, тобто на цьому кошику ребаланс шкодить; на 8 місяцях, одному режимі, перевірки не варто (замало незалежних даних). Його власне правило теж переваги не дало (I1, вище).
- H3 добір у червоні дні кошика: картки нема. Крос-секційну версію вже відхилено (`IDEA-20261015-daily-residual-reversal-perps`, витрати з'їдають ефект); часова версія на кошику має MDE ≈ 0.65 %/добу (≈ 400 червоних днів, SD 3.5 %) проти очікуваних 0.2-0.4 %, тобто не перевіряється. Його власна кореляція −0.30 (n = 63) розвідувальна.
- I2 вхід після капітуляції («войти около дна») і I3 монета-лідер після обвалу (HYPE): без карток (тріаж 23.10). ≈ 5-8 незалежних епізодів, MDE ≈ 40 п.п. проти очікуваних 10-15 п.п.; I3 перекривається з відхиленими `xs-factor-ic-panel` (M28) та `alt-downside-beta-regime-basket`. Не перевірено: це відсутність потужності, а не доказ відсутності ефекту. Деталі в `LIB-20261023-cryptobred-vaults.md`.

## Як користуватись зараз
- Перед копіюванням будь-якого лідера: профіль волта (бета, плече, частка прибутку від 1-2 монет, частка закриттів через виведення) і порівняння з механічним «кошик × плече».
- Перцентиль чужого 8-місячного результату: таблиця перцентилів (L = 1-3, ребаланс / «купити й тримати») у звіті `../verification/2026-10-23-alt-basket-leverage-benchmark.md`, розділ «Робастність». Відтворення: `uv run python scripts/verify_alt_basket_leverage.py bh`. Брати механізм, що відповідає стилю лідера.
- На кошику топ-12 альтів за обігом у 2021-11 … 2026-09 плече > 1 без стопів дало неприйнятний розподіл: при L = 2 просадка ≥ 70 % у 82-94 % вікон. У періоді переважав ведмежий ринок альтів, а кошик за обігом відбирає монети після пампів, тож на інших періодах цифри можуть бути м'якшими.
- Трек-рекорд без альфи після віднімання беті не копіювати; доборів лідера як сигналу не брати (альфи t ≤ 1).
- Правила власника (ризик $100 на угоду, стопи) несумісні зі стилем «без стопів, 3x, просадка 50-79 %».
