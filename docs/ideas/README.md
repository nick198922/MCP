# Ідеї стратегій

Картки ідей, які пише скаут і проходять конвеєр із `docs/AGENTS.md`. Шаблон — `TEMPLATE.md`, файл картки — `IDEA-РРРРММДД-slug.md`.

Статуси: `proposed` (запропоновано) → `accepted` / `forward` / `rejected` (тріаж критика) → `testing` → `confirmed` / `rejected` / `inconclusive` (бектест кванта і рев'ю критика) → `built` (є інструмент у MCP).

`forward` (з 21.10): механізм правдоподібний, але історія його не перевірить, бо подій замало або бракує даних. Така ідея не відкидається. Вона стає неперевіреним контекстом для планів угод асистента, і її оцінює форвардний запис. Плани з тегом `idea:<slug>` записуються через `plan_add`, а `plan_review` рахує їх результат. Умови й план — у розділі «Форвард» картки. `rejected` лишається для ідей без механізму, дублів, ідей, де витрати з'їдають ефект, і голого теханалізу.

Уже перевірене до появи агентів (звіти в `docs/verification/`): SFP і рейнджі з лекцій — ✗; cash-and-carry на мейджорах — дрібний плюс; carry на альтах — ~3–5 % на капітал; перп-перп carry — сильний, але хвостовий; VRP на BTC — розрив IV−RV на DVOL ✓, але на реальних марках `inconclusive` (прибутку не видно).
