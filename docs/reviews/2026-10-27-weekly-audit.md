## 6. Безпека

- 🟠 **Ключ власника читають агенти.** `/etc/tradedesk-bybit.env` (ключ Bybit лише для читання, 26.10) читають user-таймери `tradedesk-bybit-live` і `tradedesk-bybit-options` від `tradedesk` — того самого користувача, під яким працюють агенти. Їхні списки дозволів забороняють `Read(~/.config/tradedesk/**)` і `/etc/tradedesk-mcp.env`, але дозволяють `Bash(cat:*)` і `Bash(python3:*)`, і на `/etc/tradedesk-bybit.env` заборони нема. Для демо-ключа цей ризик прийнято ADR 0007; для ключа власника — ні. Права файла з цієї сесії перевірити не вдалося (`ls /etc/…` поза робочими каталогами). Рішення власника — BACKLOG. Нагадування: скрипти відкидають ключ, якщо `readOnly != "1"`, тож торгувати ним не можна, але читати позиції й баланс — так.
- 🟢 **Секретів у git і логах нема:** шаблони ключів / токенів у відстежуваних файлах, `history.tsv`, `loop.log`, `*.summary.md`, `*.doctor.md` — 0 збігів; `evidence` і помилки проходять `redact`.
- 🟢 **HTTP слухає `127.0.0.1`** (`config.py:27,137`), bearer-токени є; у публічний інтернет сервер не відкрито.
- 🟢 **Дозволи агентів:** DENIED покриває push у `main`, `--force`, `reset --hard`, `git config`, `rm -rf`, `sudo`, читання облікових даних; ALLOWED поповнився лише формами читання git (22–26.10). Списки не змінював.
- 🟡 **Гілка `claude/2026-10-26-prelimit-entries`** змінює `execution/demo_trader.py` (+85 рядків: вхід лімітом наперед на середині FVG для S12 v6).
