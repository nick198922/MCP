- Зупинена служба: якщо pull цього запуску приніс нові коміти (HEAD до pull ≠ HEAD після), а `tradedesk-mcp` не активна (`systemctl is-active`), — перезапуск без питання до скрипта, навіть коли злиття лише з docs. Так само, як досі: будь-яке злиття піднімало службу. Коли `main` не рухався, зупинену службу не чіпаємо, як і старий скрипт: службу, яку зупинили руками, щогодинний запуск не підніме. Порівнювати саме з HEAD до pull, а не з позначкою, вирішив тому, що після злиттів лише з docs позначка відстає від HEAD майже завжди, і тоді зупинену вручну службу піднімав би перший же щогодинний запуск без жодного нового злиття.
- Позначка розгорнутого коміту — файл root `/var/lib/tradedesk-update/deployed`, пишеться лише після успішних `uv sync` і перезапуску: ручний `git pull` клону іншими кроками чи невдалий `uv sync` більше не губляться (раніше наступний запуск бачив «main unchanged»). Root не виконує код репозиторію і не виконує відповідь скрипта, лише порівнює її з рядком `skip`.
