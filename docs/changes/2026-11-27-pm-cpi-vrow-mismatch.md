# 27.11.2026 — pm-cpi: рядок V / σ_A, який команди п. 10 не відтворюють, = `mismatch` (пункт 492)

Пункт 492 [постійної картки](../ideas/IDEA-20261102-standing-improvements.md): R2 повторного [рев'ю C пункту 484](../reviews/2026-11-27-pm-cpi-forward-scanner.md) і незаблокувальне 2 повторного [рев'ю C пункту 490](../reviews/2026-11-27-pm-cpi-proof-hardening.md); раунд правок за [рев'ю C пункту 492](../reviews/2026-11-27-pm-cpi-vrow-mismatch.md). Злити до 21:00 UTC дня T−3 релізу січня 2027; за п. 9 діє з першого релізу, чий M0 це містить.

## Що змінилось
- **Доказ (`--stage proof`).** Перебудова дерева M0 віддає нове поле `vrows`: рядки журналу, на яких стоїть σ релізу (`vrows_used`). Це перші рядки V1 і V2 і перший σ_A, але лише коли обидва V — `pass`. Доказ повторює для них команди п. 10 скриптом `verify_pm_cpi_step0.py` **дерева M0** (`vrows_repro`): експортує потрібні рядки 03.12, 09.12, 11.12 з БД (`mode=ro`), запускає `vcheck` для V1 (S проти 03.12, сходинка 2026-11) і V2 (09.12 проти 11.12) та `sigma` на 11.12. Рядок, який дані спростовують, дає `proof fail: mismatch (V / sigma_A lines: …)`.
- **Вердикт даних і збій середовища (рев'ю C, блокери 1, 2).** Вердикт дають лише розпізнані кінці на прочитаних даних: `NO ROW`, `NOT exported`, `V pass` (код 0), `V fail:` з причиною `vintage_why`, `JSONDecodeError` копії чи винятком структури (код 1), рядок `sigma` з n > 0 (код 0). Решта — `not recomputed (V / sigma_A lines: <рядок>: <причина>; run the proof again)`: `cannot read pm_cpi_snapshot`, експорт без рядка про файл, S відсутній чи з іншим sha256 (`V1_OLDER_SHA256`, `v1_older_why`), падіння, вбитий процес, таймаут 600 с, `n 0` / `sigma_A None` (HTML чи порожній CSV FRED), будь-що нерозпізнане. Такий прогін `proof pass` не дає ніколи й не рахується; якщо до звіту оцінки рядок так і не відтворено — «пропуск T−3 (mismatch)» (лише суворіше). Розбіжність іншого рядка лишається `mismatch`.
- **Дрібні (пп. 3–8).** Кожен прогін має свій каталог `tmp/pm_cpi_vrows_<випадкове>/` разом із кешем FRED (п. 3). Виняток звірки дає `not recomputed (… raised …)` і не прибирає інших причин доказу (п. 4). Рядок `sigma_A` з більш ніж 4 знаками — `mismatch` (п. 8). Текст реєстрації: п. 7 (8) — доказу для 2027 року потрібні FRED і файли S (п. 5); у п. 8 (1) коміт перейменовано на Mσ, `sigma_for` — коду M0 цього релізу (п. 6); у п. 4 записано, що команди виконує код M0 кожного релізу, а зміна їхніх функцій після 485 — зміна реєстрації за п. 9 (п. 7).
- **Хто її знає.** Нема `vrows` у відповіді (M0 старший за пункт 492) — звірка не застосовується (`not applicable, M0 before item 492`). `vrows`, що не є словником рядків, — `mismatch`.
- **10.12 не зачеплено.** Для `FIRST_RELEASE` поле `vrows` порожнє, жодна команда не виконується, у виводі доказу лише додатковий рядок `V / sigma_A lines: none used`. `T-3.json`, `REBUILT`, `T3_KEYS`, `CODE_PATHS` і команди етапів не змінились; `sigma_for` переписано через спільний `journal_vrows` без зміни поведінки.
- **Реєстрація.** «П'ята частина поправки 27.11» у вступі картки [pm-cpi](../ideas/IDEA-20261028-pm-cpi-brackets-vs-nowcast-forward.md), новий підпункт п. 4 ((а)–(д)), вставка п. 7 (8) і уточнення п. 8 (1) (перебудова «no sigma_A» для B: `--fallback` дерева M0 цього релізу з `--m0 Mσ`). Раніше зареєстрований текст не змінено. Станом на 27.11 рядків V1 / V2 / σ_A у журналі нема.
