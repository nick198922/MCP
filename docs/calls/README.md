# Трекер закликів

Заходи, цілі й стопи, які блогери й автори з бібліотеки (`docs/library/`) називають у відео чи постах, записуються тут і перевіряються вперед: чи дійшла ціна до зони, що дав вхід у ній і чи краще це, ніж діяти одразу. За кілька місяців видно, чиїм закликам варто довіряти.

- Заклики: [`calls.csv`](calls.csv).
- Звіт: [`REPORT.md`](REPORT.md). Його оновлює `uv run python scripts/calls_check.py`; агенти запускають скрипт раз на тиждень (крок a0 у `.claude/nightly.md`).

## Як додати заклик

Один рядок у `calls.csv`, поля:

| Поле | Що писати |
|---|---|
| `id` | унікальний, напр. `MR-BTC-LONG` |
| `date` | день заклику (запис відео чи посту); якщо невідомо — день, коли матеріал потрапив у бібліотеку |
| `source` | запис бібліотеки, напр. `LIB-20261015-market-review` |
| `asset` | тікер базового активу: `BTC`, `ENA` |
| `side` | `long` або `short` |
| `zone_low`, `zone_high` | зона входу; для однієї ціни обидва однакові |
| `target`, `stop` | якщо автор їх назвав, інакше порожньо |
| `horizon_days` | скільки днів стежити, за замовчуванням 90 |
| `symbol` | лише якщо автоматичний пошук не знайде ринок: `bybit:VVV/USDT:USDT`, `hyperliquid:kPEPE` |
| `note` | слова автора, застереження (у лапках, якщо є коми) |

Рядки з `#` — коментарі. Розмиті заклики («купувати на сильному відкаті») без ціни не записуються.

## Правила оцінки

Повністю — у docstring [`src/tradedesk/analytics/calls.py`](../../src/tradedesk/analytics/calls.py). Коротко:
- стежимо з наступного дня після заклику, лише завершені денні свічки UTC;
- зону торкнулися, коли лоу (для шорту — хай) дійшов до її краю. Вхід — на краю зони або за відкриттям, якщо ціна відкрилась уже за зоною;
- стоп рахується з дня входу, ціль — з наступного дня. Якщо одного дня зачеплено і стоп, і ціль, вважаємо, що спрацював стоп;
- «одразу» — вхід за відкриттям першого дня і вихід за останнім закриттям.

Дані — денні свічки перпів: спершу Binance, потім Bybit, потім Hyperliquid. Акції (напр. CRCL) і токени без перпів поки не перевіряються.
