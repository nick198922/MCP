# Панель: правила зручності

Рішення власника 28.10: панель перевантажена, «очі розбігаються», незрозуміло, навіщо те чи інше число. Мета —
юзабіліті, а не шрифти й кольори. Макет: https://claude.ai/artifact/RFNbdBdmcLEJ2ipk3qTz6Q (приватний, у власника).
Ці правила діють для всіх, хто змінює `scripts/dashboard.py` і Telegram-брифи (агенти теж).

1. **Спершу підсумок, потім деталі.** Угорі сторінки одне речення «що зараз» і одне «що робити».
2. **Кожне число відповідає на питання «що мені з ним робити».** Під плиткою — рядок дії (≤ 8 слів), а не опис.
3. **Підказка (i) — інструкція, а не визначення:** одне речення «що це», далі «мало → що робити», «багато → що
   робити», «зараз → …». Не більше 3–4 коротких рядків.
4. **Решта згорнута** (`_fold`: `<details>` без `open`), але в заголовку видно однорядковий підсумок з головним
   числом, щоб розгортати доводилось лише за потреби.
5. **Застереження один раз на сторінку, унизу.** Не повторювати «ризик-нейтральні», «не порада», «перевірено й
   відхилено» в кожному блоці.
6. **Те, що потребує дії, — першим і видно завжди:** відкриті позиції, порушені правила, подія < 48 год.
7. **Нова плитка чи блок — лише замість старого.** Додаєш — прибери або згорни щось менш корисне.
8. **Таблиці угод — як трейдерський журнал** (скрін власника 26.10): один рядок на угоду, контракт зі стороною
   (мітка ЛОНГ/ШОРТ), вхід, вихід, тривалість, комісії й результат у % від вартості позиції, USD дрібно під ним.

Система, решта — «Детально») → решта вкладок.
