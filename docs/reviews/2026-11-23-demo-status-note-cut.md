## Крайні випадки (розібрано за кодом і тестами)
1. Примітка ≤ `NOTE_CHARS` або порожня: повертається як є (рання гілка), порожній рядок не падає.
2. Довжина: хвіст ≤ N/3, тому room ≥ 2N/3 − 2 > 0. Голова ≤ room, плюс " …" (2) і хвіст, разом ≤ N. `rstrip` лише скорочує. Межа справді жорстка (раніше N+2). Тест `len(cut(n)) <= 30` це перевіряє.
3. Хвіст довший за третину: відкидається, примітка ріжеться як звичайний перелік. Є тест `long_tail`.
4. Нема ", " у другій половині room (або взагалі): `i = -1` або `i < room//2`, обрізання по символах, хвіст лишається. Є тест `no_sep` і `"z"*40`.
5. Нема "; " зовсім: `j = -1`, `tail = ""`, поведінка як раніше.
6. Очікуване, але не блокує: якщо "; " трапляється всередині останньої угоди (не як роздільник пояснення), «хвіст» буде шматком переліку, а не поясненням. Для реальних приміток (`; вони не входять у закриті вибірки…`) не виникає, і тест на реальній фікстурі це підтверджує.
