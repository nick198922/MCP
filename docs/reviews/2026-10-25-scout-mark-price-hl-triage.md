## Картки

1. **mark-price-stop-trigger, accepted (середня).** Потужність на межі: MDE 0.013R проти очікуваних 0.015R, параметри q, μ, SD не виміряні. Умова: ворота кроку 0 (≥ 150 розбіжних угод, MDE ≤ 0.02R) виконуються до читання R; формулу виходу гілки mark при запізненні зафіксувати в реєстрації; primary лише H1, H2 описова; вердикт стосується Binance-симуляції, зміна демо лише після перевірки на Bybit mark. Ймовірність знижено з ~20 % до ~12 %: сам потік сетапів має E[R] ≤ 0, і це поліпшення збиткового потоку.
2. **hl-whale-liquidation-magnet, forward (середня).** Історії позицій нема. Виправлення: база для H1 мусить бути емпіричною (жирні хвости, умова «ціна вже рухається до рівня»), а не нормальною P0 (інакше хибно-позитив); суперечність частоти (ворота 1/тиждень проти 24/рік у цінності) розв'язана воротами кроку 0; рішення за n ≥ 90, не 60. Секцію «Форвард» додано до картки, S37 додано в `docs/knowledge/setups.md` зі статусом ◯. `trader_positions` — журнал змін без mark, тож крок 0 дасть наближену d (mark із годинних свічок HL).
