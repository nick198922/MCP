## Як тестували

- **Стратегія:** «завжди в позиції». На початку вікна купити спот і відкрити шорт перпа HL на ту саму кількість монет, вихід у кінці. Обидві ноги на HL, пари `@142` UBTC/USDC, `@151` UETH/USDC, `@107` HYPE/USDC, `@156` USOL/USDC.
- **Дані:** HL `fundingHistory` (щогодинні фактичні ставки, покриття 100 %), 4h-свічки спота й перпа HL (`candleSnapshot`); Binance: 4h-свічки спота й USDT-M перпа, funding 8h.
- **Вікно:** 2025-10-29 … 2026-10-29, 12 блоків по 365/12 днів. Дохід = сума виплат funding + ціновий P&L хеджу (ΔS − ΔF)/S з 4h-закриттів − витрати. Усе **на номінал**; на капітал (спот + маржа перпа 3x) = номінал / 1.33.
- **Витрати:** HL taker спот 0.070 %, перп 0.045 % на сторону. Проковзування береться з **живих знімків книги** (умова 3): 7 знімків `l2Book` HL і книг Binance 2026-10-29 05:54-06:02 UTC, ордер $10k, медіана. Вийшло 0.0006-0.013 % на ногу, тобто ≈ 0. Коло HL BTC 0.232 %, ETH 0.247 %; Binance 0.30 % (taker 0.10 / 0.05 %). Ребаланс маржі при русі ціни > 20 %.
- **Пороги (зареєстровано):** H1 для BTC і для ETH: net ≥ +6 %, net − T-bill (4.0 %, припущення) ≥ +2 п.п., нижня межа 95 % t-CI блоків > +3 %. H2: обидві половини > 0, max DD базису ≤ 3 %. HYPE і SOL описово.

## Перевірка по активах (5a)

Cochran's Q по 4 активах HL: Q = 21.5, df = 3, I² = 86 %, p < 0.001. Ефект **залежить від активу**: HYPE ≫ BTC ≈ ETH ≫ SOL.

| актив (ранг за 1-ю половиною) | 1-а половина | 2-а половина |
|---|---|---|
| HYPE | +8.6 % | +9.3 % |
| ETH | +4.3 % | +7.1 % |
| BTC | +4.0 % | +6.7 % |
| SOL | −4.0 % | +4.3 % |

Ранг у другій половині зберігся (топ-чверть, HYPE: +9.3 % проти +6.0 % у решти). Але активів лише 4, тож це опис, а не тест стійкості. Можливе пояснення (гіпотеза після факту на 4 активах, не тестувалась): чим більше роздрібного плеча лонг на HL відносно спот-хеджерів, тим вища премія.

## Застереження

- **Проковзування:** колектор пише книги лише перпів HL, історії спот-книги нема. Використано 7 знімків однієї години 2026-10-29. На $10k вплив мізерний, але в стресі (день ліквідацій) спред спота UBTC/UETH може бути на порядки ширшим. Стрес 0.05 % позначено як припущення.
- **Ціни:** 4h-закриття спота HL — це остання угода. Один бар у вікні (BTC, 2026-07-08) мав |базис| > 1 %. Фільтр |базис| ≤ 2 % дає ті самі числа.
- **T-bill 4.0 %** — фіксоване припущення, не виміряне. При 3.6 % надлишок ETH становив би +2.1 п.п., але net < 6 % однаково не проходить.
- **Не змодельовано:** ризик моста Unit (UBTC/UETH — обгортки), ADL прибуткового шорта, ліквідація шорта на сквізі без поповнення маржі (смуга 20 % при плечі 3x), податки, доходність USDC-маржі.
- Одне вікно (12 міс.) з одним режимом; блоки місячні й автокорельовані (бутстреп блоками по 3 дає схожі межі).
