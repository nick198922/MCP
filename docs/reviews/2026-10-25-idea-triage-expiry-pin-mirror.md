## Знахідки

1. **Середня.** SD Δ у картці (0.02) занижена. Δ = 2·clip(x, −d, +d), x = добовий рух (SD ≈ 2.5 %), d = |K*−S0|/S0 ≈ 1-4 %; SD Δ ≈ 0.03-0.04. З n ≈ 1 400 після фільтра 0.5-6 % MDE(H1) ≈ 0.0022-0.003, не 0.0014. Виправлення: G3 з емпіричної SD і SE бутстрепу по тижнях, ворота MDE ≤ 0.003, інакше `inconclusive` (умова 1).
2. **Середня.** Поріг 0.0015 по середньому Δ змішаний з дрейфом: для K* вище спота бичий дрейф (+0.05-0.1 %/добу) дає Δ ≈ +0.1-0.2 % без жодного пінінгу. Плацебо D−1 згадане, але не є основною статистикою. Виправлення: основна статистика = Δ − Δ плацебо або Δ, демінована по стороні; звіт показує сторони окремо (умова 2).
3. **Низька.** Критерій «вбити» (CI_hi < 0.0015) при MDE 0.0022+ майже недосяжний, тож при нулі вийде `inconclusive`. Уточнено в умові 1; додано стійку пару (частка settle ближче до K*, медіана Δ) як описову (умова 3).
4. **Зауваження до чесності.** Пінінг на p дає Δ = 2p, тобто картка очікує p = 0.05-0.15 %, а текст говорить «0.1-0.3 % спота» про зміщення. Реєстрація має однозначно зафіксувати, у чому вимірюється поріг (Δ, не p).
5. **Цінність.** Торгова версія (3-4 ноги × ≈ 0.16 %) мертва за конструкції; цінність лише знаннєва (позначити `deribit_max_pain`/GEX-рівні). Ймовірність 10-15 % брутто. Вартість мінімальна, тому приймаю.

## Умови (також у картці)
1. G3 з емпіричної SD Δ і кластерного бутстрепу; MDE(H1) ≤ 0.003, інакше `inconclusive`.
2. Основна статистика демінована (плацебо D−1 / сторона K*); обидві сторони показати.
3. Поріг 0.0015 і межі 0.5-6 % фіксуються до перегляду Δ; додати непараметричну частку.
4. H2/H3 розвідувальні, якщо ворота не пройдено; без пошуку підгруп.
5. Крок 2 лише за H2 ✓ і нетто > 0.
