# 28.11: гальмо «лише картки власника» діє й нижче 80 %

- Причина: `scripts/nightly_agents.sh` додавав примітку BUDGET для режиму «випереджаємо графік» лише тоді, коли в промпті ще немає слова `BUDGET:`, а воно завжди є в `.claude/nightly.md`. Нижче 80 % тижня координатор примітки не бачив, хоча цикл писав у лог «taking only those».
- Наслідок: 27–28.11 агенти брали пункти постійної картки («Темп: за графіком») у режимі «лише картки власника»; на прогони з цією карткою пішло ≈ 18 пунктів тижневого ліміту (за приростами в `history.tsv`, тиждень 55 % → 78 %).
- Виправлено: `elif` замість пошуку в тексті промпту.
- Простій у цьому режимі тепер триває 3 год замість 30 хв (`TRADEDESK_AGENTS_OWNER_IDLE_WAIT_SECONDS`), бо порожній прогін витрачає резерв власника; раніше — після злиття гілки агентів, нової картки чи відповіді на `main` або ввімкнення буста.
- Дозволи агентам лише на читання: `git -c core.quotepath=false status`, `git check-attr`, `systemctl status tradedesk-mcp`, `journalctl -u tradedesk-update`.
- Тест `tests/test_agents_budget_note.py` (на старій умові падає).
