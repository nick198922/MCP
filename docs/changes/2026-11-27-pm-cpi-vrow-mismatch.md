# 27.11.2026 — pm-cpi: рядок V / σ_A, який команди п. 10 не відтворюють, = `mismatch` (пункт 492)

Пункт 492 [постійної картки](../ideas/IDEA-20261102-standing-improvements.md): R2 повторного [рев'ю C пункту 484](../reviews/2026-11-27-pm-cpi-forward-scanner.md) і незаблокувальне 2 повторного [рев'ю C пункту 490](../reviews/2026-11-27-pm-cpi-proof-hardening.md); раунд правок за [рев'ю C пункту 492](../reviews/2026-11-27-pm-cpi-vrow-mismatch.md). Злити до 21:00 UTC дня T−3 релізу січня 2027; за п. 9 діє з першого релізу, чий M0 це містить.

## Що змінилось
- **Доказ (`--stage proof`).** Перебудова дерева M0 віддає нове поле `vrows`: рядки журналу, на яких стоїть σ релізу (`vrows_used`). Це перші рядки V1 і V2 і перший σ_A, але лише коли обидва V — `pass`. Доказ повторює для них команди п. 10 скриптом `verify_pm_cpi_step0.py` **дерева M0** (`vrows_repro`): експортує потрібні рядки 03.12, 09.12, 11.12 з БД (`mode=ro`), запускає `vcheck` для V1 (S проти 03.12, сходинка 2026-11) і V2 (09.12 проти 11.12) та `sigma` на 11.12. Рядок, який дані спростовують, дає `proof fail: mismatch (V / sigma_A lines: …)`.
- **Вердикт даних і збій середовища (рев'ю C, блокери 1, 2).** Вердикт дають лише розпізнані кінці на прочитаних даних: `NO ROW`, `NOT exported`, `V pass` (код 0), `V fail:` з причиною `vintage_why`, `JSONDecodeError` копії чи винятком структури (код 1), рядок `sigma` з n > 0 (код 0). Решта — `not recomputed (V / sigma_A lines: <рядок>: <причина>; run the proof again)`: `cannot read pm_cpi_snapshot`, експорт без рядка про файл, S відсутній чи з іншим sha256 (`V1_OLDER_SHA256`, `v1_older_why`), падіння, вбитий процес, таймаут 600 с, `n 0` / `sigma_A None` (HTML чи порожній CSV FRED), будь-що нерозпізнане. Такий прогін `proof pass` не дає ніколи й не рахується; якщо до звіту оцінки рядок так і не відтворено — «пропуск T−3 (mismatch)» (лише суворіше). Розбіжність іншого рядка лишається `mismatch`.
- **Дрібні (пп. 3–8).** Кожен прогін має свій каталог `tmp/pm_cpi_vrows_<випадкове>/` разом із кешем FRED (п. 3). Виняток звірки дає `not recomputed (… raised …)` і не прибирає інших причин доказу (п. 4). Рядок `sigma_A` з більш ніж 4 знаками — `mismatch` (п. 8). Текст реєстрації: п. 7 (8) — доказу для 2027 року потрібні файли S, а FRED після N2 не потрібен (п. 5); у п. 8 (1) коміт перейменовано на Mσ, `sigma_for` — коду M0 цього релізу (п. 6); у п. 4 записано, що команди виконує код M0 кожного релізу, а зміна їхніх функцій після 485 — зміна реєстрації за п. 9 (п. 7).
- **Хто її знає.** Нема `vrows` у відповіді (M0 старший за пункт 492) — звірка не застосовується (`not applicable, M0 before item 492`). `vrows`, що не є словником рядків, — `mismatch`.
- **10.12 не зачеплено.** Для `FIRST_RELEASE` поле `vrows` порожнє, жодна команда не виконується, у виводі доказу лише додатковий рядок `V / sigma_A lines: none used`. `T-3.json`, `REBUILT`, `T3_KEYS`, `CODE_PATHS` і команди етапів не змінились; `sigma_for` переписано через спільний `journal_vrows` без зміни поведінки.
- **Другий раунд (повторне рев'ю C, N1).** Нова команда для кроків 485 / 488, лише читання: `scripts/pm_cpi_forward.py --stage vrows --line V1 | V2 | sigma_A` (`vrows_stage`). Вона запускає команди п. 10 тим самим класифікатором, що й доказ (`vrows_repro`). Код 0 означає вердикт даних, і тоді після `journal line …` друкується рядок журналу. Код 3 означає «нічого не писати»: останній рядок `<рядок>: write nothing …` каже, чи повторювати. Код 3 буває раніше за 03.12 / 11.12 21:05 UTC (`V_FROM`; з третього раунду 22:00, Т3), коли рядок цього виду вже є в картці, коли для σ_A рядки V1 / V2 картки не обидва `pass`, на будь-якому кінці «не відтворено» і на винятку. Тексти кроків 485 і 488 доповнено командами; до злиття 492 кроки чекають.
- **`sigma_for` (N1, лише суворіше).** Якщо в M0 бракує рядка V1 чи V2, реліз — «no sigma_A», навіть коли другий рядок `fail` (раніше в цьому разі було 0.164). Так код збігся зі своїм докстрингом і з уточненням пункту 484 у п. 4 (а). `vrows_used` у такому разі порожній.
- **Дзеркальний випадок N1.** Експорт `--stage row --export` тепер іде першим, до описових рядків. Блоб, що не розпаковується (`zlib.error`), дає `NOT exported … do not decompress`, тобто `fail` за даними. `cannot read a copy (UnicodeDecodeError …)` теж вважається вердиктом даних.
- **N2.** Крок 488 (`--line sigma_A`) зберігає прочитаний CSV FRED як `docs/forward/pm-cpi/fred/CPIAUCNS_<YYYYMMDD>.csv` (`x`; ті самі байти лишає, інші — код 3). Рядок має вигляд `sigma_A · <σ> · n <n> · sha256 nowcast <…> · CSV CPIAUCNS_<YYYYMMDD>.csv sha256 <…>`. Доказ (`vrows_check`, аргумент `ref`) бере файл з `origin/main`, звіряє sha256 і запускає `sigma … --vintage` без мережі (новий аргумент `--vintage` у `verify_pm_cpi_step0.py`). Рядок без sha256 CSV або з іншим sha256 дає `mismatch`. Якщо файлу в `origin/main` нема, результат — `not recomputed`. Розташування не зачіпає тестів-охоронців: `docs/` не перезапускає службу (`test_restart_needed`), `git check-ignore` файл не ігнорує, `.gitattributes` нема (байти не перекодовуються), `docs_paths` шаблон `<YYYYMMDD>` пропускає.
- **N3 (текст, п. 4 (д)).** Рішення ухвалюється для рядка: перший прогін, що вирішив рядок, вирішує його для всіх релізів. Звіт оцінки виконує звірку один раз для всіх рядків, що лишились `not recomputed`, і описово звіряє рівні збереженого CSV із FRED.
- **Третій раунд (третє рев'ю C, Т1–Т6).**
  - **Т1, блокер: охоронець рядка σ_A.** Тест `test_the_real_card_keeps_its_sigma_a_line_whole_and_its_csv_tracked` читає справжню картку з дерева, мережі не потребує. Без рядка σ_A він проходить. Коли перший рядок σ_A є, тест вимагає, щоб розбиралися ім'я CSV і повний sha256 (64 hex), файл `docs/forward/pm-cpi/fred/CPIAUCNS_<d>.csv` був і в дереві, і в індексі git з тим самим sha256, σ мало не більше 4 знаків, а перші рядки V1 і V2 були `pass`. Падає він і на спробі рядка V / σ_A, якої сканер не розбирає (інший префікс чи розмітка, дата не `YYYY-MM-DD`, перенесений рядок, `σ_A`, `sigma_A:`, `v2`, `V1 —`). Текст формату в картці й рядки етапів, що згадують `sigma_A` як джерело чи причину пропуску, тест не чіпає. Через перевірку індексу забутий `git add` ловить уже локальний `make test` доставки (`deliver` у `scripts/agents_deliver.sh` тоді гілку не пушить), а не лише CI.
