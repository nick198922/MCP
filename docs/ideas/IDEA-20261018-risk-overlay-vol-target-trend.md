## Механізм
- **Хто платить (H1, таргетування волатильності):** інвестори з постійною експозицією (або з обмеженим плечем) тримають повний ризик у періоди, коли волатильність висока, а очікувана дохідність на одиницю ризику не вища (Moreira–Muir: зміни волатильності не супроводжуються пропорційними змінами очікуваної дохідності). Дохід — це уникнення кластерів великої воли (березень 2020, травень 2021, 2022), а не «передбачення напрямку». Волатильність кластеризується надійно — це найстійкіший факт у цінових рядах.
- **Хто платить (H2, тренд):** недореакція на інформацію/увагу роздрібного капіталу, повільний рух інституційного капіталу, крипто-ринки без короткого тримання для більшості. Тренд-слідування заробляє на ведмежих фазах як страхування, тобто втрачаємо трохи в боковиках.
- **Що зламає:** зміна режиму (ETF-ера зменшила амплітуду циклів, 2024–26), різкі V-розвороти (трендовий фільтр запізнюється), гепи.

## Гіпотеза
Реєструється до даних. Усі правила — ваги на добу t використовують лише дані до закриття t−1.
- **H1:** `w_t = clip(σ*/σ̂_t, 0, 1.5)`, σ̂ = EWMA(λ=0.94) денної воли, σ* = вола купівлі-й-тримання за вибірку (щоб середня експозиція ≈ 1). Різниця річного Sharpe «керований мінус купівля-й-тримання» ΔSR > 0, 95 % CI (парний блоковий бутстреп, блок 20 діб) нижче нуля не заходить, на BTC 2014-01…2026-09 і окремо на ETH 2018…2026-09.
- **H2:** довго/кеш за ансамблем Donchian (20, 50, 100, 200 діб; вага = частка каналів вгору), ваги розмірено σ*/σ̂. Критерій той самий: ΔSR > 0 і додатково `MaxDD(H2) ≤ 0.7 × MaxDD(BH)` (описово).
- **H3:** H1 × H2 (комбінація); розвідувально, вердикт не за нею.
- Очікування (гіпотеза з літератури, НЕ факт): ΔSR ≈ +0.2…+0.3; MaxDD −25…−40 % відносно BH.
- OOS: остання чверть (2023-01…2026-09) — знак ΔSR той самий. Holm по H1, H2 у картці.

**Сигнали** (на даних до close доби d включно; r_d = ln(C_d / C_{d−1}))
- σ̂_d — EWMA RiskMetrics: v_d = λ·v_{d−1} + (1−λ)·r_d², λ = 0.94. Старт: v = середнє r² перших 20 дохідностей. σ̂ = √(365·v).
- σ*_d — ковзна реалізована вола за останні 365 дохідностей до d (мінімум 200), × √365.
  - Відхилення від варіанта (б) критика (розширюване вікно): розширюване σ* залежить від того, з якої дати почато дані. Якщо додати 2011–2013 з волою понад 100 %, ваги роками стоять на капі. Ковзне вікно так само використовує лише дані до t−1, тож заглядання вперед нема.
  - Варіант (б) з розширюваним вікном зареєстровано як стійкість (нижче). Вибір зроблено до даних.
- **H1:** s1_d = clip(σ*_d / σ̂_d, 0, **1.0**). Кап 1.0, спот, без плеча.
- **H2** (за карткою: ансамбль Donchian, розмірений волою). Для кожного n ∈ {20, 50, 100, 200}: стан_n = 1, якщо C_d > max(C_{d−n…d−1}); стан_n = 0, якщо C_d < min(C_{d−n…d−1}); інакше стан лишається попереднім (на старті 0). f_d = середнє станів. s2_d = f_d · s1_d.
- **H2-raw:** s2r_d = f_d, лише тренд без воли.
- **H3:** у формулюванні картки (H1 × H2) вола множилася б двічі, тож H3 = H2 і окремо не рахується. Описово порівнюються H2-raw і H2. Обидва описові (умова 5 критика).

**Виконання і витрати**
- Позиція на добу j (дохідність R_j = C_j / C_{j−1} − 1): w_j = s_{j−2}. Сигнал відомий на close j−2, а виконується на close j−1, тобто через 24 год, пізніше за «відкриття + 1 год». Це консервативніше за умову 4.
- Чиста дохідність на капітал: P_j = w_j·R_j − fee·|w_j − w̃_{j−1}|, де w̃ — вага після дрейфу: w̃ = w(1+R)/(1+wR).
- fee = 0.10 % на одиницю обороту споту. Кеш без відсотків. Ребаланс щодоби, без смуги.
- Позиція відкривається з нуля на першу добу оцінки, з витратами.
- Бенчмарк C: стала вага c = середнє w_j стратегії за період оцінки, щодобовий ребаланс, ті самі витрати. Бенчмарк BH: вага 1, без витрат.
- Усі дохідності — на капітал, спот без плеча.

**Головні кінцеві точки (H1, окремо BTC і ETH; Holm по 4 точках, α = 0.05)**
- T1 = CVaR5(C) − CVaR5(H1). CVaR5 = −середнє ceil(5 % n) найгірших календарних місячних чистих дохідностей. T1 > 0 означає тонший лівий хвіст у H1.
- T2 = MaxDD(C) − MaxDD(H1) на денних кривих капіталу. MaxDD — частка (0.5 = −50 %).
- CI і p:
  - для T1 — парний бутстреп рухомими блоками місяців (блок 3, 2000 повторів);
  - для T2 — парний бутстреп рухомими блоками діб (блок 20, 2000 повторів);
  - seed 20261018; одностороннє p = (1 + #{T* ≤ 0}) / (1 + 2000).
- Плацебо: 1000 перестановок 60-денних блоків ряду ваг H1 у межах періоду оцінки, з тим самим c. p_pl = (1 + #{T_pl ≥ T}) / 1001.
- OOS: T1 > 0 і T2 > 0 в останній чверті.
- **Вердикт H1 по активу:**
  - ✓ — T1 і T2 проходять Holm, p_pl ≤ 0.05 для обох, обидві > 0 в OOS;
  - ≈ — хоча б одна проходить Holm, але не виконано решту умов;

**Друга кінцева точка: дохідність**
- ΔSR = SR(H1) − SR(C), де SR = mean(P) / sd(P) · √365. CI — бутстреп блоками діб (20, 2000).
- MDE = 2.8 · SE рахується на стадії 0, наосліп: точкова оцінка не друкується. Якщо MDE > 0.30, ΔSR описова: **◯** («тест дохідність не розрізняє»).
- Якщо MDE ≤ 0.30:
  - ✓ — нижня межа CI > 0, OOS того самого знака, p_pl ≤ 0.05;
  - ✗ — CI включає 0 і точкова оцінка < +0.1 (критерій (а) картки) або OOS протилежного знака;
  - ≈ — інакше.
- Пул BTC+ETH: середнє двох ΔSR на спільних добах, спільний бутстреп.
