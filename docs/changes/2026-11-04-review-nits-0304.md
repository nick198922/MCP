# 2026-11-04 — відкладені зауваження рев'ю 03–04.11

Постійна картка `IDEA-20261102-standing-improvements`, п. 50. Переглянуто всі рев'ю `docs/reviews/2026-11-03-*` і `2026-11-04-*` з approve; кожного кандидата перед роботою звірено з кодом.

## Виправлено (з тестом на кожне)

- **H7″: стадія `full` більше не довіряє будь-якому `stage0.json`** ([рев'ю](../reviews/2026-11-03-pm-h7-qlike.md), знахідка 4). `scripts/verify_pm_h7_qlike.py`: стадія 0 записує `cutoff` копії БД; `full` порівнює `cutoff` і кількість рядків воріт з поточною копією (`stale_gate`) ще до завантаження будь-якого бару тестового періоду. Якщо копію оновили (`--refresh-db`) або файл воріт старий, без `cutoff`, стадія відмовляє й просить перезапустити стадію 0. Раніше повторний прогін 2027-03-08 міг піти на воротах, порахованих на іншій вибірці. Пороги й реєстрацію 8l не змінено. Тести: `tests/test_verify_pm_h7_qlike.py`. `load_rows` проходить на копії з таблицею `pm_gap_outcome`, кожен доступ до якої заборонено авторизатором sqlite, тож тест упаде, якщо стадія 0 почне її читати. Окремо перевірено: застарілі ворота дають відмову до запиту барів, а ті самі ворота на тій самій копії пропускають до запиту.
- **Охоронець README рахує лише колонку «Інструмент»** ([рев'ю](../reviews/2026-11-04-tool-docs-guard.md), п. 2). `tests/test_tool_docs.py`: раніше зараховувалося ім'я в backticks у будь-якій комірці, тож згадка в описі іншого рядка ховала інструмент без власного рядка. Новий тест на синтетичній таблиці; усі 108 інструментів і далі є в колонці.
- **`backup_db` не створює теку призначення, коли джерела немає** ([рев'ю](../reviews/2026-11-03-scripts-dedup-2.md), п. 1). `scripts/common_helpers.py`: `mkdir` тепер виконується після відкриття джерела. Тест `test_backup_db_missing_source_raises_and_creates_nothing` перевіряє відсутність теки, як і обіцяє його назва.
