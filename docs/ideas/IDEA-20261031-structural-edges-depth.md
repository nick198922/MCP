## Механізм
Цінові патерни (сетапи курсу, сито зі 102 стратегій, 10 паспортів, понад 30 модулів) переваги після витрат не дали: у них немає того, хто систематично платить. Тут він є:
- **carry / funding:** ті, хто тримає плече в бік натовпу, платять funding; ті, хто дає ліквідність базису (довгий спот / короткий перп, або спред funding між біржами), отримують його. Ризик — розворот funding, базис, ліквідація ноги, витрати входу.
- **Polymarket ↔ опціони:** роздрібні учасники Polymarket оцінюють імовірність ціни BTC / ETH інакше, ніж опціонний ринок; розрив, більший за комісії й похибку моделі, — плата за неуважність. Ризик — модель (ризик-нейтральна ймовірність ≠ реальна), ліквідність, розрахунок ринку.
- **премія опціонів:** продавці волатильності отримують премію за страхування (VRP), але з хвостом; тижневий straddle відкинуто за критерієм руїни (`2026-10-15-weekly-straddle-vrp.md`), тож шукати форми з обмеженим ризиком (кондори, спреди, календарі, фільтри за DVOL / IV rank / подіями).

- **Розкладання сторони (точне, сума = фактична вартість реєстрації (б) + час):** (1) комісія taker, як записано (Binance спот 0.10 %, Binance USDT-M 0.05 %, Bybit linear 0.055 %; знижки BNB / maker / USDC не беруться — офіційну таблицю не звірено, рев'ю критика A); (2) половина спреду = (ask − bid) / 2 / mid; (3) удар по глибині = |VWAP − mid| / mid − половина спреду (VWAP — прохід записаної книги на $2 000); (4) час (описово, зі знаком, «+» = на шкоду): купівля (mid − ціна моделі) / ціна моделі, продаж навпаки; ціна моделі — закриття 4h-бару, яким рахують бектест і рушій. Для угоди-сторони (дві ноги) час двох ніг складається (для хеджованої пари це зміна базису між закриттям бару і книгою). Модель зараз: комісія + 0.05 % на ногу.
- **Funding між циклами (на угоду):** різниця між funding, який рушій нарахував (`cp_log` funding, частка номіналу), і сумою ставок з історії біржі (`cp_funding`) за вікно утримання (open, close / останній цикл]; плюс кількість виплат, на які угода була «відкладена» (`funding_payment_missing`). Нарахування в обох бектестах — та сама конвенція, тож очікується ≈ 0; ненуль — окрема стаття витрат.
- **Оновлена модель (основна, зареєстрована):** проковзування ноги = середнє (2)+(3) за типом ноги: спот Binance, перп Binance, перп Bybit (перп Binance — з обох рушіїв разом); комісія — (1). Компонент (4) входить у модель, лише якщо 95 % CI його середнього на угоду-сторону не містить 0; інакше 0 у основній моделі. **Стрес:** проковзування = верхня межа 95 % CI кожного типу ноги (+ |середнє (4)|, якщо воно > 0). Описово: ×2 основної, p90 по сторонах, номінал ×5 ($10 000, той самий прохід книги). У симулятор (`simulate_carry_portfolio` / `simulate_perp_spread_portfolio`, один параметр `slippage` на обидві ноги) передається середнє проковзування двох ніг, що дає ту саму вартість сторони.
- **Перерахунок бектестів:** основні варіанти бенчу без змін правил — A: 5 слотів, ≥ 0.20 / ≤ 0, без стопу; B: 5 слотів, ≥ 0.10 / ≤ 0, розрив ≤ 0.02, стоп 0.50 + штраф 0.01. Для кожного: стара модель, основна, стрес, ×2. Показники: APR на номінал і **на капітал** (A: капітал = 1.5 × номінал, спот + маржа перпа 2x; B: 1.0 × номінал, 2x на кожну ногу), найгірша просадка (на капітал, з кривої 8h-кроку з маркуванням), найгірший календарний тиждень (пн–нд UTC, зміна кривої на капітал), 95 % CI APR — бутстреп блоками по 4 тижні з тижневих приростів кривої (10 000 повторів, seed 20261031). Розбивка IS / OOS: перша й друга половина періоду; без топ-5 символів за P&L.
- **Мінімальні вибірки:** калібрування типу ноги — ≥ 20 сторін і ≥ 8 символів, інакше для цього типу ◯ (тоді він бере середнє наявних сторін як **припущення** з позначкою, а стрес — максимум сторін цього типу).
- **Критерії вердикту:** (В1, В2) «модель витрат занижена» для A / B: ✓ — нижня межа 95 % CI середнього (фактична − модельна) на сторону > 0; ≈ — середнє > 0, CI містить 0; ✗ (модель не занижена) — середнє ≤ 0; ◯ — менше мінімуму. (В3, В4) «carry переживає оновлені витрати» для A / B: ✓ — APR на капітал з основною моделлю має нижню межу CI > 0 **і** APR зі стресом > 0; ≈ — основна > 0, але CI містить 0 або стрес ≤ 0; ✗ — основна ≤ 0. Поріг реєстрації форварду (б) ≤ 1.5× тут лише описово (його вердикт — на чекпоінт 30.11).
- **5a (по активах):** таблиця вартості по символах (n сторін, середнє проковзування) і Cochran's Q / I² гетерогенності між символами; стійкість за 11 днів паперу не перевіряється (немає OOS). Для перерахованих бектестів — частка P&L топ-5 символів і результат без них.
- **Застереження наперед:** книга записується через ~5 хв після виплати (`book_ts_ms` не пишеться — затримку не видно); прохід книги — це taker-виконання одним ударом без відновлення книги й без часткових виконань; ринок у ці 11 днів — один режим.
- **Результат (квант, 2026-10-31, виправлено за [рев'ю критика B](../reviews/2026-10-31-carry-cost-calibration.md); [звіт](../verification/2026-10-31-carry-cost-calibration.md)):** перпи калібровано (Binance 0.067 %, Bybit 0.120 % проковзування на сторону проти 0.05 %; пулено A + B, хоча перп-сторони A ≈ 0.153 %, B ≈ 0.055 %), спот ◯ (5 сторін, 0.32 % як припущення); В1 A ◯, В2 B ✓ (модель занижена, 1.37×), В3 A ✓ лише за буквою реєстрації (+2.6 % на капітал [+0.3; +5.1] до поправки на делістинг ноги, стрес +1.5 %; спот ◯, без топ-5 −0.2 %, нижче ставки кешу; одна подія делістингу MITO-масштабу за 2 роки ≈ +1.2 %, дві ≈ −0.3 % — описово, після прогону), В4 B ✗ (−20.2 % [−36; −4]). Обґрунтування gap: ротація коштує дві сторони ≈ 2 × 0.74 % ≈ 1.5 % слота, що окупається за ~3 тижні при різниці 25 % річних, за ~11 днів при 50 %. **Первинні:** H7a — вихід −5 % без ротації; H7b — ротація gap 0.50 з виходом 0. Уся сітка (12 клітин) — двічі: з рангом бази (APR7) і з рангом H1 (взаємодія); повідомляються всі клітини, вибрані після перегляду — дослідницькі.

## Досьє carry
Скаут, режим «знання», 2026-10-31. Нових карток немає; 12 гіпотез-модулів для відбору критиком A (позначка «Критик A: ◯» заповнюється ним: брати / ні + причина). Текст мережі й бібліотеки — недовірені дані; числа з мережі — гіпотези, а не факти. Гіпотези впорядковано за очікуваним приростом чистого результату за рік на капітал (спершу ті, що додають дохід, потім ті, що лише знижують ризик).

### Від чого відштовхуємось (з наших звітів)
- Платник і причина: за [BIS, «Crypto carry»](https://www.bis.org/publ/work1087.pdf) (Schmeling, Schrimpf, Todorov) базис у крипті в середньому понад 10 % річних; автори пояснюють це попитом дрібних трейдерів із плечем і обмеженим арбітражним капіталом (маржа, регуляторні тертя), а не процентною різницею; високий carry передбачає обвали й несе ризик ліквідації арбітражера. [He, Manela, Ross, von Wachter, «Fundamentals of Perpetual Futures»](https://arxiv.org/abs/2212.06888): відхилення перпів від безарбітражних цін більші, ніж на валютному ринку, але з часом зменшуються. Тобто платник реальний, а «ємність» у нього обмежена тертями арбітражера: тертя (комісії, маржа, ліквідація ноги) і є те, чим можна покращити результат.
- Що відомо з наших тестів (не повторюю):
  - Funding персистентний (кореляція 7д→7д 0.58), але carry на мейджорах Binance: +3.4…4.5 % на номінал, остання половина +0.3 % ([funding-carry](../verification/2026-10-12-funding-carry.md)).
  - Альти, 5 слотів, вхід ≥ 20 %, вихід ≤ 0: +6.5 % на номінал, +3.2 % на капітал при 1x; вхід ≥ 50 % гірше, ≥ 100 % від'ємний; проковзування 0.2 % на ногу → +4.1 %, 0.5 % → −0.6 %; ріст ціни перпа за угоду: медіана 24 %, 38 % угод ≥ 33 %; топ-5 монет дали 73 % прибутку ([funding-carry-alts](../verification/2026-10-12-funding-carry-alts.md)).
  - Перп-перп B на повній історії funding: −8.7 % (основний), +2.9 % без стопу; бенч заморожено, A відтворено (+6.5 %) ([paper-carry-bench](../verification/2026-10-17-paper-carry-bench.md)).
  - HL спот-перп: BTC +5.3 %, ETH +5.7 % на номінал (≈ T-bill на капітал), HYPE +8.9 %, HL над Binance +2.4…3.9 п.п., уся різниця з funding ([hl-spot-perp-carry](../verification/2026-10-29-hl-spot-perp-carry.md)).
  - COIN-M проти USDT-M: на BTC/ETH різниці немає (+0.16 п.п.), на альтах крихко ([coinm-vs-usdtm](../verification/2026-10-25-coinm-vs-usdtm-funding-carry.md)).
  - Датований базис Deribit: d = +1.25 п.п. [−1.86; +4.35], ворота не пройдено; календар ≈ 0 після витрат; dated cash-and-carry +6.2 % на капітал, останній рік 2.7 % ([dated-basis](../verification/2026-10-14-dated-basis.md)).
  - Закрито: вхід на одну виплату (ціна забирає funding, [settlement-window](../verification/2026-10-20-funding-settlement-window.md)); HL↔Binance 7-денний спред −0.32 % ([hl-binance-spread](../verification/2026-10-15-hl-binance-funding-spread.md)); кошик за переповненістю, IC ≈ 0 ([funding-crowding](../verification/2026-10-15-funding-crowding-longshort.md)); USDe як випереджальний сигнал ([ethena-usde](../verification/2026-10-25-ethena-usde-supply-funding-regime.md)); скорочення інтервалу: брак потужності ([interval-cut](../verification/2026-10-25-funding-interval-cut-stress.md)).
- Потужність: carry оцінюється по днях/тижнях/угодах, а не по тисячах незалежних подій. Альт-A: 42 угоди за 2 роки, SD блоків HL ≈ 3 п.п. Тому приріст ≲ 1.5 п.п. річних на номінал за 2 роки історії майже не розпізнати; модулі нижче, де це так, позначені «потужність низька» і задумані як порівняння симуляцій на тих самих даних (парні різниці з бутстрепом по тижнях), а не як окремі тести.

### Тип: вибір інструментів

Умова: перерахунок з комісіями Bybit і ліміт-розмірами ноги; якщо спот-історії Bybit нема, модуль знімається, а не добудовується.

**H3. Реверс-carry (лонг перп + шорт спот через маржинальну позику) на монетах зі стійким від'ємним funding.**
- Зміна: коли символ стійко (≥ 3 доби) платить від'ємний funding вище вартості позики, відкривати дзеркальну пару: шорти платять лонгам, ми лонг перпа і шорт спота (позика). Додає угоди в режимі, коли звичайний carry на нулі.
- Механізм: від'ємний funding — це натовп шортів (паніка, делеверидж), що платить лонгам; ліквідність дає той, хто бере протилежний бік. Ціна цієї ноги — ставка позики монети (на дрібних альтах часто вище funding, і позика лімітована). Дзеркальна вигода з боку Ethena: стрес-періоди, коли USDe-стиль carry зникає ([Ethena FAQ](https://docs.ethena.fi/resources/faq) попереджає про тривалий від'ємний funding).
- Джерело: [Kraken, funding rate arbitrage](https://www.kraken.com/gb/learn/futures-trading-funding-rate-arbitrage) (реверс-пара, ризик перевороту знаку); наш звіт про скорочення інтервалу (208 подій, ставка на нижньому ліміті −2 %); [funding-carry](../verification/2026-10-12-funding-carry.md) (вихід при ≤ 0).
- Виміряти: епізоди від'ємного funding — кеш `funding_crowding/` (678 символів). **Історії ставки позики немає**: Bybit публічний `spot-margin-trade/data`, Binance `margin/interestRateHistory` (підпис), тому потрібен колектор погодинних ставок позики для монет з епізодами; до того — лише оцінка «funding мінус гіпотетична позика 10/20/40 % річних» як поріг прийнятності. Звіт будуємо як чутливість, не як вердикт.
- Тип: вибір інструментів. Перевірено: ні. Очікування: низьке (5–10 %), бо позика дрібних альтів дорога й обмежена; значення — у перевірці, чи вікно існує.
- Критик A: **ні.** Нема історії ставки позики, результат буде чутливістю до припущення; дрібні альти не позичаються; очікування 5–10 %. Не форвард-кандидат без колектора ставок (нова робота).

### Тип: розмір і капітал

**H4. Спот як застава перпа (портфельна / уніфікована маржа): капітал ≈ номінал замість номінал × (1 + 1/плече).**
- Зміна: не міняє валовий дохід, а зменшує капітал, на який він ділиться. Тепер звіти ділять на 1.33…2 номіналу (альти: 6.5 % на номінал = +3.2 % при 1x). Якщо спот зараховується заставою перп-шорта, капітал ≈ номінал, і ті самі 6.5 % дають ближче до 6.5 % на капітал: ≈ +3 п.п. річних на капітал. Інша форма: плече 2x на перпі й менший буфер.
- Механізм: плата не за альфу, а за вартість капіталу: «регуляторні й маржові тертя» обмежують арбітражні гроші (BIS). Binance Portfolio Margin і Bybit UTA оцінюють ризик пари разом (за описом бірж; точні коефіцієнти застави/haircut — перевірити на офіційних сторінках: наш пошук знайшов суперечливі описи для зарахування BTC-споту на Bybit, а поріг входу в PM Binance у сторонній статті — 100 000 USDT, застарілий).
- Джерело: [Binance Portfolio Margin](https://www.binance.com/portfolio-margin), [Bybit UTA](https://www.bybit.com/en/learn/bybit-uta/uta-improves-capital-efficiency); наш HL-звіт (рядок «з кращою маржею» дає 5.3/5.7 %, висновок про T-bill не змінює); BIS.
- Виміряти: `analytics/carry.py` — додати модель капіталу «зарахований спот» (haircut h, буфер b) і перерахувати результати A на капітал; ризик-ліміти Bybit є у `docs/paper/ladder/2026-10-17-bybit.json`; для Binance коефіцієнти застави — збір вручну (власник: чи доступний PM / Multi-Assets на його рахунку). Історія: **так** (це бухгалтерія, не нові дані). Ризики: ADL закриває прибуткову ногу; падіння застави на спот-ногу при стрибку ціни підвищує ризик ліквідації перпа (шорт піднімає маржу, спот знецінюється в тому ж напрямку, що мало ризику для шорта, але haircut зростає у стресі).
- Тип: розмір / хедж. Перевірено: частково (HL-звіт підрахував лише BTC/ETH). Прирісту до валового немає, тому це найдешевший модуль із найбільшим очікуваним ефектом на *капітал*; тест — розрахунковий, потужність не потрібна.
- Критик A: **брати** (модуль 2, найвищий очікуваний ефект на капітал). Умови: haircut і буфер — з офіційних таблиць Bybit/Binance (не зі сторонніх статей), показати чутливість до h ∈ {0, 10, 25 %}; обов'язково стрес «+25 % ціна перпа / −X % застава» і найгірший тиждень; чи доступний PM / UTA власнику — вказати як припущення, питання у QUESTIONS не створювати до результату. Це не альфа: звіт має чітко розділяти «менше капіталу» і «більше доходу».

**H5. Розмір слота за ризиком стиску ноги (OI / обіг спота, вік листингу, ліміт позиції) замість рівних слотів, плюс правило долиття маржі.**
- Зміна: вага слота ∝ 1/(очікувана максимальна несприятлива екскурсія), а не 1/5; фіксоване правило долиття (повернення до плеча 1.5x, коли ціна перпа +25 %). Угод стільки ж; змінюється розподіл капіталу й імовірність ліквідації шорта без долиття.
- Механізм: шорт ноги дають збиток від стиску: 38 % угод ≥ +33 %, 21 % ≥ +100 % (звіт альтів), а після ліквідації хедж стає голим лонгом. BIS: carry несе ризик ліквідації і передує обвалам. Стиск найімовірніший, коли відкритий інтерес великий щодо вільного обігу (малий float) — це гіпотеза, не факт.
- Джерело: [BIS](https://www.bis.org/publ/work1087.pdf); наші звіти (альти, перп-перп). Прямих досліджень OI/обіг → стиск не знайшов; маркувати як нетестовану ідею.
- Виміряти: для кожної угоди A (42) і сітки кандидатів: ознаки на вході — OI(USD)/обіг спота за 7д (архів `metrics` OI для 28 монет повністю, для решти `um_metrics_ratios_daily`), вік листингу, ліміт позиції (знімок Bybit); ціль — MAE за 4h-хаями. Регресія/ранговий зв'язок ознака → MAE; потім розмір слота ∝ обернена передбачена MAE і порівняння дохідності на капітал з рівними слотами (парно). Потужність низька (42 угоди); розширити пулом усіх «кандидатських» епізодів (≥ 20 % APR тривалістю ≥ 3 доби), їх сотні.
- Тип: розмір / хедж. Перевірено: MAE описано, предикторів MAE не шукали.
- Критик A: **ні.** Знижує ризик, а не додає дохід; гіпотеза OI/float → стиск без джерела; 42 угоди, ознаки підбираються під MAE (форкінг); долиття маржі вимагає моделі ліквідації, якої нема. Повернутись, якщо H4 покаже, що ліквідація ноги вирішальна.

**H6. Режимна ємність: кількість слотів/капітал за «шириною» funding, а решта капіталу — у безризиковій ставці або yield-активі.**
- Зміна: ширина = частка топ-N перпів із 30д funding вище бази. Широко — 5 слотів; вузько — 0–2 слоти, решта в T-bill / sUSDe-класі. Не відкидає угоди, а розподіляє капітал між carry і безризиковою ставкою (тепер carry на мейджорах «в ринку» 9 % часу в останній половині).
- Механізм: при низькому funding carry нижчий за безризикову ставку (HL: ≈ T-bill 4 % на капітал); платить натовп із плечем лише тоді, коли він є (BIS), тож ємність цієї премії змінна.
- Джерело: [BIS](https://www.bis.org/publ/work1087.pdf); [BitMEX Q3 2025](https://www.bitmex.com/blog/2025q3-derivatives-report) (за зведенням пошуку: funding додатний у понад 92 % Q3 2025, прив'язаний до бази 0.01 %/8 год; сторінка не відкрилась, цифра не перевірена); наші звіти (режимна залежність: 6.5 % → 0.3 % на мейджорах).
- Виміряти: ряд ширини з кешу `funding_crowding/` (678 символів, 2021-10…); зв'язок ширини(t) з доходом carry(t+1…t+4 тижні) на 265 альтах. Історія є, але *незалежних режимів* ≈ 4–6 за 5 років, потужність низька; мета — описова карта режиму + правило розподілу капіталу, перевірене на двох половинах, не окремий вердикт. USDe-частка й кошик переповненості вже не дали сигналу ([ethena-usde](../verification/2026-10-25-ethena-usde-supply-funding-regime.md), [funding-crowding](../verification/2026-10-15-funding-crowding-longshort.md)); це інша змінна (ширина, а не USDe/ціна).
- Тип: розмір / контекст. Перевірено: ні.
- Критик A: **ні.** 4–6 незалежних режимів за 5 років: MDE нескінченний, результат — розповідь; сусідні змінні (USDe, переповненість) уже дали нуль; «T-bill» як альтернатива — не модуль, а арифметика. Джерело BitMEX не відкрилось, цифру 92 % не використовувати.

### Тип: вхід / вихід

**H7. Утримання через короткі провали: поріг виходу нижче нуля та правило «замінити слот, лише якщо кандидат кращий за поточний на вартість обороту».**
- Зміна: тепер вихід при trailing 7д APR ≤ 0 (кращий за ≤ 5, звіт мейджорів) і кожні 8 год слот може бути замінений кращим. Тестується сітка виходу {0, −5, −10 %} і гістерезис ротації (замінювати, лише якщо APR_кандидата − APR_поточного > поріг, що окупає 0.35…0.65 % кругового обороту за очікуваний час утримання).
- Механізм: вартість кругового обороту ≈ 0.35…0.65 % (альти) проти funding кількох днів; короткі провали trailing APR нижче нуля розвертаються (персистентність 0.58), і вихід + повторний вхід платить комісії двічі за провал. Оборотні витрати — найпрозоріший канал втрат (3d ≥ 5 %: 13.6 угод на рік, комісії −4.1 %).
- Джерело: наші звіти (мейджори: короткі вікна / гістерезис; альти: проковзування); теорія — оптимальна зупинка з фіксованою вартістю переходу (стандарт, без специфічного посилання).
- Виміряти: `simulate_carry_portfolio`, сітка за двома параметрами, ті самі дані, що H1; виходи рахувати на *вже зафіксованій* в звіті моделі витрат (після пункту 2 — на оновленій). Дві зміни, Холм на 2. Угод стає менше, але капітал працює довше — дивитися дохід на капітал за рік, а не кількість угод.
- Тип: вхід / вихід. Перевірено: лише ≤ 0 проти ≤ 5 на мейджорах ([funding-carry](../verification/2026-10-12-funding-carry.md)); від'ємні пороги й ротацію з гістерезисом — ні. Потужність низька.
- Критик A: **брати** (модуль 3). Оборот — найпрозоріший канал втрат (комісії −4.1 % на рік), зміна додає чистий дохід. Умови: сітка з 2 параметрів фіксується в реєстрації до прогону, Холм враховує H1, H7 і H4 разом; тестувати і окремо, і разом з H1 (взаємодія), на моделі витрат пункту 2 (не 0.1/0.05).

**H8. Вхід, коли перп торгується з премією до спота (захоплення конвергенції), і вихід по розпаду премії.**
- Зміна: до правила «APR ≥ 20 %» додати умову входу: поточна премія mark − index ≥ x б.п. (напр. 30 б.п.), лімітним ордером на перпі; вихід частково при премії ≤ 0. Якщо шорт-нога відкрита при завищеній премії, ціновий P&L хеджу додатний, коли премія повертається.
- Механізм: премія — наслідок плечевого попиту на лонг; арбітражер, що відкриває шорт на піку премії, купує базис дешевше за середній вхід. Безумовний ціновий P&L ≈ 0 ([funding-carry](../verification/2026-10-12-funding-carry.md)), але умовний на премії вході не вимірювали. He et al.: відхилення від безарбітражних цін великі й спільні для монет.
- Джерело: [He, Manela, Ross, von Wachter](https://arxiv.org/abs/2212.06888); [Binance, формула](https://www.binance.com/en/support/faq/introduction-to-binance-futures-funding-rates-360033525031) (funding = середня премія + clamp, тобто премія і funding пов'язані механічно — **ризик подвійного обліку з H1**: дивитися приріст понад APR, а не замість).
- Виміряти: 1m `premiumIndexKlines` (архів Binance, вже використаний у settlement-window, 2024-01…2026-09, лише для днів із |funding| ≥ 0.10 % — для загального відбору довантажувати) + 4h-ціни споту й перпа; для кожної угоди A розкласти дохід на funding і ціновий P&L за премією входу (терцилі). Простий звіт-розбивка, не окремий тест; MDE оцінити після підрахунку.
- Тип: вхід / вихід. Перевірено: ні (безумовно ціновий P&L ≈ 0).
- Критик A: **ні.** Премія і funding пов'язані механічно (Binance-формула), тож це H1 під іншою назвою; дані тільки для екстремальних днів (вибір за наслідком); безумовний ціновий P&L ≈ 0 вже відомий.

### Тип: витрати та хедж

**H9. Структура витрат: знижка BNB, maker на перпі, лімітний вхід на споті, ноги по черзі; калібрування моделі витрат за паперовими угодами.**
- Зміна: тепер модель = спот 0.10 % + перп 0.05 % taker + 0.05 % проковзування на ногу. Тестується сценарій (а) спот-комісія зі знижкою BNB (25 % за сторонніми описами; **не підтверджено**, є й версія про 15 % і інший базовий тариф — звірити з офіційною таблицею), (б) maker на перпі (0.02 %), (в) лімітне виконання споту, (г) спот-пара в USDC/FDUSD з нижчою комісією, якщо така є. Паперові рушії A/B уже показали витрати 1.68× і 1.33× моделі на 21.10.
- Механізм: цей модуль не потребує переваги платника — він повертає частку вже існуючої премії. Проковзування критичне: 0.2 % на ногу знищує третину результату (+6.5 % → +4.1 %), 0.5 % — весь.
- Джерело: [Bitsgap, Binance fees](https://bitsgap.com/blog/binance-trading-fees-explained-what-it-costs) та інші результати пошуку — суперечливі, використовувати лише як підказку, що вивіряти; офіційна комісія — на сторінці Binance. Наш звіт альтів.
- Виміряти: пункт 2 картки (калібрування з паперу) і чутливість `simulate_carry_portfolio` до комісій/проковзування; книгу ордерів збирає колектор для знімків (`docs/paper/`), історії стаканів немає. Історія не потрібна.
- Тип: витрати. Перевірено: комісії ×2 (HL), проковзування 0.2/0.5 % (альти). Потужність не потрібна (детермінована арифметика + виміряні знімки).
- Критик A: **не модуль 3: це пункт 2 картки** (калібрування витрат). Включити туди сценарії maker/BNB/USDC лише після звірки з офіційною таблицею комісій Binance: сторонні описи суперечливі (BNB 25 % чи 15 %), їх числа не брати. Проковзування вимірювати з паперових угод, не припускати.

**H10. Дохідна спот-нога: ETH-carry на WBETH/stETH (стейкінг ≈ 2.5–4 % плюс funding) замість «голого» ETH.**
- Зміна: на ETH-нозі carry тримати ліквідний стейк-токен проти шорта ETH-перпа. Додається ставка стейкінгу до funding; ризики — відхилення курсу токена від ETH у стресі та зарахування як застави.
- Механізм: платить мережа (емісія), а не контрагент; Ethena будує USDe так само (staked ETH + шорт ETH-перпа), і її документація оцінює стейкінг-нагороду 3–4 %, funding+базис 6–7 % за три роки.
- Джерело: [Ethena docs, FAQ](https://docs.ethena.fi/resources/faq) (числа з пошуку; не перевірені нами); [Ethena USDe overview](https://docs.ethena.fi/solution-overview/usde-overview); наш HL-звіт: ETH +5.7 % на номінал.
- Виміряти: ціна WBETH/ETH і ETH/BETH на Binance (4h, ccxt `WBETH/ETH`); приріст = (курс WBETH за рік − 1) + funding ETH − дисперсія відхилення пари; найгірший шок за історією (напр. червень 2022 stETH, відкрити окремо — наших даних про stETH немає). Історія WBETH на Binance є з 2023-04 (перевірити). Також враховувати, чи приймає Binance WBETH заставою перпа.
- Тип: хедж / вибір інструменту. Перевірено: ні.
- Критик A: **ні: дублікат** відхиленої картки `IDEA-20261018-staked-eth-carry` (тріаж 18.10: надлишок над кешем ≈ 0…+1 п.п., MDE 4.5–6 п.п.; питання застави WBETH вирішує документація). Новизни немає; дохідність Ethena — з пошуку, не перевірена.

**H11. Датований базис як фіксація: календарний вибір «датований або перп» за різницею базису й очікуваного funding (BTC/ETH).**
- Зміна: коли річний базис квартального ф'ючерса − trailing 30д funding перпа ≥ k, закріплювати дохід датованим (Binance USDT-M квартальний, Deribit, OKX), інакше перп; вихід на експірації без ролу. Дохід відомий на вході, не має ризику розвороту funding, але капітал зв'язаний до експірації.
- Механізм: BIS — крипто-базис великий і зберігається через обмежену арбітражну ємність; датований контракт збігається на експірації, тож премія «добирається» гарантовано.
- Джерело: [BIS](https://www.bis.org/publ/work1087.pdf); наш звіт про датований базис (H2: +6.2 % на капітал, останній рік 2.7 % < 3 %).
- Виміряти: `dated_basis/` (29 контрактів Deribit, 22 Binance); календар «датований проти перпа» як вибір правилом k. **Потужність мізерна**: n = 29, MDE 4.4 п.п. > очікуваного ефекту → лише форвард-колектор термінової структури (щоденний знімок базису Binance/Deribit/OKX) і розрахунок на paper.
- Тип: вибір інструментів. Перевірено: так (d ≈ 0, ворота не пройдено, [dated-basis](../verification/2026-10-14-dated-basis.md)); новий елемент — правило вибору за різницею, не безумовний календар. Очікування низьке (≈ 5–10 %), модуль не варто робити до появи форвардних даних.
- Критик A: **ні.** n = 29, MDE 4.4 п.п. > ефекту, база вже не пройшла ворота (`dated-basis`); автор сам не радить робити.

**H12. Форвардний модуль: «подія листингу / ліміт ноги» — carry на нових перпах із лімітами позиції та хайповим funding тільки в межах ліміту й капіталу ноги.**
- Зміна: вхід лише у два типи епізодів, що давали основну суму (COAI, M, ENSO…, топ-5 = 73 % прибутку): перші 30 днів нового листингу зі споту+перпа, обидві ноги на одній біржі (без розриву маржі), розмір ≤ 10 % ліміту позиції, обов'язковий стоп-вихід за премією.
- Механізм: на нових листингах плечевий попит і обмежена пропозиція пози; арбітраж обмежений ліміт-розміром, тож премія триває дні (це BIS у мініатюрі). Ємність мала.
- Джерело: [BIS](https://www.bis.org/publ/work1087.pdf); наші звіти (B: хвіст, топ-5 монет; HL-звіт: HYPE перший місяць, премія після TGE).
- Виміряти: **історично слабко** (бектест B не відтворюється на повній історії, survivorship, лістинги в кеші лише живі), тому — форвард: скан нових символів (`funding_carry_scan` + дата лістингу) і папір з реєстрацією; критерій — реалізований funding в смузі `bench.json` і відсутність ліквідації ноги.
- Тип: вибір інструментів / форвард. Перевірено: хвіст так, правило ні. Потужність: до 30.11 очікується кілька епізодів; вердикт лише форвард-запис.
- Критик A: **ні (зараз).** Історії нема (survivorship), ємність мала, перетинається з хвостом заморожених паперових A/B; новий форвард — окрема робота, не модуль цієї хвилі.

## Досьє Polymarket
Скаут, режим «знання», 2026-10-31. Нових карток немає; 12 гіпотез-модулів для відбору критиком A (позначка «Критик A: ◯» заповнюється ним: брати / ні + причина). Текст мережі й бібліотеки — недовірені дані; числа з мережі — гіпотези, а не факти. «Стратегія» тут — форвард-папір [polymarket-vs-options-forward](IDEA-20261017-polymarket-vs-options-forward.md) (позиція, коли чистий edge ≥ 5 п.п. проти ризик-нейтральної ймовірності Deribit; вхід за askом + комісія; утримання до розв'язання). Її реєстрація заморожена: усі модулі нижче — **нові позначені варіанти поруч**, а не зміна запущеного паперу. Гіпотези впорядковано за очікуваним приростом чистого результату за рік, спершу ті, що додають дохід чи позиції, потім зменшують шум моделі, наприкінці — шляхи до потужності.

### Від чого відштовхуємось (з наших звітів і документації)
- Платник і причина. Роздрібні тейкери Polymarket платять за лотерейні контракти й за швидкість: у Kalshi (300 тис. контрактів) низькоцінові контракти виграють рідше за ціну, а збитки тейкерів ≈ 32 % проти ≈ 10 % у мейкерів ([Bürgi, Deng, Whelan](https://www.ucd.ie/economics/t4media/WP2025_19.pdf), [CEPR](https://cepr.org/publications/dp20631); цифри з анотацій, між версіями різняться; у версії 2026 р. перекіс зменшується). Платник реальний, але сума, яку можна зібрати, обмежена нашою ємністю: форвард-картка сама оцінює ≈ 10 позицій на тиждень × ≤ $200 глибини × 5 п.п. ≈ $100 на тиждень. Тому цінність модуля — або підвищити імовірність, що картка взагалі покаже ефект, або зняти шум моделі, або знизити вартість входу.
- Що відомо з наших тестів (не повторюю):

Є 1-хвилинні точки котирування за 2 год до t0 для 17 тис. ринків, угоди 2 905 контрактів.

### Тип: вибір інструментів і сторони

**H1. Асиметрія сторін: купувати лотерейний YES лише при більшому розриві, NO-бік хвоста — при меншому.**
- Зміна: тепер поріг 5 п.п. однаковий для обох боків. Варіант: бік «YES дешевше за 15 ц» (лотерея) потребує edge ≥ 8 п.п., бік «NO у хвості / фаворит» — ≥ 3 п.п. Позицій на боці NO більшає, на боці YES менше; сума може зрости, бо поріг 3 п.п. на NO тримає значно більше знімків.
- Механізм: favourite-longshot bias сильніший за тейкерів на дешевих контрактах; роздрібні тейкери переплачують за «BTC торкнеться $150k» і за дешеві дотики, тому розрив «модель > ринок» на боці YES частіше є шумом моделі (хвостові ймовірності з усмішки найнестійкіші), а розрив «модель < ринок» — платою за лотерею. Зараз 11 з 16 паперових позицій — саме купівлі YES на дотик, тобто на боці, де література очікує програш тейкера.
- Джерело: [Bürgi, Deng, Whelan](https://www.ucd.ie/economics/t4media/WP2025_19.pdf); наша бібліотека [LIB-20261015-polymarket-basics](../library/LIB-20261015-polymarket-basics.md) (теза 1); [yes-calibration](../verification/2026-10-16-polymarket-yes-calibration.md) (центр не переоцінений, хвости не мірялись).
- Виміряти: форвард — розбивка існуючих позицій і всіх допущених знімків за боком × ціною входу × напрямом (reach / dip) × CLV +24 год і P&L; історія — 1 913 хвостових контрактів порогових ринків (кеш `polymarket_threshold/`) за боками: калібрування q проти частоти виграшу окремо в кошиках [0.02; 0.15] і [0.85; 0.98] (MDE 2.23 п.п. за датами — нижче, ніж потрібно, тож лише описово). Історія є частково; ефект малий, MDE велика.
- Тип: вибір інструментів / сторони. Перевірено: хвостові NO — форвардні картки (`longdated-tail-no`, `touch-ladder`), але не за боком усередині порогових розривів з опціонами. Потужність низька.
- Критик A: drop — n = 16 позицій, MDE 2.23 п.п. на історії, суміжне закрито `yes-calibration`; розбивка за боком — частина вердикту форвард-картки.

**H2. Вихідні й свята в моделі: окрема знижка k для вікон, що лежать у Fri 21:00 UTC — Sun 21:00 UTC, замість сталих 0.92.**
- Зміна: реєстрація знижує IV сталим множником 0.92. Для вікон повністю або здебільшого у вихідних множник береться з нашої знижки вихідних: ринок закладає 0.82 дисперсії контролю, реалізується 0.48, тобто реалізована σ ≈ 0.77 від закладеної (√(0.48/0.82); оцінка скаута, не розрахунок на нашій моделі). Позиції, що виходять із цього (особливо NO на OTM-дотику та OTM-порогових ринках у вихідні), додаються, а не відсікаються.
- Механізм: вихідні — час, коли дилери дисконтують вол менше, ніж вона падає; роздрібний PM-покупець цінує хвіст як у будні (спот у сусідній вкладці рухається менше). Платить покупець хвостового дотику у вихідні. Тривати це може, бо арбітражний капітал на тонких вихідних книгах мінімальний.
- Джерело: наш звіт [weekend-vol-discount](../verification/2026-10-15-weekend-vol-discount.md) (R0 = 0.544, 6 з 6 років); розподіл волатильності за часом доби й тижня: [CryptoSlate](https://cryptoslate.com/crypto-never-closes-but-bitcoin-ethereum-xrp-and-solana-now-move-on-wall-street-time/) і [Quantpedia](https://quantpedia.com/are-there-seasonal-intraday-or-overnight-anomalies-in-bitcoin/) (вторинні; частка US-годин у денній дисперсії ≈ 50 %, вихідні тихіші — гіпотези).
- Виміряти: ряд Binance 1m (є) → реалізована дисперсія за вікнами «до розв'язання» для кожної дати порогових ринків (кеш `polymarket_threshold/`) проти EWMA-моделі; калібрування q для ринків, чий [t0; T] перетинає вихідні, проти решти (≈ 2/7 дат, ≈ 110 дат хвостів: MDE ≈ 3.7 п.п., лише описово); форвард — CLV і P&L позицій за прапорцем «вікно у вихідних» (колектор його не пише, рахується з `end_ts`, `hours_to_end`). Історія є, потужність низька.
- Тип: контекст / модель. Перевірено: знижка вихідних в опціонах — так (`weekend-vol-discount`); перенесення на ціни PM — ні.
- Критик A: drop як окремий модуль — ≈ 110 дат хвостів, MDE ≈ 3.7 п.п.; вихідні/година входять профілем у H7 (на Binance 1m потужність є), не окрема гіпотеза в Холмі.

### Тип: вхід і виконання

**H3. Лімітний (мейкерський) вхід замість тейкерського аска; поріг edge знижується до 2–3 п.п.**
- Зміна: замість купівлі за аском + комісія ставити GTC-ліміт на ціні «справедлива (з опціонів, k = 0.92) мінус потрібний edge» поруч із краєм книги; вихід лімітом також. Вартість входу тейкера: комісія до 1.75 ц при 50 ц + половина спреду (в реєстрації 1 ц) ≈ 2.75 п.п., тобто більше половини порога 5 п.п. Мейкер не платить комісії і отримує 20 % повернення від тейкерських комісій.
- Механізм: мейкер бере плату у нетерплячого тейкера, а не навпаки (Kalshi: мейкери ≈ −10 % проти ≈ −32 % у тейкерів). Ризик: відбір невигідних угод (виконання перед рухом проти нас) і невиконання у «правильних» випадках. Це ручні ліміти, 5–10 на тиждень, без автоматичного котирування — відмінність від відхиленої `polymarket-liquidity-rewards-yield`.
- Джерело: [Polymarket fees](https://docs.polymarket.com/trading/fees); [Bürgi et al.](https://www.ucd.ie/economics/t4media/WP2025_19.pdf); [Polymarket liquidity rewards](https://docs.polymarket.com/market-makers/liquidity-rewards) (винагороду не враховуємо).
- Виміряти: форвард — у `pm_gap_snapshot` лише година-у-годину знімки, тож модель виконання така: ліміт «виконався», якщо ask наступного знімка ≤ нашої ціни (консервативно); частка виконаних і CLV виконаних проти пропущених. Історично: стрічка угод `/trades` (кеш `polymarket_threshold/`, `pm_touch/`) для здогаду про частоту перетину рівня й markout 10 хв / 1 год; книги для історії немає. Історія є частково (угоди), книги нема.
- Тип: вхід / витрати. Перевірено: ні (форвард входить лише за аском). Потужність: markout по угодах — сотні подій, достатньо; прибутковість — форвард.
- Критик A: drop (форвард/ручна практика) — історії книг нема, модель виконання за погодинними знімками оптимістична й не бачить відбору; ідея для плану, не для кванта.

**H4. Ранжувати за річним edge і виходити при збіжності, а не тримати до розв'язання.**
- Зміна: реєстрація: одна позиція на (ринок, бік) до розв'язання, строк ≤ 14 днів. Варіант: бал = чистий edge / (ціна входу × діб до кінця); закривати біля bid, коли розрив до моделі < 1 п.п. або минула доба-дві. Не відсікає позиції, а перерозподіляє капітал і прибирає з основної дисперсії бінарний результат 0/1 (SD контракту 0.235 проти SD зміни міду за добу ≈ 0.10–0.20 у розділі 11).
- Механізм: платник не змінюється; вартість капіталу в PM (USDC, заблокований на дні утримання) і шум результату розв'язання. Короткий розрив 5 п.п. на ціні 0.2 за 2 дні — 25 % за 2 дні, на 14 днях — той самий 25 % за 14. Підхід з беттингу: CLV як цільова метрика.
- Джерело: реєстрація (розділи 7, 11); [LIB-20261015-polymarket-basics](../library/LIB-20261015-polymarket-basics.md) (теза 2, «закривати біля 50 ц» — перевірено лише як правило ризику, [yes-calibration](../verification/2026-10-16-polymarket-yes-calibration.md): частота YES після перетину 0.50 ≈ 0.50, edge нема).
- Виміряти: форвард з `pm_gap_snapshot`: для кожної позиції ряд міду боку щогодини (є) → дохід «закрити на bid при збіжності» проти «до розв'язання» і оборот капіталу за рік; кластер — ISO-тиждень входу. Історія для виходів не потрібна й не існує. Реальні ліміти закриття — як H3.
- Тип: вихід / розмір. Перевірено: ні.
- Критик A: drop — 16 позицій, вихід по bid платить спред вдруге, «закривати біля 50 ц» edge не дало (`yes-calibration`).

**H5. Тригер за стрибком спота: знімок і сигнал щойно після різкого руху BTC / ETH, а не щогодини.**
- Зміна: колектор пише знімок щогодини; бот-арбітраж між Binance і PM і так працює з секундами, але на **тонких денних драбинах** хвостові страйки оновлюються рідше. Варіант: після руху |Δ5 хв| ≥ 0.5 % (поріг фіксується до прогону) окремий знімок через 1, 5 і 30 хв і сигнал, якщо розрив до моделі з Binance-споту відкрився й тримається ≥ 10 хв. Додає позиції, зосереджені у моменти руху.
- Механізм: хто платить — маркет-мейкер із запізнілою квотою й роздрібний покупець, що не бачить руху; чому триває — на ринках з обігом десятків тисяч доларів оновлення квот не окупається. Цей канал могли вже забрати боти: для 5- і 15-хвилинних ринків введено комісії саме проти нього; для денних драбин невідомо.
- Джерело: [CoinSpectator](https://coinspectator.com/mainstream/2026/01/07/polymarket-introduces-dynamic-fees-to-curb-latency-arbitrage-in-short-term-crypto-markets/); [QuantVPS](https://www.quantvps.com/blog/binance-to-polymarket-arbitrage-strategies) (маркетинг, довіри мало); наш звіт про мітку `/prices-history`: [threshold-vs-vol](../verification/2026-10-15-polymarket-threshold-vs-vol-model.md) («Що далі»: мітку часу точки перевірити окремим тестом — той самий тест тут є попередньою умовою).
- Виміряти: історія — 1-хв котирування за 2 год до t0 для 17 тис. ринків + Binance 1m: швидкість підлаштування ΔPM(t, t+k) до зміни DigitalN(d2) після стрибка (півперіод затримки по ліквідності ринку); кількість стрибків ≥ 0.5 % за 5 хв на добу порахувати до реєстрації. Форвард — потрібен подієвий збір (нова робота колектора, BACKLOG). Історія є лише у вікнах 2 год до t0, тож охоплює лише стрибки в ці години.
- Тип: вхід (тригер). Перевірено: ні. Очікування низьке (≈ 5–10 %): конкурують швидші; корисний головно як вимірювання «швидкості PM».
- Критик A: drop — конкурують швидші боти й динамічні комісії, історія лише вікна 2 год до t0, потрібен новий подієвий збір.

### Тип: розрив із моделлю — хедж і модель

**H6. Хедж колл-спредом Deribit (статична репліка цифрового опціона) замість голої ставки проти ризик-нейтральної моделі.**
- Зміна: купівля YES(K) на PM + продаж колл-спреду K / K+δ на Deribit на тому ж активі. Прибуток тоді фіксується вартістю репліки, а не «реальною» імовірністю; питання, чи ризик-нейтральна ймовірність ≠ реальна, відпадає (інваріант 8 `CLAUDE.md`). Для вибору позицій розрив рахується не до моделі, а до вартості репліки за bid/ask Deribit (виконуваний розрив). Це змінює і звіт: меншої кількості, але хеджованих позицій.
- Механізм: платить роздрібний покупець PM; роль арбітражера — мало хто тримає одночасно рахунок Deribit і USDC на Polygon; капітал і операційні тертя обмежують конкуренцію. Обмеження: експірація Deribit 08:00 UTC, закриття PM 12:00 ET (16:00–17:00 UTC), тобто залишок ≈ 8–9 год руху (σ_9год ≈ 0.55·√(9/8 760) ≈ 1.8 % ціни за IV 55 % — оцінка, того ж порядку, що й крок страйків), тож репліка недосконала; ширина крила δ — друге джерело помилки.
- Джерело: replication через колл-спред і Breeden–Litzenberger: [Hypercall docs](https://docs.hypercall.xyz/docs/reference/binary-static-replication/learn/), [MetricGate](https://metricgate.com/docs/breeden-litzenberger-risk-neutral-density/) (довідкові, не наукові); інваріант 8; реєстрація (розділ 3 «Знижка за ризик-нейтральність»).
- Виміряти: форвард — розширити колектор: для кожного знімка писати bid/ask двох сусідніх страйків Deribit навколо K на найближчій експірації (ланцюжок тільки поточний; історії нема). Далі: дисперсія P&L хеджованої пари проти голої, частка розривів, що переживають вартість репліки. Історія недоступна. Потужність: позицій ≈ десятки за 16 тижнів; вердикт описовий.
- Тип: хедж. Перевірено: ні (реєстрація радить лише консервативний фільтр k = 0.92).
- Критик A: drop — нема історії ланцюжків, залишок 8–9 год робить репліку недосконалою, на ємності $200 дві ноги Deribit з'їдають edge.

**H7. Експірація і внутрішньодобовий профіль: інтегрувати дисперсію до самого моменту розв'язання (12:00 ET), а не брати IV експірації 08:00 UTC.**
- Зміна: модель беруть з IV найближчої експірації Deribit (08:00 UTC); колектор пише `expiry_gap_hours`, тож зсув до 36 год залишається. Поправка: розбити вікно [зараз; кінець PM] на години, зважити їх профілем дисперсії за годиною доби (US-години ≈ 50 % денної дисперсії за 37.5 % часу, за вторинним джерелом) і побудувати σ_еф для цього інтервалу. Шум моделі падає, поріг можна знижувати (реєстрація оцінює шум моделі 1–2.5 п.п. і бере 5 п.п. ≈ 2× шуму) — отже позицій більше при тій самій якості.
- Механізм: це не нове джерело доходу, а зменшення помилки, яку поточна модель сприймає за розрив; хибні розриви відкидаються, а справжні при нижчому порозі проходять. Платник — той самий, що в H1–H2.
- Джерело: [CryptoSlate](https://cryptoslate.com/crypto-never-closes-but-bitcoin-ethereum-xrp-and-solana-now-move-on-wall-street-time/), [Quantpedia](https://quantpedia.com/are-there-seasonal-intraday-or-overnight-anomalies-in-bitcoin/) (вторинні); наш `expiry_gap_hours` у реєстрації.
- Виміряти: профіль за годиною — Binance 1m (є, 2022+); якість моделі — Brier / логарифмічна втрата EWMA-моделі з профілем і без нього на 17 тис. порогових ринках (кеш `polymarket_threshold/`; поправка щодо потужності: різниця Brier парна за ринками, потужність краща за калібрування PM, бо йдеться про модель, а не про ринок); форвард — частка знімків, чий розрив змінюється більше за 1 п.п. після поправки. Історія є. Опціонної частини (IV експірації) історично немає.
- Тип: модель. Перевірено: ні.
- Критик A: take — парна різниця Brier на 17 тис. ринків (сторона моделі, потужність краща); профіль лише з минулого (IS/OOS), вихідні (H2) всередині; IV експірації історично нема.

**H8. Джерело розв'язання: Binance BTC/USDT замість індексу Deribit (базис USDT і «ґноти» Binance).**
- Зміна: PM розв'язує за 1-хвилинною свічкою Binance; модель бере `spot` = індекс Deribit (USD), а реєстрація залишає питання «форвард = індекс» відкритим. Варіант: брати S0 = `binance_last` (колектор його пише), форвард усмішки (`model_forward`, колектор пише після мерджу) і додати поправку на ґноти: дотик по Binance 1m High ловить локальні пікові викиди Binance, які індекс згладжує.
- Механізм: розрив 0.1 % між індексом і Binance дає ≈ 1.4 п.п. на ATM-порозі за 1 день (реєстрація); розрив 0.3–0.5 % дав би 4–7 п.п. Це або хибні позиції, або пропущені. Без нової складової доходу: усуває систематичну помилку, яка однаково штовхає всі порогові позиції в один бік.
- Джерело: реєстрація (розділи 2–4, відкрите питання для кванта про форвард); правила ринків (текст «Binance 1 minute candle for BTC/USDT»).
- Виміряти: форвард — розподіл `binance_last − spot` (історії індексу Deribit не потрібно: це різниця на момент знімка, дані з форварду) і перерахунок `model_prob` з аналітикою (тест з аналітичним еталоном); зріз позицій, які зникають / з'являються. Дані: є.
- Тип: модель / витрати. Перевірено: ні. Очікування «розрив > 0.2 %» — гіпотеза, лише розподіл покаже.
- Критик A: take — вимір систематичної помилки входу (арифметика на колекторі, ≈ 2 тижні щогодини); знімки залежні, CI блоками по добах; результат — поправка моделі, не вердикт про прибуток.

**H9. Знижка залежно від рівня DVOL (і строку), а не стала k = 0.92.**
- Зміна: k = f(DVOL-терцилі, строк 1–3 / 4–14 діб) із відношень реалізованої σ до ATM-IV на нашій історії (DVOL є, Binance 1m є). Мета — менше пропущених позицій при низькому VRP (k ≈ 1) і менше хибних при високому DVOL (k < 0.9). Ефект на кількість позицій двосторонній.
- Механізм: VRP залежить від рівня вола (наш звіт: рівень DVOL має значення, а IV−RV — ні) і скорочується з 2021 року; стала k 0.92 була взята з одного джерела (30-денний BTC).
- Джерело: [vrp](../verification/2026-10-13-vrp.md), [vrp-real-marks](../verification/2026-10-18-vrp-real-marks.md); реєстрація, розділ 3 (k не підганяється, інші k не пробуються — тому це **новий позначений варіант**, а не зміна).
- Виміряти: Deribit DVOL-історія + Binance 1m, неперекривні вікна 1/3/7/14 діб, відношення реалізованої σ до DVOL по терцилях DVOL; CI блоковим бутстрепом. Історія є, але ATM-IV сьогоднішнього знімка не дорівнює DVOL (30-денна), тому лише для низької точності.
- Тип: контекст. Перевірено: частково (30-денний BTC); горизонти 1–14 діб — ні.
- Критик A: drop — k заморожена реєстрацією, `vrp` вже відповів, DVOL 30-денний ≠ горизонти 1–14 діб, 6 комірок = forking paths.

### Тип: розширення універсу і шляхи до потужності

**H10. SOL і XRP (і інші) драбини проти опціонів Deribit / Binance на тих самих активах.**
- Зміна: колектор бере лише BTC/ETH; PM має щоденні драбини SOL і XRP (≈ 400 порогових подій на актив у нашому переліку, 279 і 276 подій на дотик). Опціони: Deribit запускала SOL_USDC і XRP_USDC (2024; чи XRP ще торгується — перевірити живим `get_instruments`), Binance — SOL денні й тижневі європейські (з 2024-11, за новиною). Багато менш ліквідних ринків = менше уваги арбітражерів = ширші розриви; і вдвічі більше незалежних дат на тиждень.
- Механізм: той самий платник (роздріб PM), нижча конкуренція. Контрриск: опціони на SOL / XRP теж тонкі, їхні IV шумніші за BTC; розрив до моделі стає розривом до шуму.
- Джерело: [The Block, Deribit SOL / XRP linear options](https://www.theblock.co/post/276635/deribit-linear-options-sol-xrp-matic), [Deribit support, Linear USDC Options](https://support.deribit.com/hc/en-us/articles/31424932728093-Linear-USDC-Options), [blockchain.news про Binance SOLUSDT](https://blockchain.news/news/binance-introduce-bnbusdt-solusdt-monthly-options) (вторинні; перевірити живими інструментами); наш перелік порогових подій ([threshold-vs-vol](../verification/2026-10-15-polymarket-threshold-vs-vol-model.md): SOL 401, XRP 392 подій).
- Виміряти: крок 0 — `get_instruments` Deribit для SOL_USDC / XRP_USDC (кількість експірацій і страйків, спред); історія — калібрування PM проти EWMA-моделі окремо за активами в кеші `polymarket_threshold/` (SOL і XRP вже там, без опціонів); форвард — розширення колектора на актив. Опціонної історії немає.
- Тип: вибір інструментів. Перевірено: ні (звіти лише BTC/ETH).
- Критик A: drop — нема історії опціонів SOL/XRP, ліквідність нижча, калібрування PM по активах дублює `yes-calibration`; живий `get_instruments` — для скаута.

**H11. PM-імпліцитна волатильність за драбиною події (безперервна змінна) замість бінарних результатів окремих контрактів.**
- Зміна: для кожної події («above» на дату) відновити σ_PM і нахил із усієї драбини страйків (підігнати нормальний/лог-нормальний CDF до YES-цін) і порівнювати σ_PM з DVOL / ATM-IV Deribit та з реалізованою σ до розв'язання. Одна подія → одне число; сигнал — «PM-вол» систематично вищий або нижчий за опціонну й реалізовану.
- Механізм: ціни сусідніх страйків корельовані; шум окремого контракту (SD 0.235) усереднюється, вимірюється різниця волатильностей, а не 0/1. Потужність: безперервна змінна на ≈ 1 152 «днях-активах» (прогноз Mincer–Zarnowitz) замість ≈ 389 дат хвостів, де MDE 2.23 п.п. Результат також корисний як «індекс страху PM» для аналізу ринку (знання).
- Джерело: [threshold-vs-vol](../verification/2026-10-15-polymarket-threshold-vs-vol-model.md) («Що далі»: порогові ворота не пройдено через бінарність); [MetricGate](https://metricgate.com/docs/breeden-litzenberger-risk-neutral-density/) (відновлення щільності з ряду страйків, довідка).
- Виміряти: кеш `polymarket_threshold/` (q на t0 для кожного страйку; результати; Binance 1h; DVOL); регресія realized_σ на σ_PM і на σ_EWMA / DVOL, парні Diebold–Mariano-різниці, кластер — дата. Історія є. Опціонна ATM-IV історично лише через DVOL (30 діб).
- Тип: модель / сигнал. Перевірено: ні (звіти рахували ворота контрактів і не дійшли до середніх).
- Критик A: take — безперервна змінна, потужність краща за бінарні ворота; n_eff менша за 1 150 (кластер — тиждень), q як мід до t0, реалізована σ лише після t0, головне порівняння з EWMA, не з DVOL.

**H12. Погодинні порогові ринки як шлях до потужності (новий продукт, нова реєстрація).**
- Зміна: звіт [threshold-vs-vol](../verification/2026-10-15-polymarket-threshold-vs-vol-model.md) сам вказує: погодинні ринки (`…-1pm-et`, ≈ 4 800 подій на BTC і на ETH) — шлях до потужності, бо мають у десятки разів більше подій, ніж денні. Тест калібрування PM проти моделі реалізованої волатильності за останні години (1-хв Binance); опціони Deribit у горизонті годин не дають IV, тож порівняння — з реалізованою / EWMA-волою. Якщо знак і величина перекосу є в погодинних, це дозволяє перенести правило на денні.
- Механізм: ті самі платники (роздрібні тейкери), але на коротких ринках діє комісія, спрямована проти латентного арбітражу (Polymarket, січень 2026), тож результат може відрізнятись від денних; кластери всередині дня залежні (одна подія = десяток страйків).
- Джерело: [threshold-vs-vol](../verification/2026-10-15-polymarket-threshold-vs-vol-model.md); [CoinSpectator](https://coinspectator.com/mainstream/2026/01/07/polymarket-introduces-dynamic-fees-to-curb-latency-arbitrage-in-short-term-crypto-markets/).
- Виміряти: інструментарій (перелік, 1-хв котирування, угоди, класифікація правил) уже готовий; потрібне: реєстрація до першого fetch окремим комітом, тест мітки часу `/prices-history`, перенесення `load_spot` і `load_dvol` в `analytics/` (звіт, «Що далі»). Кластер — година-в-добі × доба (n_eff значно менша за кількість ринків, MDE порахувати до воріт).
- Тип: вибір інструментів / шлях до потужності. Перевірено: ні. Очікування: сам по собі не edge, а умова для H1–H2 на більшій вибірці; відхилення комісіями ймовірне.
- Критик A: drop — нова реєстрація й інфраструктура, n_eff всередині доби мала, комісії проти латентного арбітражу; повернутись, якщо H11 покаже знак.

- Потужність: парна різниця SD ≈ 1.0–1.5 %, MDE ≈ 0.2–0.25 %; ефект, ймовірно, нижче; у половині тижнів сигнал нейтральний.
- Цінність: ефект ≈ +0.05–0.15 % спота за тиждень (приріст над H1) → 2–8 % номіналу на рік; ймовірність ≈ 8 % (наш власний тест RR25 вже дав ◯); вартість 1–2 год після H1.
- Критик A: **ні.** `put-skew-v2` вже показав, що RR25 не розділяє P&L; половина тижнів нейтральна, тож n ≈ 150 на парну різницю з MDE 0.2–0.25 % проти ефекту 0.05–0.15 %; правило z ≥ +1 з самозвіту статті, а вибір сторони — ще один ступінь свободи в Холмі. Повернутись, лише якщо H1 покаже асиметрію сторін (розбивка пут/кол у звіті H1 безкоштовна).

**H3. Вибір дельти й ширини: сітка з трьох комірок (шорти 5Δ / 10Δ / 16Δ, крило 10 % / 15 %) замість «стандартних» 16Δ.**
- Зміна: не фільтр, а вибір точки на кривій «кредит проти ймовірності попадання». Практики кажуть, що ширше розведення шортів підвищує ймовірність виграшу, але зменшує кредит ([Option Alpha, 0DTE](https://optionalpha.com/blog/0dte-options-strategy-performance); маркетингове джерело, вибірки малі).
- Механізм: премія хвостів платить за стрибки (ґеп-ризик), а не за дрібну вариативність; далі страйки — меншa частка премії йде в «недооцінений» центр (у центрі IV−RV ≈ рівні витрат, у крилах — вища інтенсивність попиту). Хто платить: покупець 5Δ-опціонів як «дешевого» хеджу чи лотереї.
- Джерело: наш `long-strangle-sell-far-strike` (марка ±8 % веде себе передбачувано, IV-реакція лише на путах); [Deribit Insights](https://insights.deribit.com/industry/bitcoin-options-finding-edge-in-four-years-of-volatility-regimes/) (скью та VRP залежать від дельти).
- Виміряти: каркас H1, шість комірок, Холм на 3 (вибір пари заздалегідь); показати стійкість вниз: чи рейтинг комірок однаковий у 2021–23 і 2024–26. Історія є; страйки далі 10Δ мають менше свіжих марок — покриття падає.
- Тип: структура. Перевірено: ні.
- Потужність: SD для 5Δ-комірки нижча (≈ 1.0–1.5 %), але ефект теж менший; MDE ≈ 0.2–0.3 %. Різниця між комірками — скоріше описова.
- Цінність: ефект ≈ 0.0–0.1 % спота за тиждень (приріст над H1); ймовірність ≈ 7 %; вартість 1–2 год.
- Критик A: **ні.** Шість комірок з різницею нижче MDE (0.2–0.3 % проти 0.0–0.1 %) = forking paths; далекі страйки мають менше свіжих марок, тож покриття 5Δ-ноги, найімовірніше, провальне. Дельта ніг у H1 фіксується заздалегідь одним значенням (10Δ), а решта сітки — лише описова чутливість у звіті H1, поза Холмом.

### Тип: час і календар

**H4. Розмір за перцентилем DVOL (безперервно), а не вхід лише у верхньому квінтилі.**
- Зміна: замість фільтра «входимо лише при DVOL ≥ 80-го перцентиля» (H2 `vrp-real-marks`: +1.43 % [−0.13; +3.45], n = 16, ◯) залишити всі тижні й масштабувати ризик-бюджет: 0.5× при P < 0.4, 1× при 0.4–0.8, 1.5× при ≥ 0.8, у межах ліміту просадки. Кількість угод не зменшується.
- Механізм: наша знахідка — рівень DVOL важливіший за спред IV−RV; в абсолютних одиницях премія вища при високій IV, а ризик руїни стримується ширшими крилами й меншою часткою капіталу. Протилежний бік: у спокійному режимі премія в дисперсійних одиницях вища (0.17 проти 0.12, [arXiv 2410.15195](https://arxiv.org/html/2410.15195v2)) — тому гіпотеза двобічна, знак перевіряється.
- Джерело: наші `vrp-real-marks` (H2), `2026-10-13-vrp.md` (DVOL-режими); [arXiv 2410.15195](https://arxiv.org/html/2410.15195v2).
- Виміряти: P&L H1-кондора за тижнями проти P_t (перцентиль DVOL за 365 д) — безперервна регресія замість квінтилів (потужніша: використовує всі 300 тижнів, не 16); парна різниця «масштабований мінус рівний розмір». Історія є.
- Тип: розмір / контекст. Перевірено: так частково — квінтиль на ATM-стреддлі ◯ (n = 16); безперервне масштабування на кондорі ні.
- Потужність: регресія на 300 точках SD ≈ 1.5–2.2 % → MDE нахилу ≈ 0.4 п.п. на одиницю P_t; різниця «масштабований мінус рівний» на парних тижнях MDE ≈ 0.1 % спота (оцінка).
- Цінність: ефект ≈ +0.05–0.1 % спота за тиждень (за рахунок більшого розміру у вигідні тижні) → 3–5 % номіналу; ймовірність ≈ 12 %; вартість 1 год після H1.
- Критик A: **брати** (модуль 2, залежить від H1). Безперервний розмір на всіх тижнях замість n = 16 квінтиля; парна різниця «масштабований мінус рівний» потужніша. Умови: схема 0.5×/1×/1.5× і поріг перцентилів фіксуються в реєстрації (без сітки); P_t лише з 365 попередніх днів; знак двобічний; важливо, що масштабування збільшує ризик саме у високій вол., де найгірші тижні, тож звіт показує CVaR і найгірший тиждень, а не лише середнє. Ефект 3–5 % номіналу оптимістичний (корелює з кількістю великих тижнів); `vrp-real-marks` (рівень DVOL важливий) — єдина підстава, а ◯ там n = 16.

**H5. Вихідні: продавати кондор п'ятниця 09:00 → понеділок 08:00 (3-добова експірація), а не будні.**
- Зміна: структурна знижка вихідних. Ринок закладає для Fri→Sun 0.82 дисперсії контролю, реалізується 0.48, тобто реалізований σ ≈ 0.77 закладеного (оцінка скаута). Щотижня одна коротка угода на понеділкову добову експірацію (кондор 10Δ / крила ±8 %), і кожне вікно перетинає вихідні.
- Механізм: вихідні — час, коли дилери дисконтують вол менше, ніж вона падає; покупець страхування на п'ятницю платить за «будній» ризик, а ліквідність виходить. Платить хеджер із п'ятниці. Тривати може, бо арбітражний капітал у вихідні мінімальний; проти — Deribit ціноутворення вихідних вже частково враховує (формула часу).
- Джерело: наш [weekend-vol-discount](../verification/2026-10-15-weekend-vol-discount.md) (R0 = 0.544, 6 з 6 років, ◯ за n = 160); [CryptoSlate](https://cryptoslate.com/crypto-never-closes-but-bitcoin-ethereum-xrp-and-solana-now-move-on-wall-street-time/) (вторинне).
- Виміряти: кеш поверхонь: п'ятниця 09:00, понеділкова добова експірація 08:00 (є в ланцюжку, якщо колекція мала понеділкові серії у 2021–2026 — **перевірити покриття, перш ніж рахувати**); P&L кондора на delivery; контроль — вівторок 09:00 → четвер 08:00 (теж 2–3 дні). Вхід о 09:00, а знижка вихідних рахується з 21:00 — цей зсув з'їдає частину ефекту (п'ятничні години включені).
- Тип: календар / контекст. Перевірено: описово в опціонах (`weekend-vol-discount`), у торгованій формі ні; тижневий стреддл включає вихідні, але не виділяє їх.
- Потужність: n ≈ 300 п'ятниць, SD кондора 3-добового ≈ 1.0–1.5 % спота, MDE ≈ 0.16–0.25 %. Вперше MDE ближчий до очікуваного ефекту (≈ 0.1–0.2 %).
- Цінність: ефект ≈ +0.1–0.2 % спота за тиждень × 52 = 5–10 % номіналу; ймовірність ≈ 12 %; вартість 2–3 год (покриття понеділкових серій — ризик).
- Критик A: **брати** (модуль 3). Єдиний модуль, де MDE (0.16–0.25 %) близький до ефекту, а механізм вже має ◯-основу (`weekend-vol-discount`: D = +0.34 [+0.19; +0.49], n = 160). Delivery за кожну добу в кеші є (2 638 днів), але чи є в знімках страйки понеділкових серій зі свіжими марками — не перевірено; це стадія 0, і без покриття модуль знімається, а не добудовується. Контроль (вівторок→четвер) фіксується заздалегідь, зсув входу 09:00 проти 21:00 описати. Ризик: ціна вихідних у Deribit частково враховує формулу часу, тож повний 0.77 з досьє — верхня межа.

**H6. Подієві тижні: не пропускати, а замінити кондор на ширше крило або зменшити розмір у вікні FOMC / CPI / NFP.**
- Зміна: за таблицею подій (`docs/verification/2026-10-15-us-macro-events.csv`) у тижні з FOMC / CPI не відсікати угоду, а ставити ширші крила (±20 %) і 0.5× розміру. Тримає угоди, прибирає хвіст.
- Механізм: ринок закладає подію (IV 63 % проти 53 %), а реалізований / premium = 0.90 і в дні подій, і в звичайні — отже подієва премія справедлива, «зайвої» премії в дні подій немає, але стрибок у ці дні — найімовірніше джерело найгіршого тижня.
- Джерело: наш [event-day-straddle](../verification/2026-10-15-event-day-straddle.md); [Deribit Insights](https://insights.deribit.com/industry/bitcoin-options-finding-edge-in-four-years-of-volatility-regimes/) (подієва довга вола — < 15 угод, висновку немає).
- Виміряти: каркас H1, розбивка тижнів за наявністю події і найгірші тижні; порівняння розподілу збитків (CVaR 5 %, найгірший тиждень) із подією й без. Історія є; тижнів із подією ≈ 35–40 % (FOMC 8 / рік + CPI 12 + NFP 12, перекриття) — але великий збиток на подію — ≈ 5–10 тижнів.
- Тип: контекст / розмір. Перевірено: подієвий стреддл на день — так (`inconclusive`); подієва розбивка кондора — ні.
- Потужність: оцінка хвоста з 5–10 подій — слабка; MDE по CVaR не визначити; вердикт буде описовим.
- Цінність: ефект скоріше знижує просадку, ніж додає дохід: ≈ 0 до +0.05 % за тиждень; ймовірність ≈ 6 %; вартість 1 год. Низький пріоритет.
- Критик A: **ні.** 5–10 подій на хвіст: MDE не визначити, автор сам оцінює ефект на дохід у ≈ 0; `event-day-straddle` показав, що подієва премія справедлива. Розбивка найгірших тижнів за наявністю події — безкоштовний розділ звіту H1, не гіпотеза в Холмі.

### Тип: вихід і управління

**H7. Вихід: закрити кондор у п'ятницю-вівторок (день 4 із 7) або при 50 % кредиту, а не тримати до delivery.**
- Зміна: замість утримання до експірації — закриття, коли за марками 09:00 вартість повернення ≤ 50 % отриманого кредиту, або в день 4 за часом; потім реінвестування в новий тиждень (додає угоди-обороти, не відсікає). Другий варіант — стоп при вартості 2× кредиту.
- Механізм: у короткого опціону theta прискорюється, але gamma-ризик на одиницю theta зростає в останні дні; перші 50 % кредиту забираються швидко, а решта — з гірше співвідношенням ризик / винагорода. Практики tastylive: короткі стренгли 45 DTE, 1 SD, управління на 50 % — вищий відсоток виграшу й вищий прибуток на день, найбільший збиток вдвічі менший ([tastylive: managing strangles](https://tastylive.com/shows/market-measures/episodes/managing-strangles-performance-08-05-2016), SPY з 2005 р.; шоу брокера, не рецензоване). Дані про 25 % проти 50 % для 0DTE суперечать одна одній і малі ([Option Alpha](https://optionalpha.com/blog/0dte-options-strategy-performance), [tastylive](https://www.tastylive.com/shows/market-measures/episodes/zero-hour-breakdown-12-01-2025)). На BTC не перевірено.
- Виміряти: щоденні марки 09:00 по чотирьох ногах (**свіжість ніг на день 4 — менша за покриття входу**, ≈ 50 % або менше; для решти — Black-76 за інтерпольованою усмішкою зі знімка, і тоді ціна виходу модельна, без спреду закриття ≈ 1–1.5 вп на ногу, який слід додати). Парне порівняння «вихід за правилом мінус утримання до delivery» по тих самих угодах. Історія частково (дні, де всі ноги свіжі). Внутрішньоденних марок і bid / ask немає — реальний час спрацювання правила невідомий.
- Тип: вихід. Перевірено: ні (стреддл утримували до експірації; `long-strangle-sell-far-strike` — інше правило).
- Потужність: парна SD різниці ≈ 0.6–1.0 % спота, n ≈ 150 (де ноги свіжі), MDE ≈ 0.14–0.23 %; ефект, імовірно, у знаку витрат закриття; виграє переважно CVaR.
- Цінність: ефект на дохід ≈ 0.0–0.1 % за тиждень; на просадку помітніший (найгірший тиждень); ймовірність ≈ 15 % на покращення CVaR 5 %, ≈ 7 % на покращення середнього; вартість 3 год (марки + модельна оцінка). 
- Критик A: **ні (зараз).** Марки лише о 09:00 UTC, ноги свіжі на день 4 у ≈ 50 % і менше, решта — модельна ціна: різниця «правило мінус утримання» вимірює модель, а не ринок, і не бачить bid/ask закриття; «50 % кредиту» за щоденними знімками невизначено за часом. Це ж вердикт слабкого дрібного ефекту на дохід (0.0–0.1 %). Форвард-варіант: записувати внутрішньоденні марки в колекторі, якщо H1 пройде ворота руїни.

**H8. Хедж: смуговий (після руху ±2.5 %) замість щоденного хеджу перпом — для 30-денного тенору й будь-яких структур зі значущою дельтою.**
- Зміна: для 30-денного стреддла (де хедж потрібен; `vrp-real-marks`) і для несиметричних вертикалей хеджувати лише при русі споту на ≥ 2.5 % від останнього хеджу. Тримає ті ж угоди, зменшує комісії (0.05 % обороту) і funding хеджу, яке з'їло 0.26 % [0.14; 0.42] спота за угоду.
- Механізм: частота хеджу — вартість без премії; щоденний хедж платить спред / комісію на шумі. Deribit Insights: «хеджувати стреддли лише після руху 2.5 %» дало сильну ризик-скориговану дохідність у тижневому тенорі (самозвіт статті).
- Джерело: [Deribit Insights](https://insights.deribit.com/industry/bitcoin-options-finding-edge-in-four-years-of-volatility-regimes/); наш розклад у `vrp-real-marks`.
- Виміряти: ті ж 66 угод фази 0 (і 301 п'ятниця тижневих): P&L з хедж-логікою за смугою проти щоденного (парно), годинний funding і ціна перпа є. Історія є, готова логіка (`weekly_straddle.book_path` розкладає по добових інтервалах).
- Тип: хедж / витрати. Перевірено: ні (лише щоденний хедж); розклад витрат — `vrp-real-marks`.
- Потужність: парна різниця має SD ≈ 0.2–0.4 % спота; n = 66 / 300; MDE ≈ 0.07–0.1 % — потужно, але ефект, скоріше, ≈ 0.05 % (комісії хеджу + частина funding).
- Цінність: ≈ +0.03–0.1 % спота за угоду; на місячній стратегії 12 угод → ≈ 0.4–1.2 % номіналу на рік; ймовірність ≈ 25 % (дешево, парно); вартість 1.5 год. Скромно, але вимірно.
- Критик A: **ні.** Хедж потрібен лише стреддлу, який відхилено (`rejected`, руїна) або `inconclusive` (30 д, +0.09 %); модулі H1/H5 безхеджеві. Ефект ≈ 0.4–1.2 % номіналу на рік на стратегії, якої, найімовірніше, не буде; це оптимізація витрат без вихідного плюса. Результат з уже наявного `weekly_straddle.book_path` кванту не потрібен для рішення.

### Тип: структура термінів (календарі, діагоналі)

**H9. Календар: продати тижневий ATM, купити 30-денний ATM того ж страйку (дебет), а не короткий стреддл.**
- Зміна: позиція з обмеженим збитком (= дебет ≈ 2–3 % спота), без голого хвоста; дохід з roll-down фронтальної IV і theta-різниці. Кожного п'ятничного входу.
- Механізм: у контанго (≈ 77.5 % часу, [Deribit Insights](https://insights.deribit.com/industry/bitcoin-options-finding-edge-in-four-years-of-volatility-regimes/); цифра статті — гіпотеза) фронтальна ATM IV вища за відкладену на роллі; платить покупець короткострокової газми (хеджер події / вихідних). Проти: **наш H3 `weekly-straddle-vrp` — тиждень не кращий за місяць на одиницю премії (−0.019 [−0.07; +0.03])**, а календар довгий по vega на 30 д: падіння IV (що зазвичай і є мішенню VRP) б'є довгу ногу. Тому апріорі слабка.
- Джерело: наш `weekly-straddle-vrp` (H3, ✗); [Deribit Insights](https://insights.deribit.com/industry/bitcoin-options-finding-edge-in-four-years-of-volatility-regimes/).
- Виміряти: дебет за марками входу; вихід — марка довгої ноги через 7 діб (свіжа лише за наявності угод у цей день на 30-денному ATM, зазвичай є; ATM-покриття 99.7 %) мінус ціна короткої за delivery; доходність на дебет. Історія є.
- Тип: структура (календар). Перевірено: ні (лише порівняння тенорів за премією).
- Потужність: n ≈ 300, SD ≈ 1.2–1.8 % спота, MDE ≈ 0.2–0.3 % спота; очікуваний ефект, ймовірно, нижче.
- Цінність: ≈ +0.05–0.15 % спота за тиждень; ймовірність ≈ 6 %; вартість 2 год.
- Критик A: **ні.** Автор сам дає апріорі слабку: `weekly-straddle-vrp` H3 (тиждень не кращий за місяць), довга vega на 30 д б'є саме тоді, коли VRP платить; 30-денна нога в календарі свіжа, але вихід за модельним значенням на день 7 — знову модель, а не ринок. Не дублює напряму, але MDE 0.2–0.3 % проти ефекту 0.05–0.15 %.

### Тип: інструмент і капітал

**H10. Доходність на капітал: маржа Deribit (Standard проти Portfolio Margin) і колатерал, як окремий результат, а не лише % спота.**
- Зміна: усі попередні звіти рахують на номінал. Для рішення власника потрібна доходність на капітал: стандартна маржа Deribit рахується окремо для кожної позиції й сумується, портфельна оцінює найгірший сценарій і для спредів «може бути значно нижчою» ([Deribit: Margin types](https://support.deribit.com/hc/en-us/articles/25944811317149), [Portfolio Margin](https://support.deribit.com/hc/en-us/articles/25944756247837)); офіційні сторінки не дають розрахунку для вертикалі. Модуль: порахувати для H1 / H5 річну дохідність на оцінену маржу за PM і за SM та показати різницю.
- Механізм: не премія, а ефективність капіталу; для структури з обмеженим збитком PM може зробити капітал рівним макс. збитку, і це та різниця, що підвищує річну дохідність при тій самій валовій премії.
- Джерело: сторінки Deribit вище; наші висновки Bybit про маржу (`docs/knowledge/options.md`: куповані ноги не зменшують маржу в Regular, лише в Portfolio Margin).
- Виміряти: формули маржі зі сторінок Deribit і калькулятор; **реальні вимоги PM для спреду потрібно підтвердити на живому рахунку власником**; історії маржі немає. Історія P&L — з H1.
- Тип: капітал / інструмент. Перевірено: ні.
- Потужність: не статистичний тест, а облік.
- Цінність: може множити річну дохідність на капітал у 2–5 разів при тому ж P&L на номінал (оцінка скаута — гіпотеза); ймовірність того, що PM дає суттєвий виграш, ≈ 50 %, але вона сама не створює edge; вартість 1.5 год. Брати разом з H1.
- Критик A: **ні як модуль Холма; розділ звіту H1.** Це облік, а не гіпотеза; «множить у 2–5 разів» — гіпотеза скаута без жодної офіційної формули для вертикалі і без доступу до PM власника, а сам P&L від маржі не залежить. Звіт H1 дає річну дохідність на макс. збиток (рахується точно) і на SM/PM-маржу лише як чутливість із явним «припущення, не виміряно»; питання у QUESTIONS до результату не створювати.

**H11. Розмір як ризик-бюджет: фіксована частка капіталу під макс. збиток (≈ 1 % на тиждень, ≤ 3 тижні одночасно) плюс ліміт по просадці, замість «1 BTC номіналу».**
- Зміна: перерахунок сукупності H1 / H5 в одиниці капіталу: ризик на угоду, заходи при серії збитків (пауза після −3 % капіталу за місяць). Не змінює сигнал, змінює рядок «чистий результат за рік» і критерій руїни у валюті капіталу.
- Механізм: у короткої волатильності розподіл лівоскошений; мала частка ризику на угоду дозволяє пережити кластер збитків (березень 2020, травень 2021, жовтень 2025) — власне суть «не ставити весь капітал» зі статті Deribit.
- Джерело: [Deribit Insights](https://insights.deribit.com/industry/bitcoin-options-finding-edge-in-four-years-of-volatility-regimes/) («лише частка портфеля»); `docs/knowledge/risk-management.md`.
- Виміряти: симуляція на серії тижневих P&L H1 (бутстреп блоками 4 тижні, 10 000) — ймовірність просадки > 15 % капіталу за рік, медіана річної дохідності; історія є.
- Тип: розмір. Перевірено: частково критерій руїни (найгірший тиждень), але не в одиницях капіталу.
- Потужність: не тест, а характеристика.
- Цінність: не додає edge, але перетворює «% спота на номінал» на число, яке власник бачить на рахунку; ймовірність того, що результат ніде не покаже «руїни» — залежить від H1; вартість 1 год.
- Критик A: **ні як модуль; розділ звіту H1.** Бутстреп по готовому ряду — переформулювання одних і тих самих 300 тижнів у одиницях капіталу, нової інформації нема; блоки по 4 тижні не охоплять кластер розміру 2020–21. Додає лише один рядок «просадка > 15 % за рік» у звіт H1 за тією самою процедурою; у Холм не входить.

### Тип: розширення вибірки й форвард

**H12. ETH (і BTC разом): ті ж кондори на ETH-опціонах Deribit, об'єднана вибірка для потужності.**
- Зміна: перенести H1 / H5 на ETH і порахувати об'єднаний BTC + ETH ряд (кореляція тижневих P&L висока, тому ефективний n менше за 2×300, але диверсифікує викиди). ETH-марок у кеші немає (`vrp-real-marks`: «ETH-марок у кеші нема»).
- Механізм: той самий платник (покупці страхування); на ETH вищий вол і, ймовірно, більші крила; частка роздрібного попиту на лотерейні ETH-кол — ймовірно, інша (гіпотеза).
- Джерело: наш `vrp-real-marks` (5a не застосовна: один актив); [Alexander, Imeraj](https://sro.sussex.ac.uk/id/eprint/91094/) (BTC; ETH не перевірено мною).
- Виміряти: потрібен збір угод ETH з `history.deribit.com` за 2021–2026 (як put-skew-v2: ≈ 2 год мережі на BTC, ETH — порівнянно), потім каркас H1. **Дані треба завантажувати; це 1–2 дні запусків колектора власника / сервера.**
- Тип: інструмент / потужність. Перевірено: ні.
- Потужність: ефективний n ≈ 1.3–1.5× від BTC; MDE зменшується на ≈ 15–20 %.
- Цінність: сама по собі лише підвищує шанс (імовірність 10 %, залежить від H1); вартість 4–5 год кванта + довгий збір. Брати після H1, якщо H1 покаже знак.
- Критик A: **ні (зараз).** Марок ETH нема, збір 1–2 дні мережі від власника/сервера = нова робота до знаку H1; ефективний n лише ×1.3–1.5 при високій кореляції, MDE −15–20 % не рятує. Умова повернення: H1 дає знак і проходить ворота руїни.

### Що вже закрито і не повторювати
- Голий ATM-стреддл (тижневий, 30-денний, подієвий), короткий 25Δ пут: [weekly-straddle-vrp](../verification/2026-10-15-weekly-straddle-vrp.md), [vrp-real-marks](../verification/2026-10-18-vrp-real-marks.md), [put-skew-v2](../verification/2026-10-14-put-skew-v2.md), [event-day-straddle](../verification/2026-10-15-event-day-straddle.md).
- Купівля денного кола під відкриття США: [catalyst-option-scalp](../verification/2026-10-23-catalyst-option-scalp.md) (`rejected`).
- Внутрішньоденні 0DTE-кондори на Deribit: марок усередині доби й bid / ask немає; чесна відповідь лише форвардна (щоденні знімки колектора + ручне виконання). Окремої гіпотези не винесено: подієвий звіт дає реалізований / premium ≈ 0.90, тобто премія добових опціонів ≈ 10 % і одного спреду достатньо, щоб її з'їсти.
- Піни на великих експірації (max pain, GEX): історії OI по страйках немає; лише форвард (знімки колектора), евристика за інваріантом 8; не винесено.

### Пріоритети для відбору (оцінка скаута, не рішення)
Найвищий очікуваний ефект за найменшу вартість: **H1** (основа, без неї решта не вимірюється; додає угоди й обмежує хвіст), **H8** (парна, потужна, але ефект малий; дешево), **H4** (безперервне масштабування замість 16 точок квінтиля; парна різниця) і **H5** (єдине місце, де наш власний звіт уже дає знак — знижка вихідних; MDE найближчий до очікуваного ефекту). **H10** і **H11** — облік, а не edge: брати разом з H1, бо без них результат лишається «% на номінал». **H7** (вихід) — вигода переважно в хвості, дані частково. Менший шанс: **H2, H3, H6, H9** (наші ж результати мають ◯ або ✗ поруч), **H12** — лише після H1. Чесна межа: для більшості модулів MDE ≥ очікуваного ефекту, тож типовий вердикт — `inconclusive`; єдині потужні — парні (H4, H7, H8). Для всіх: критерій руїни як у `weekly-straddle-vrp` (найгірший тиждень, межа CI середнього), мережі на опціони без історії bid / ask — вхід за моделлю витрат і за ціною сторони продавця.
