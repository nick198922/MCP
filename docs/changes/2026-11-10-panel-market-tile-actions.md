# 2026-11-10 · Панель, правило 2: рядок дії під кожною плиткою «Ринку» (пункт 294)

- «Ринок» (`/brief`): шість плиток без рядка «що робити» (`docs/design/PANEL.md`, правило 2) тепер його мають, нових плиток немає (`scripts/dashboard.py`):
  - ціни BTC / ETH / SOL: за добу ≥ ±3 % — «різкий рух: не входь услід», інакше «звичайний день: рішення за рівнями», без зміни — «зміни за добу немає: дивись рівні» (поріг `BRIEF_PRICE_MOVE` = «до ±3 %» з підказки `price`);
  - DVOL угорі без перцентиля: «перцентиля немає: дивись премію IV − RV30» (раніше рядок зникав);
  - у згорнутому блоці «Волатильність»: DVOL — той самий рядок, що й угорі (30-й / 70-й перцентиль, спільний `dvol_act`); RV30 — RV 7 дн проти 30 дн за підказкою `rv` («ринок пожвавився: ширший стоп, менший розмір» / «ринок заспокоївся: ближчі цілі»); IV − RV30 — з того самого тону `vol_lean`, що й значок «покупцю дешево / дорого» (≤ 0 / ≥ +10 вп), тож рядок і значок не суперечать.
- Тести (`tests/test_dashboard.py`): межі кожного порогу (2.99 / 3.0 %, 0.29 / 0.3 / 0.7 / 0.71, RV7 =, <, > RV30, IV − RV30 −0.01 / 0 / 0.0999 / 0.10), зв'язок `BRIEF_PRICE_MOVE` з текстом підказки, рядки на реальному знімку 20.10 і на зміненому (різкий день, без зміни, без перцентиля, жвавіший тиждень, дорогі опціони).
- Охоронець правила 2 на всіх вкладках: кожен рядок дії ≤ 8 слів (довших 0); плитки ще без рядка — перелік `RULE2_TODO` за ключем підказки, що мусить збігатися з фактом в обидва боки (як `RULE3_TODO`). Зараз у ньому 25 ключів: «Демо» 3, «Мої угоди» 22 (BACKLOG 6.55).
