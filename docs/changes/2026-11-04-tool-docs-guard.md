# 2026-11-04 — тест-охоронець документації інструментів (інваріант 5)

Пункт 46 [IDEA-20261102-standing-improvements](../ideas/IDEA-20261102-standing-improvements.md).

- **Новий тест** `tests/test_tool_docs.py`: обходить усі інструменти `build_server()` і перевіряє, що ім'я кожного стоїть у backticks у рядку таблиці розділу «## Інструменти» `README.md` (згадка деінде в тексті не зараховується). Тест падає і на новий інструмент без рядка, і на запис в allowlist, який уже задокументовано.
- **Прогалин — 0:** усі 108 інструментів уже є в таблиці README. Дописувати в README нічого не довелося; `README_ALLOWLIST` порожній, решти для BACKLOG немає.
- **`docs/PARITY.md` не перевіряється:** це зіставлення інструментів DOUBLETOP з нашими, а не перелік усіх наших; 50 із 108 наших інструментів там немає за задумом (у DOUBLETOP аналога нема і в розділі «Чого в DOUBLETOP не було» їх не перелічують). Тест на PARITY вимагав би або allowlist на 50 записів, або переписати файл — ні те, ні інше не дає користі.
- **Помічено, не змінено:** у таблиці README рядок «MCP-промпти: …» стоїть усередині таблиці (між «Події» і «Prediction markets»), тож GitHub показує його як рядок таблиці. Тест його не зараховує (рядок не починається з `|`); перенести під таблицю можна окремою дрібною правкою.
