# Рев'ю: тест cutoff для звірки S12 (пункт 437)

Режим C. Вердикт: **approve**.

Перевірив сам: `make lint` чисто; `uv run pytest -q tests/test_verify_s12_demo_vs_passport.py` дає 1 passed; `git status --short scripts` порожній (скрипт не змінено); diff картки містить лише рядок пункту 437 і підпункт «Зроблено».

## Висновки

1. Герметичність (ок). `Runtime`, `dvb.venue_fetch`, `dvb.bybit_day_fetch` і `time` модуля підмінено через monkeypatch. Лічильник `offline["fetch"] == 0` підтверджує, що жодного завантаження не було: у синтетичній БД немає демо-угод S12, тому реплеїв немає. БД — копія `migrated_db`, скрипт відкриває її лише на читання (`connect_ro`). Мережі немає.
2. Прив'язка до cutoff (ок). Рядки 381–382 скрипта (`match_rows(..., now_ms=cutoff_ms)`, `decided_ts < cutoff_ms`) і рядок 388 (`summary(..., now_ms=cutoff_ms)`) покриті трьома твердженнями.
   - Другий прогін відбувається на 5 днів пізніше. План 2 закрито через 1 годину після cutoff. Секція й весь звіт мають збігатися з першим прогоном.
   - Очікується `n 2, з R 1, відкрито 1`: план 2 рахується відкритим, а рішення 3 після cutoff відкинуто.
   - Прогін на cutoff + 2 години дає `з R 2, відкрито 0`. Це контрольний випадок: тест не збігається з відкритим станом випадково.
3. Не тавтологічність (ок). Якщо замінити в скрипті `cutoff_ms` на `now`, план 2, закритий після cutoff, у другому прогоні стане закритим, і `a == b` та рядок `відкрито 1` впадуть. Те саме для `decided_ts < cutoff_ms` із рішенням 3. Автор заявляє, що мутацію перевірив; я скрипт не правив (заборонено), але за кодом висновок правильний. Порівняння йде між двома прогонами і з явними очікуваними числами, а не лише між собою.
4. Менш важливо (не блокує). Тест не покриває відсічення закритих демо-угод за cutoff і гілку реплею. Це поза межами пункту 437. Фільтр рядків `seed `/шапки прибирає лише `RSS`-залежний рядок, а інші поля звіту дійсно детерміновані.

Висновок: пункт 437 виконано, вимоги з картки (без мережі, той самий вхід при двох різних `now`, план після cutoff = відкритий, логіку не змінено) дотримано.
