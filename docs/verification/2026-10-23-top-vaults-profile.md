# 2026-10-23 — Профілі топових волтів Hyperliquid (описово)

Запит власника: прогнати профіль волта на інших топових волтах HL. Скрипт `scripts/research/vault_profile.py` (+ `vault_sizing.py`), публічний API HL, дані на 23.10.2026.

**Відбір:** 3 078 відкритих волтів (`stats-data.hyperliquid.xyz/Mainnet/vaults`). Узято користувацькі (без HLP і його дочірніх) з капіталом ≥ $0.3M, віком ≥ 120 днів, топ-12 за PnL за весь час, плюс DOUBLETOP Vault і BredoStrategy. **Це відбір за результатом:** серед найкращих із ≈ 3 000 кілька t ≈ 2-2.7 очікувані й випадково. Поріг Бонферроні для 13 волтів ≈ 2.9.

## Виправлення скрипта (у цьому ж PR)

- **Денний капітал:** тепер `anchored_equity` (остання офіційна точка + перерахований PnL + потоки, без заглядання вперед) замість інтерполяції офіційного PnL. Бети BredoStrategy ті самі; альфа t 0.2 → 1.4.
- **Офіційна дохідність по інтервалах:**
  - на запуску волта (внесок $100 і мільйони депозитів в одному інтервалі) база тепер за Дітцом. Раніше дохідність DOUBLETOP Vault виходила −15 674 %, drkmttr — −157 %;
  - NAV не опускається нижче нуля.
- **Перевірка за учасниками:** медіанна дохідність учасників, що у волті ≥ 90 % його життя (`follower_returns`).
- **Обмеження офіційних тижневих точок:** учасники вносять перед падіннями й виводять на ростах, тож жоден метод не дає точної дохідності. BredoStrategy: офіційні інтервали +145 %, Дітц на всіх інтервалах +290 %, учасник із першого дня без доборів ≈ +117 %. Тому в таблиці дві оцінки.

## Висновки

1. **Три типи волтів:**
   - **Бета під плечем:** Bredo, Enjoyooor, drkmttr, DOUBLETOP, Hyperrr. Результат пояснюють ринок і плече, альфа t ≤ 1.4. Hyperrr показує, чим це закінчується в обвал.
   - **Нейтральні кошики й гріди:** Systemic ×2, Growi, AceVault, Long HYPE/Short Garbage. Низька бета, просадка 12-50 %. Прибуток грідів і Growi береться з внутрішньоденної торгівлі, тому денна реконструкція його не бачить. У Long HYPE/Short Garbage прибуток дає HYPE, а не нейтральність.
   - **Активні малі трейдери:** Delta_01, Jade Lotus, Elsewhere. Найвищі t (2.3-2.7), але капітал ≤ $1M, альфа по третинах згасає, а в Elsewhere давні учасники втратили все.
2. **«PnL за весь час» на сторінці волта не дорівнює дохідності учасника.** drkmttr: +$4.35M PnL при ≈ −6 % на одиницю капіталу. Hyperrr: +$0.9M при −100 % у давніх учасників.
3. **Жоден результат не доведений** з урахуванням відбору. Найкращий t (2.7) нижчий за поріг Бонферроні ≈ 2.9, і ще більше поправки потребує відбір із ≈ 3 000 волтів.
4. **Що варто спостерігати наперед:** Growi HF (найрівніша крива, 2.3 роки), Delta_01 і Jade Lotus (найвищі t, але згасають). Це питання для картки `IDEA-20261015-smart-money-persistence`: чи зберігають сильні перевагу в наступні місяці.
