## Інструменти і ринок
Deribit BTC, опціони на 14–21 день до експірації (місячна/двотижнева серія). Купівля OTM-пута і OTM-кола (≈ ±3 % від форварда) у день T. Далі правило: коли споту за 1–5 днів проходить ±3–4 %, продати страйк на наступному «рівні» (≈ ±8 % від початкового споту) тієї ж серії. Для власника — закриті структури (вертикальний спред), ризик ≤ $100 лишається; це правило ведення, не нова пропозиція ризику.

## Механізм
- **Хто платить:** комбінація двох ефектів. (1) Тета: куплені ноги щодня втрачають; продаж дальнього страйку фінансує її. (2) Якщо при русі до страйку IV росте (спот-вол кореляція, хеджування покупців захисту, особливо для путів), проданий OTM-страйк коштує більше, ніж модель при незмінній IV, і «безкоштовність» досягається. Платить той, хто купує дальній OTM-захист/лотерею після руху.
- **Чому очікування може не змінитися:** проданий страйк оцінений ринком справедливо за поточною усмішкою; якщо усмішка «липка за moneyness», то мартингальна арифметика дає нульову добавку (як у нашому висновку про вихід на 50/80 %). Тоді виграє лише форма: ліміт хвоста і фіксація.
- **Що зламає:** різкий розворот після продажу (куплена нога без підтримки, проданий страйк вже «поряд»); IV-крах після події (FOMC) забирає з обох ніг; коротка нога потребує маржі і має ризик гепа через вертикаль (обмежений куплений страйк — не повний).
- **Твердження автора (самозвіт, без історії):** пут 74k при BTC 77k коштуватиме ≈ $1 600, як куплений 78k; кол 88k при 84.5k — так само. Наша перша перевірка 26.10 на моделі Black-76 з липкою усмішкою: $1 165 / $1 326 / $1 490 (IV незмінна / +3 п. / +6 п.) проти $1 590 — тобто «безкоштовно» лише при IV +6–8 п.

## Гіпотеза
На BTC-опціонах Deribit 2021–2026 (епізоди: купівля OTM ±3 % на 14–21 день, після чого спот проходить ±3–4 % за 1–5 днів, лишається ≥ 8 днів до експірації):
- **H2 (основна, механіка).** Ринкова марка проданого страйку (≈ +8 % / −8 % від початкового споту) на момент проходу ≥ **90 %** (довірчий 95 % — нижня межа ≥ 75 %) марки купленої ноги на вході, у % споту. Наша модельна оцінка — 73–82 % при незмінній IV, тож H2 підтверджується лише за реальної реакції IV. Окремо для верхнього і нижнього боків: очікуємо асиметрію (путова нога виконується частіше).
- **H1 (P&L).** Ведення «продати дальній страйк» дає на експірацію **середній P&L не гірший** за «тримати голий стренгл» і **CVaR 5 % кращий** щонайменше на 1.0 % спота при втраті середнього ≤ 0.3 % спота (після витрат: опційний спред 1.5 вп до IV, комісії Deribit). Порівняння з (б) «закрити ногу на дотику» і (в) «закрити + купити спред далі» (план PDF власника).
- Інтерпретація: підтвердження H2 без H1 означає лише «ріст IV є, але не окуповує обмеження апсайду»; відхилення H2 вбиває «безкоштовність» як тезу автора.

Для реальних котирувань потрібен щоденний знімок ланцюга колектором (форвард ≥ 1 рік), BACKLOG.
- Події FOMC (≈ 40 з 2021) використовуємо лише як **підвибірку** (стрінгл «під кластер подій»), основа — усі епізоди руху ±3–4 %.

## Як тестувати
1. Реєстрація: щодня о 09:00 UTC (кроком 3 дні, щоб розрідити перекриття) умовно купити пут і кол ≈ ±3 % від форварда на серію 14–21 день. Правило тригера: перший день D, коли |спот(D) − спот(T)| ≥ 3 % (≤ 5 днів); продати страйк, найближчий до ±8 % від спота T на тій самій серії, за маркою дня D (мінус 1.5 вп IV).
2. Варіанти: (а) утримання, (б) закрити тригерну ногу, (в) закрити + купити спред далі, (г) F1ntech. P&L на експірацію за delivery price (і відкритий P&L на D+3 як описова метрика).
3. Метрики: відношення марки проданого/купленого (H2), середнє, SD, CVaR 5 %, частка епізодів «профіт ≥ 0».
4. Базовий рівень: нульова добавка, тобто модельна ціна при незмінній IV і липкій усмішці (різниця «ринок мінус модель» і є ефект ведення).
5. Стійкість: підвибірка FOMC; роки; сторона (пут/кол); ширина прольоту ±8 % проти ±6/±10 %.

## Очікувана величина і витрати
Груба оцінка при припущенні невеликої добавки: якщо IV росте на +3–4 п. на дальній страйк, виграш ≈ 0.2–0.4 % спота за епізод порівняно з модельним нулем; ≈ 15–25 епізодів на рік → 3–8 % спота на рік на **одній** ноге (але на капіталі в опціонах $300–$3 000 це ≈ $20–60 на рік для власника при розмірі 0.1 BTC). Витрати: спред Bybit/Deribit ≈ 1–2 % премії на ногу, маржа на проданій нозі. Ємність не обмежує. Це швидше уточнення протоколу ведення, ніж джерело доходу.

## Цінність (до перевірки)
- **Ефект, якщо правда:** при 0.1 BTC на ногу і ~15 епізодах на рік добавка 0.2–0.4 % спота ≈ $15–30 за епізод → **$200–450 на рік** на сумі в ризику $300–$600 за стренгл; більша цінність — правило для монітору позицій (відповідь «що робити при тесті 77k/84k») і зменшення хвоста.
- **Імовірність підтвердження:** ≈ **10 %** для H1 (позитивна добавка після витрат), ≈ 30 % для H2 (≥ 90 %) лише на путовій стороні. Більшість подібних правил ведення в ходу очікування нейтральні (див. `options.md`).
- **Вартість перевірки:** ≈ 5–7 годин Claude, нових даних не потрібно (кеш поверхонь є).
- **Оцінка = 450 × 0.10 / 6 ≈ 7.5 ($ на рік на годину Claude); якщо рахувати «цінність правила» в монітор, помірно вище.** Низька, нижче за картки VRP/skew; брати лише при вільному слоті.

## Потужність (до перегляду даних)
- **n:** епізодів ±3–4 % за ≤ 5 днів, незалежних (крок 3 дні, без перекриття вікон 21 день): ≈ 25–40 на рік × 5.8 років ≈ 150–230 перекритих, ≈ **80–120 ефективно незалежних** (стадія 0 уточнить). Підвибірка FOMC: n ≈ 40, **недостатньо** для окремого висновку, лише описово.
- **SD:** різниця «ведення мінус утримання» на епізод ≈ 1.0–1.5 % спота (приблизна, за порядком вартості ноги 2 % і руху 8 %).
- **MDE:** 2.8 × 1.2 / √100 ≈ **0.34 % спота** (при n = 80: 0.38 %; при n = 40, лише FOMC: 0.53 %). Очікувана добавка 0.2–0.4 % ≈ MDE → тест здатний виявити лише верхню межу. Для H2 (відношення марок) SD нижча (≈ 15 п.п. відношення) → MDE ≈ 4 п.п., цілком достатньо. Тому: **H2 — основна, H1 — другорядна, і її `inconclusive` не вважати провалом.** Якщо стадія 0 дасть < 60 незалежних епізодів, лишити лише H2.

## Критерій «вбити»
H2: нижня межа 95 % довірчого інтервалу відношення марок < 75 % **на обох сторонах** → «безкоштовність» не підтверджена, у базі знань позначити «лише при IV +6–8 п.».
