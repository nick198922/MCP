# Знімок даних асистента (картка assistant, пункт 2)

- `src/tradedesk/collector/assistant_snapshot.py` — завдання колектора `assistant_snapshot` (за замовчуванням вимкнене, `TRADEDESK_ASSISTANT_SNAPSHOT_ENABLED=1`, період `..._SECONDS`, за замовчуванням 600 с). Викликає наші ж read-only інструменти in-process (тикери, OHLCV 120д, страх і жадібність, DVOL, VRP, термструктура, скью, очікуваний рух тижня й місяця, ланцюжок місячної експірації, funding BTC/ETH, макро-календар, Upbit) і пише один JSON.
- Файл: `/var/lib/tradedesk-mcp/assistant/snapshot.json` (або `TRADEDESK_ASSISTANT_SNAPSHOT_PATH`); запис атомарний (tmp + rename), права 644. Поля: `schema`, `asof_utc`, `expiries` (тижнева/місячна), `sections.<ім'я>` = `{ok, data, missing, warnings}`, верхній `missing` — імена секцій без даних. Збій секції не валить завдання; якщо не вдалася жодна секція, попередній файл лишається, а завдання фіксує помилку. Нічого секретного, тексти API — звичайні рядки (екранування під час рендеру).
- Кожна секція має власний `asof_utc`. Якщо оновлення секції не вдалося, а в попередньому файлі вона була справна, переноситься стара (`stale: true`, її власний `asof_utc`, причина збою в `missing` секції); імена таких секцій — у верхньому списку `stale` (не в `missing`). Секції на експірацію (`em_week`, `em_month`, `chain`) переносяться лише для тієї самої експірації. `deribit_vrp` просить 400 днів історії. Помилки інструментів (`is_error`) зберігають справжню причину.
- `analytics/assistant.py` — чисте `pick_expiries`: тижнева = найближча п'ятниця за 2..10 днів (інакше `None`, секція `em_week` у `missing`), місячна = найближча «остання п'ятниця» від 25 днів. Ймовірності діапазонів сценаріїв у цьому кроці не рахуються: у JSON лежить ланцюжок з IV, а розрахунок піде разом із панеллю.
- `scripts/server/19-assistant-snapshot.sh` — для власника: вмикає завдання в `/etc/tradedesk-mcp.env` і перезапускає MCP. Не запускався.
- Тести: `tests/test_assistant_snapshot.py` (щасливий шлях, збій Deribit → секції в `missing` і файл записано, усі секції впали → старий файл цілий, завдання вимкнене за замовчуванням).
