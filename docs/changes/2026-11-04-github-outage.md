- Цикл агентів пережидає збої GitHub (`scripts/agents_loop.sh`, `github_up` / `github_down` / `github_back`). Якщо `git fetch` не проходить і `git ls-remote` теж, крок не починається: цикл перевіряє GitHub кожні 5 хв (`TRADEDESK_AGENTS_GITHUB_WAIT_SECONDS`). Якщо крок упав, а GitHub недоступний, це не рахується як збій, лікар не викликається. Власник отримує одне тихе повідомлення, коли GitHub пропадає, і одне, коли він повертається. Причина: інцидент GitHub 04.11, через який кожен крок падав з кодом 128 і приходило сповіщення.
