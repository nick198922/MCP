## Метод (як зареєстровано, 4.6)

- **Дані:** кеш поверхонь Deribit 09:00 UTC (BTC, 2021–2026, `~/.cache/tradedesk-agents/put_skew`), ціни поставки Deribit 08:00, DVOL. Події FOMC / CPI / NFP з `docs/verification/2026-10-15-us-macro-events.csv` (ET → UTC з літнім часом; скасовані виключено): 182 дні подій 2021-01-08 … 2026-10-02 (FOMC 46, CPI 68, NFP 69; один день із двома подіями).
- **Вхід:** 09:00 UTC дня події; експірація — найраніша після події з DTE ≤ 1.5 д (на практиці завжди денна наступного ранку, DTE 0.96 д для всіх 178 угод H1 і 1027 контролю).
- **H1:** залізний кондор P12 (короткі 25Δ, крила 3 % спота, `condor_dvol.plan_p1`), до поставки; R = P&L / (ширина − кредит), тобто **на капітал під ризиком**; паралельно P&L у % спота на номінал 1 BTC.
- **H2:** різниця середніх R подія − контроль; контроль = пн–пт 09:00 без події в [вхід − 24 год; вхід + 48 год], той самий кондор; кластерний бутстреп різниці з окремим ресемплом груп.
- **H3:** куплений ATM-стреддл (`straddle_p5.plan_straddle`, правило (а) «заміна» для арбітражу марок), до поставки, R = P&L / дебет (премія + комісії).
- **Витрати:** марки Deribit; продані ноги за mark IV − 1.5 в.п., куплені + 1.5 в.п. (Black-76, r = 0, форвард експірації); комісія Bybit на кожну ногу; поставка 0.015 % (≤ 12.5 % внутрішньої вартості). Усі R — після витрат.
- **IS / OOS:** до 2024-01-01 / від 2024-01-01. Кластер — 4-тижневий календарний блок. CI — кластерний бутстреп 10 000, seed 20261114; для H1 / H3 — об'єднання з блоковим бутстрепом (блок 4 угоди). MDE = 2.8 × SE.
- **Вердикт** — рівно `straddle_p5.verdict` (✓: нижня межа CI > 0, Холм < 0.05, OOS > 0, стрес 3 в.п. > 0; ✗: верхня межа < 0, або середнє ≤ 0 і верхня межа < EDGE_R; ≈: середнє > 0 у всій вибірці, IS і OOS; ◯ інакше). EDGE_R H1 / H2 = ¼ × медіана кредит / ширина H1 = 0.045 R (обчислено на стадії 0 без P&L); H3 — 0.10 R.

## Ворота

- **Покриття:** експірація після події є для 182 / 182 днів (100 %); H1 побудовано 178 / 182 = 97.8 %, контроль 1027 / 1048 = 98.0 %, H3 172 / 182 = 94.5 % (пропуски: нема свіжого страйка ноги; арбітраж у марках). Усі ≥ 60 % → пройдено.
- **Хвіст:** H1 — збиткових 47 з 178 у 42 з 76 блоків → пройдено; контроль — 339 з 1027 у 76 / 76 блоках → пройдено; H3 двобічні — збиткових 119 у 68 / 75 блоках, виграшних 53 у 45 → пройдено. Тобто, на відміну від P1′ / P12-H2, вибірка має достатньо збитків, щоб CI був чесним.
- **Параметричний хвіст (стрес-середнє з верхньою межею частки збитків):** H1 −0.097, контроль −0.083, H3 −0.303.

## Застереження

- **Ціни — марки Deribit, витрати — модель Bybit.** Денні опціони мають малу вегу, тож спред у в.п. на них ширший, ніж модельні 1.5 в.п.; стрес 3 в.п. погіршує H1 до −0.022 і H3 до −0.199. Реальний спред денних страйків біля події може бути ще ширшим: для H1 це лише гірше, для H3 (✗) — посилює висновок.
- **Поставка — ціна Deribit 08:00** наступного дня; утримання до поставки без проміжного керування (стоп, ролл). Ліквідація ніг не моделюється: кондор з обмеженим ризиком, стреддл — куплений, маржинального ризику нема.
- **Один актив (BTC)**, 2021–2026; ETH не перевірено.
- **Ризик-нейтральність:** «подієва премія» в IV — ціна, не прогноз руху.
- **H2 ≈** — порівняння двох збиткових або нульових угод; не робить продаж кондора на подію прибутковим.
- Повторна партія (правила пункту 4 повторюються): нічого не закреслено.
