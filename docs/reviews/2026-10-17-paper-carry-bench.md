2. **[середня] Твердження «(в) для B провалиться ~83 % часу при n = 18» спирається на неправильне n.** 18 — очікувана кількість *усіх закритих* угод B за старим бектестом (326 угод за 2 роки). Одиниця (в) інша: угода з ≥ 7 днями. На повній історії B має 397 угод за 1.98 року (~200 на рік), з них ≥ 7 днів 39 % (155/397). За ~41 день це ≈ 22 угоди, із них ≈ 9 з ≥ 7 днями, тобто **нижче мінімуму 10: (в) для B найімовірніше буде ◯**. Якщо набереться рівно 10, то за p = 0.70 ймовірність провалу 62 % (потрібно 8 з 10; P(pass) = 0.38).
   *Виправлення:* у звіті й поправці картки замінити речення на «очікувано ≈ 9 угод ≥ 7 днів до 30.11 → (в) для B, найімовірніше, ◯; при n = 10 провал ≈ 62 %, при n = 18 ≈ 83 % (p = 0.70 поза вибіркою)». Те саме для A вже сказано («◯»). Варто записати **зараз, до старту**, як читатимуть провал (в) для B: за покриття поза вибіркою 70 % провал при 80 % очікуваний навіть за правильного рушія. Тоді провал (в) для B — сигнал нестаціонарності, а не «розбіжність рушія з бектестом». Поріг не змінювати.
