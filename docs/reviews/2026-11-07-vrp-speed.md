- Порівняння з `options.black76_greeks` (рядки 53-64), `ncdf` (26-27), `d1d2` (38-41):
  1. Гілка `t <= 0 or sigma <= 0` дає delta 0.0 для колла й пута, сума 0.0. Інлайн дає `target = 0.0`. Збігається.

  3. `s <= 0` або `k <= 0`: `math.log` кидає `ValueError` і в старому, і в новому коді, поведінка однакова. Вхід у цю функцію гарантує `close > 0` (є перевірка вище за diff), нового ризику немає.
