## Знахідки

### 1. [Блокер, формулювання і висновок] Ворота A − B провалює один день, а не брак історії

Я перерахував SE, без середніх:

| Варіант | MDE(A) | SE(B) | MDE(A − B) |
|---|---|---|---|
| як зареєстровано | 0.82 % | 0.40 % | **1.42 %** |
| без дня 2025-10-10 (5 подій A, 23 B) | 0.81 % | 0.23 % | **0.94 %** |
| дохід обрізано до ±30 % | 0.80 % | 0.22 % | 0.97 % |
| без 5 найбільших \|дохід\| у кожному кошику | — | — | 0.99 % |

Майже вся SE кошика B і різниці береться з каскаду 10.10.2025. IPUSDT +334 % за 2 год, SUIUSDT +172 %, EIGENUSDT +134 % тощо. Дані справжні: я перевірив 1m-свічки IPUSDT, ціна пройшла 7.76 → 1.116 (21:19) → 4.848 (23:19). Але вхід за close 1m-бару на самому дні віку в момент, коли біржа перевантажена, фактично не виконуваний. Звіт натомість пише: «A − B потребує в (1.42/1.20)² ≈ 1.4 раза більше днів, ніж дає вся історія». Це неправда: без одного дня ворота A − B пройдено з запасом.

Вердикт від цього не змінюється. MDE(A) лишається 0.80–0.82 % майже в усіх варіантах, тобто на межі або вище порогу. Потужність H1 при +0.5 % становить ≈ 40 % за будь-якого варіанту. Обидва факти разом є справжньою причиною, чому повторний тест на історії має низьку цінність.

**Виправлення.** У розділі «Чому не пом'якшую ворота і що далі», у вердикті картки, у `setups.md` (S9) і в рядку README бази знань:
(а) прибрати аргумент «1.4 раза більше днів»;
(б) написати, що MDE(A − B) визначає хвіст одного дня 2025-10-10, а без нього MDE ≈ 0.94 % (ворота пройдено). Позначити це як дослідницьке, не на вердикт;
(в) назвати обмеженням, що прив'язує, MDE(A) ≈ 0.8 % проти порогу H1 +0.5 % (потужність 40 %);
(г) додати, що вибір воріт для будь-якої нової картки на цій вибірці (вінзоризація, виключення днів збою біржі) уже не сліпий: SE під цими варіантами відомі.

### 4. [Середня, lookahead на майбутнє] Хвіст найкращого k > 0 для рядка, спостереженого в T
