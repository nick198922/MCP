# 2026-11-07 — один тег версії угоди в чекпоінті та в статистиці за версіями

Пункт 228 [IDEA-20261102-standing-improvements](../ideas/IDEA-20261102-standing-improvements.md), лишок пункту 225 ([2026-11-07-demo-inputs-tests](2026-11-07-demo-inputs-tests.md), «Знайдено»).

- **Що було:** `checkpoint._versioned` передавав у `applies` / `version_of` сиру назву сетапу, а `setup_versions.version_stats` спершу обрізав пробіли (`_setup`). Угода S12 з назвою `" S12 "` після 31.10 у чекпоінті отримувала `v3`, а у статистиці за версіями `v9` (або власний тег із колонки `version`).
- **Що зроблено:** `_versioned` нормалізує назву тією самою `setup_versions._setup`. Для чистих назв, порожньої назви й угод без сетапу теги не змінились.
- **Тести:** у `tests/test_analytics_demo_inputs.py` додано 2 функції (13 випадків): `" S12 "` і `"S12\n"` з `version` None / `v9` / `v7` дають однаковий тег у `_versioned` і `version_stats`. На старому коді 6 випадків червоні. Чисті S28 / S1 / None / `""` зберігають свої теги.
- `execution/`, `core/`, колектори й реєстрації не змінено.
