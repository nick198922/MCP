## Читання
- Витрати кола домінує комісія 0.09 %; медіанні спреди за іменами — 0.00–0.17 % на ногу (окремі сесії можуть бути ширшими). Ліквідні імена (SPY, QQQ, MSFT, AAPL, TSLA, NVDA…) дають 0.09–0.10 % за коло; ≤ 0.15 % має 58 % імен (77 % при половині спреду), медіана медіан 0.137 %. Яка з мір рахується для умови повтору кроку 0 «≤ 0.15 % за коло», не визначено: це вирішить реєстрація повтору кроку 0, тут умову не оголошуємо виконаною.
- Дорогі хвости (≥ 0.20 %): тонкі та левериджні тікери (SHAZ, QNTX, NOK, USAR, SNXX, HIMS, KORU, CRWD…). Ранги стабільні (ρ 0.95); відбір дешевої чверті — лише дослідницька ідея: найдешевші імена — мега-кап й індексні ETF, де механізм картки найслабший, а менший набір ускладнює ворота потужності G2; будь-який такий фільтр потребує нової реєстрації до повтору кроку 0. Комісію 0.045 % на ногу взято з картки, перед кроком 0 звірити з таблицею комісій Binance.
- Це лише про витрати, а не про наявність сигналу: edge ночі (G2: MDE ≤ 0.10 %) цим прогоном не перевірявся. Спредова умова не блокує картку, але й не підтверджує edge.
- Обмеження: спред — знімок раз на хвилину (as-of ≤ часу входу/виходу), номінальний, не глибина на розмір угоди; 20 сесій — один режим ринку.
