#### Форвард (паперовий; тег `idea:bcx3-negfunding-squeeze` у плані угод, критик ставить `forward`)

- **n для вироку:** ≥ 30 незалежних тригерів (не більше одного на монету на добу). Якщо за 12 тижнів набрано < 30 — закрити як нерозв'язне за частотою (`inconclusive`), без продовження.
- **Критерій вбивства:** після 30 тригерів середній чистий результат ≤ 0R, або нижня межа 90 % CI < −0.3R; раніше — зупинка, якщо після 15 тригерів середній ≤ −0.5R. Потужність: SD ≈ 1.3R, n = 30 → MDE ≈ 0.7R, тож форвард судить лише про великий ефект; помірний (≈ 0.1R) судити нічим — це сказано чесно.
- **Статус у `docs/knowledge/setups.md`:** сетап не додавався (нема власного опису правил автора); ◯ на старті форварда.
