# 2026-11-14 · Опціонні ідеї за правилами плейбуку (картка options-playbook, пункт 2, перший зріз)

- `src/tradedesk/analytics/option_ideas.py`: таблиця `RULES` — усі 15 правил [плейбуку](../knowledge/options-playbook.md) (назва, умова з інструментом MCP і полем, конструкція, статус ✓ / ≈ / ◯ / ✗ / не перевірено, текст доказів, посилання на розділ). Надсилається лише правило, умову якого міряє інструмент MCP і статус якого не ✗; ідеї впорядковано за доказами, до 3 на монету. Пороги — з плейбуку (`DVOL_PCT_HIGH` 0.8, інверсія фронту +1.5 п., RR25 −5 п. і розворот 1 п. за 3 доби), не підбиралися.
- Знято з розсилки: кондор за IV ≥ RV (P1, ✗) і стренгл за IV < RV (P4, ✗); унизу повідомлення рядок «Не надсилаємо (✗ у плейбуку)». Угоди зараз дає лише P3 (200-денний тренд → дебетовий спред, «не перевірено»). Контекст без угоди: P2 (DVOL ≥ 80-го перцентиля, ◯), P9 (подія ≤ 48 год, ✓ як правило ризику), P10 (інверсія фронту перед FOMC / CPI, не перевірено), P15 (RR25 ≤ −5 п. і розворот, ◯).
- Кожна ідея й кожна позначка мають рядок «Правило: <код назва> · докази: …»; у журнал ідей пишуться код правила (`rule`) і всі перевірки умов (`context.checks`) — для підсумку за правилами в пункті 3.
- `scripts/option_ideas_tg.py` бере умови з інструментів MCP у своєму процесі (`deribit_vrp`, `deribit_atm_term`, `macro_calendar`, `skew_percentile` через `build_server()` і MCP-клієнт); `skew_percentile` читає історію колектора з `TRADEDESK_DB_PATH` (за замовчуванням — `--db`, БД сервера). Збій інструмента лишає правило «не виміряно», ідеї інших правил ідуть.
- Живий прогін 14.11 (`--print`): ETH — пут-спред 1875/1700 за P3; BTC — тренд нейтральний, ідей нема; P2 ні (перцентиль 0.53 / 0.41), P9 і P10 ні (подій до 8 д нема), P15 ні (ETH RR25: мінімум −5.3 п., зараз −4.4 п., розворот 0.9 < 1.0).
- Тести: `tests/test_option_ideas.py` — кожне правило (умова виконана / ні / не виміряно), таблиця збігається з заголовками плейбуку, ✗ і невимірювані не надсилаються, порядок за доказами, повідомлення, збій інструментів.
- Не зроблено: конструкція P10 (календар за цінами Bybit; потрібен розрахунок довшої ноги на експірації фронту) — у BACKLOG.
