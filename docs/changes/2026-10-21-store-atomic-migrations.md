- `Store.init`: each migration block now runs in an explicit `BEGIN IMMEDIATE … COMMIT` together with its `PRAGMA user_version` bump, and rolls back on error. Before, Python `sqlite3` committed every `ALTER TABLE` on its own, so a crash mid-block left the columns without the version and the next start failed with "duplicate column". A failed `init()` also closes the connection instead of leaving a half-open store that skipped migrations on retry (and kept the process from exiting). Test: `tests/test_store.py::test_migration_block_is_atomic_and_retried_after_a_failure`.
