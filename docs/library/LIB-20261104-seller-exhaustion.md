## Тези
- **Визначення (з джерел, не з поста):** Seller Exhaustion Constant = частка пропозиції в прибутку × 30-денна волатильність ціни. Автори показника — ARK Invest і David Puell, у Glassnode він є як `SellerExhaustionConstantPit`. Низьке значення означає «багато монет у збитку + тиша»: продавці, що панікують, уже вийшли. Кількісна.
- Показник опустився до мінімумів, типових для ведмежих ринків. Кількісна: 0.0498 на 04.11.
- Історично такі мінімуми створювали умови для дна. Якісна.
- Розвороту це не гарантує: для відновлення потрібен попит, якого бракує. Якісна.

## Як це може дати гроші
- **Контекст режиму, а не сигнал входу:** компонент `cycle_regime` або фільтр сторони для сетапів (див. пункт «режим ринку задає дозволену сторону» в [IDEA-20261030-demo-setups-depth](../ideas/IDEA-20261030-demo-setups-depth.md)). Наприклад, «шорти BTC/альтів не відкривати, коли SEC < 0.05».
- **Нове безкоштовне джерело ончейн-даних.** Bitview (bitview.space, відкритий код MIT, `bitcoinresearchkit/mono`) має публічний API: `/api/series/<name>/day1/data?start=YYYY-MM-DD`, пошук `/api/series/search?q=…`. Там є `supply_in_profit_share` (з 2011, денна), `realized_price`, когорти LTH/STH, URPD. У `docs/knowledge/regime-indicators.md` «пропозиція у збитку» досі позначена ◯ «без безкоштовних ончейн-даних», а це джерело її розблоковує. Ліміти API не задокументовані.

## Перевірювані гіпотези
Перша розвідка Claude з чату 04.11. Скрипт разовий, у репозиторій не входить; розраховано з `supply_in_profit_share` і `price` Bitview, день 1, 2011-01-01 … 2026-11-04. Формула: частка/100 × σ(денних лог-дохідностей за 30 днів) × √30. На 04.11 вийшло 0.0506 проти 0.0498 на графіку, тобто визначення відтворено. Це не реєстрація, а підстава для неї.

- **H1. SEC < 0.05 → BTC вище через 365 днів.** Епізоди (перший день під 0.05 після ≥ 120 днів без сигналу; дохідність за 90 / 180 / 365 днів; найгірша просадка за рік):
  - 2013-01-04: $13, +928 % / +490 % / +6 202 %, 0 %;
  - 2014-07-30: $562, −37 % / −52 % / −49 %, −69 %;
  - 2015-04-26: $219, +31 % / +27 % / +113 %, 0 %;
  - 2016-03-21: $412, +85 % / +46 % / +169 %, 0 %;
  - 2018-10-23: $6 427, −45 % / −18 % / +16 %, −50 %;
  - 2022-10-15: $19 057, +4 % / +59 % / +43 %, −17 %;
  - 2023-07-21: $29 849, −4 % / +43 % / +124 %, −16 %;
  - 2026-05-19: $76 740, −16 % за 90 днів, далі ще не минуло; найнижче значення 0.028 — 16.08.2026.

  Через рік вище в 6 з 7 завершених епізодів, а базова частка «вище через рік» для всіх днів з 2013 — 69 %. При n = 7 це статистично не відрізнити. Сигнал рано спрацьовує: у 2014 і 2018 після нього ще −50…−69 %. Середні по днях (+172 % за рік) тягне 2013, тож ними не користуватися.
- **H2. Відносний поріг не працює.** Варіант «нижче 10-го перцентиля за останні 4 роки» дав промахи 2022-04 (−26 % за рік, просадка −59 %) і 2025-08 (−44 %). Зберігати абсолютний рівень 0.05 (поріг Glassnode/поста, не підібраний нами), але волатильність BTC з роками падає, тож поріг дрейфує. Це треба перевірити окремо.
- **H3 (для агентів).** Чи покращує «SEC < 0.05 → без шортів» або «SEC < 0.05 → лонг-ухил» результат сетапів демо на 2018–2026? Механізм: капітуляція завершилась, продавців мало, і шорт на свипі низу б'є відсутність пропозиції. Дані: Bitview (є, безкоштовно) + паспорти сетапів. Це можна поєднати з пунктом про режим ринку в картці сетапів демо, щоб не ганяти два тести окремо.
- **Застереження:** незалежних циклів 3–4, отже потужності мало, і очікуваний вердикт — `inconclusive`. Ончейн-оцінка «прибутку» UTXO (ціна останнього руху) — наближення: біржові гаманці, обгортки та ETF-кастодіани змішують когорти.
