# ADR 0004 — Режим «працює, поки сплю»

Статус: прийнято як напрям; хостинг не підтверджено власником.

**Рішення.** Один довгоживучий процес (asyncio): MCP-сервер (streamable-http) + збирач даних + WebSocket-читачі + рушій правил/алертів. Сховище — SQLite (WAL) на диску VPS з регулярним резервним копіюванням. Деплой — Docker/systemd на постійно ввімкненій машині (VPS 1–2 vCPU / 2 GB достатньо). Доступ назовні — лише через автентифікацію (bearer/Tailscale) і TLS.

**Чому не ноутбук.** Сон/відсутність мережі зупиняють збір історії й алерти. **Чому не serverless.** Потрібні довгі WebSocket і локальний стан.

**Чому SQLite.** Один процес, прості резервні копії, достатньо для мільйонів рядків; міграція на Postgres/Timescale можлива, якщо зʼявиться потреба.

**Відкрито:** вибір провайдера VPS, канал алертів (Telegram?), IB Gateway на сервері (IBKR).
