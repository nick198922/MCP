# Питання до власника

Агенти додають сюди питання, коли рішення може ухвалити лише власник (напрям, ризик, гроші, нові джерела даних). Відповідайте прямо в полі «Відповідь власника» і змініть статус на `answered`. Поки питання `open`, пов'язана робота стоїть.

Формат:

```
## Q-РРРРММДД-N: коротка назва
Статус: open | answered
Контекст: що з'ясували і чому потрібне рішення.
Варіанти: 1) … 2) …
Рекомендація агентів: …
Відповідь власника:
```

---

## Q-20261106-1: який поріг «великого збитку» для правила «48 год перерви»
Статус: open
Контекст: правило 4 (`docs/knowledge/trading-strategy.md`) каже «після дня з великим збитком — 48 год перерви», порогу не називає. Реалізовано буквально: день UTC із закритим P&L ≤ −2 % депозиту, перерва з 00:00 UTC наступного дня на 48 год ([зміни](changes/2026-11-06-rule-48h-break.md), [рев'ю](reviews/2026-11-06-rule-48h-break.md)). На журналі це 21 такий день, порушень правила 4 стало 134 замість 60.
Варіанти: 1) лишити −2 %; 2) інший поріг (параметр `big_loss_pct`); 3) інший початок перерви (від моменту збитку).
Рекомендація агентів: 1, поки власник не назве свій поріг.
