# 2026-11-12 — зіпсовані рядки сховища: `enabled` правила і `tags` позиції (пункт 328)

Інваріант 1 `CLAUDE.md`; відкриті питання з `docs/changes/2026-11-08-tool-failure-tests-6.md` і знахідки 5 рев'ю `docs/reviews/2026-11-08-tool-failure-tests-6.md`.

- **`enabled` правила.** Сховище читало `bool()` будь-якого значення, тож текст "false" / "true" / "yes", 2, -1, 0.5 у `rules_list` показувались як `enabled: true`, порожній текст як `false`, а blob після `bool()` проходив повз перевірку blob-ів. Тепер `rule_get` / `rules_list` у сховищі перетворюють на bool лише ціле 0 / 1, а `drop_corrupt_rows` має параметр `flags`: `rules_list` пропускає такий рядок із попередженням (якщо зіпсовано все, то `ok=false`). `rules_disable` записує 0 / 1 поверх зіпсованого значення й повертає вже виправлений рядок. Текст "0" / "1" і 1.0 SQLite сам зберігає як 0 / 1 (INTEGER affinity), тож такі рядки валідні. Alerts-джоб не зачеплено: він вибирає `enabled = 1` у SQL і тих рядків ніколи не бачив.
- **`positions_list` і `tags` "[NaN]".** Цей випадок уже оброблявся з пункту 296 (`finite_json`): рядок пропускається з попередженням. Тепер він закріплений тестом разом з "[Infinity]", "1e400" і `{"x": NaN}`. Знайдено новий випадок: глибоко вкладений масив (`[[[...]]]`) кидав `RecursionError` з `json.loads` у сховищі, і весь інструмент падав (той самий шлях у `positions_close`, `positions_risk`, `journal_list`). Тепер такий рядок читається як порожні теги, як будь-який нерозбірний текст. JSON, що не є списком (`5`, `{"a": 1}`), повертається як є: він скінченний і нічого не ламає.
- Новий `tests/test_tool_failure_extra_18.py` (48 тестів, зокрема з незмінним happy path). Номер 7 уже зайнятий тестами пункту 289. Опис `rules_list` тепер згадує, що зіпсовані рядки пропускаються. `execution/` не чіпали, нових інструментів немає.
- Відкрите: `_parse_carry_paper_row` і `_parse_json_cols` (`trade_plan`) так само ловлять лише `TypeError` / `ValueError` у `json.loads`, тож глибоко вкладений JSON там не перевірено. `stopped` / `entry_tradable` у carry-paper теж читаються через `bool()`.
