# База знань агентів

Агенти не пам'ятають попередніх ночей: усе, чого вони «навчились», має лежати у файлах. Бібліотека (`docs/library/`) — це окремі матеріали (відео, пости), а тут — **теми**: як працює ринок, індикатори, методики трейдерів і що з цього підтвердили наші власні перевірки. Скаут, квант і критик читають потрібні нотатки перед роботою над темою.

**Книга сетапів:** [`setups.md`](setups.md) — практичний підсумок бази знань: «коли лонг, коли шорт, коли кол чи пут», для кожного сетапу умови, вхід, стоп, інструмент і статус перевірки (✅ / ≈ / ◯ / ✗). Скаут додає сетапи з кожного матеріалу бібліотеки, квант оновлює їхній статус після перевірки.

## Як влаштована нотатка

Один файл на тему, `docs/knowledge/<тема>.md`:
- **Суть** — як це пояснюють автори (з посиланнями на записи бібліотеки й кадри);
- **Механізм** — хто платить і чому це може працювати (або чому ні);
- **Що показали наші перевірки** — звіти `docs/verification/` з вердиктами ✓ / ≈ / ✗ / ◯;
- **Відкриті гіпотези** — картки `docs/ideas/` чи гіпотези з бібліотеки, які ще не перевірено;
- **Як користуватись зараз** — практичний висновок для власника (часто: «як правило ризику — так, як перевага — не доведено»).

Нотатку оновлює скаут, коли розбирає матеріал бібліотеки на цю тему, і квант, коли перевірка дає вердикт.
