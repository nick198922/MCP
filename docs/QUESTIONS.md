# Питання до власника

Агенти додають сюди питання, коли рішення може ухвалити лише власник (напрям, ризик, гроші, нові джерела даних). Відповідайте прямо в полі «Відповідь власника» і змініть статус на `answered`. Поки питання `open`, пов'язана робота стоїть.

Формат:

```
## Q-РРРРММДД-N: коротка назва
Статус: open | answered
Контекст: що з'ясували і чому потрібне рішення.
Варіанти: 1) … 2) …
Рекомендація агентів: …
Відповідь власника:
```

## Q-20261102-1: чи стосується заборона «нових запитів до DefiLlama» (Q-20261023-2) лише розкладів анлоків?

## Q-20261103-1: Polymarket v1 — що робити з позиціями без знімка +24 год (дірка не випадкова)
Статус: answered
Контекст: [звіт](verification/2026-11-03-pm-gap-24h-gaps.md), [рев'ю](reviews/2026-11-03-pm-gap-24h-gaps.md) (approve): 3 із 7 позицій, що рахуються в основній метриці, без знімка +24 год; причина — не колектор (знімки щогодини), а ринки «touch» зникають зі списку після закриття, тож пропуск залежить від розв'язання ринку. Те саме для closing-CLV: `missing` 20.5–22 % (поріг реєстрації 20 %). Звіт частково розкрив напрям (див. «Застереження»); сторони й значення позицій ніхто не дивився.
Варіанти: 1) (b) звітувати обидва варіанти метрики + частку рано розв'язаних (рекомендація рев'ю); 2) (a) 1/0 виплата як значення +24 год, позначена «поправка після часткового розкриття»; 3) колектор записує момент закриття ринку й результат Gamma (зміна збору, лише вперед).
Рекомендація агентів: 1 + 3.
Відповідь власника: 1+3

## Q-20261106-1: який поріг «великого збитку» для правила «48 год перерви»
Статус: open
Контекст: правило 4 (`docs/knowledge/trading-strategy.md`) каже «після дня з великим збитком — 48 год перерви», порогу не називає. Реалізовано буквально: день UTC із закритим P&L ≤ −2 % депозиту, перерва з 00:00 UTC наступного дня на 48 год ([зміни](changes/2026-11-06-rule-48h-break.md), [рев'ю](reviews/2026-11-06-rule-48h-break.md)). На журналі це 21 такий день, порушень правила 4 стало 134 замість 60.
Варіанти: 1) лишити −2 %; 2) інший поріг (параметр `big_loss_pct`); 3) інший початок перерви (від моменту збитку).
Рекомендація агентів: 1, поки власник не назве свій поріг.
Відповідь власника:
