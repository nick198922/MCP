# 2026-10-22 — демо-трейдер: беззбиток за половиною шляху до цілі

- Рішення власника 22.10: стоп переноситься в беззбиток (вхід + обидві комісії тейкера), коли ціна пройшла 50 % шляху від входу до цілі. Раніше тригером було +30 % ROE.
- Причина: ROE залежить від плеча (20x / 10x / 5x), а ризик від плеча не залежить. На BTC +30 % ROE — це ≈ 0.75R, на монетах з плечем 5x — 2–5R, тобто здебільшого далі за ціль.
- Код: `execution/guard.py` (`BE_PATH = 0.5`, `path_to_target`), `execution/demo_trader.py` (`manage`, повідомлення «пройдено N % шляху до цілі (+xR)», аудит `path` і `r`).
- Тести: `tests/test_execution_guard.py::test_path_to_target`, `tests/test_demo_trader.py` (тригер, один раз, уже стоїть на біржі).
