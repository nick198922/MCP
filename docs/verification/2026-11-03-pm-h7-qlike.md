1. SD_тиж за реєстрацією — об'єднаний по парах (зсув, тиждень); неповні W43 (SD 0.139) і W45 (SD 0.040) тягнуть його вгору. Оцінка на W44 — розвідувальна; вона теж дає N* ≫ 20.
2. Повтор вважає ETH повністю корельованим з BTC і бере рівень з 7-денної RV (шумніша за IV) — для ETH консервативність показано, для заміни IV на 7-денну RV вона правдоподібна, але не перевірена; SD може бути завищений; але навіть у 3 рази менший SD воріт не проходить.
3. Розділ «Попередня реєстрація 8l» уже існував з 2026-11-01 (усі чотири вимоги: правило часткових годин, джерело барів Binance 1h спот, нейтралізація рівневого зсуву s′ = s / m без підгонки, ворота потужності).
