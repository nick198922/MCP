# Сумісність із Python 3.11 і для `tests/` (пункт 178)

- `tests/test_python_compat.py` тепер сканує і `tests/**/*.py` тими самими перевірками: синтаксис 3.12+ (разом із f-рядками PEP 701) і таблиці імен та аргументів stdlib 3.12/3.13. `tests/fixtures/` виключено, бо там записані дані, а не код (`.py` там зараз немає).
- Додано 321 файл (усі лежать у корені `tests/`), разом сканується 947 файлів. Тест-файл: 1026 passed (було 705) на 3.11.17, 3.12.3 і 3.13.16.
- **Порушень 0, виправлено 0**, `ALLOWED` порожній. Окремий контроль: усі 321 файл компілюються справжнім Python 3.11.17 (0 помилок). Grep за назвами з таблиць знаходить у `tests/` лише `ast.walk` / `os.walk`, локальну змінну `override` і коментарі; детектор їх правильно не позначає.
- `test_scope_is_the_whole_tree` додатково перевіряє, що в списку є `tests/conftest.py` і сам тест-файл, а файлів із `tests/fixtures/` немає.
- `src/`, `scripts/`, `execution/`, колектори й реєстрації не змінено; інші тести не змінено.
