# Контрольна точка: орфани демо — коридор, а не лише гірший випадок (пункт 338)

- `src/tradedesk/analytics/checkpoint.py`: поряд зі сценарієм «кожну закрито за стопом (−1R)» у примітці рядка сетапу демо
  з'явилась межа «орфани = 0R» (константа `ORPHAN_FLAT_R`): середній R за n + орфани і, коли n + орфани ≥ 30, вердикт
  проти смуги рішення того самого n (як у сценарії −1R).
- Вибірка, n, середній R і вердикт самого рядка не змінюються; змінюється лише текст примітки.
- Тести в `tests/test_checkpoint_report.py`: текст «−1R» лишився; межа 0R з числами, перерахованими вручну
  ((28·0 + 2·0)/30 = 0, (30·(−0.6) + 20·0)/50 = −0.36, (3·(−0.3) + 0)/4 = −0.225 без вердикту, бо n + орфани < 30).
- Користь: на розборі 30.11 видно коридор між −1R і 0R; «узгоджується» не читається ні гірше, ні краще, ніж є.
