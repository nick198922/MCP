- Картка [onchain-parity](../ideas/IDEA-20261114-onchain-parity.md), пункт 5: два інструменти пулів дохідності DefiLlama (`yields.llama.fi`, без ключа) — `yield_pools` (перелік пулів з фільтрами `chain` (з псевдонімами eth / arb / sol …), `project`, `min_tvl_usd`, `stablecoin_only`, сортування `tvl_usd` / `apy` / `newest`, `limit` ≤ 200) і `yield_pool_history` (денний TVL і APY одного пулу за `days`, зміни TVL 7д / 30д, середній APY 7д / 30д, min / max APY у вікні, початок історії, «застарілість» останньої точки).
- Одиниці: DefiLlama віддає APY у відсотках, інструменти — десятковими частками (0.05 = 5 %), зміни APY — у десяткових пунктах. `apy = apy_base + apy_reward`: базовий — комісії / відсотки пулу, винагородний — у токенах за поточною ціною.
- Застереження в описі й `warnings`: APY оголошений, ретроспективний і змінний, не гарантія; винагорода падає разом з ціною токена й закінченням емісії; без IL, газу, комісій входу / виходу й прослизання; назви пулів і токенів — недовірений текст. Ризик токенів / адрес не дублюємо: опис і `warnings` ведуть на `contract_risk` (GoPlus + honeypot.is); нового провайдера ризику не писали.
