## Контрольна точка вартості 3.3 (лише лічильники, без цін) — рішення

**Правило 3.3, застосоване механічно:** W₁₂ = 55.2 < 99, отже MDE при sd 12 % > 3 %. Первинний набір префікса 49 ≥ 40 (і 48 без відомих `no_data` теж ≥ 40), тож запасне правило «брати наступний квартал» не діє. **Рішення: перепис зупиняється на префіксі з п'яти кварталів (2020-Q1, 2020-Q2, 2021-Q4, 2022-Q1, 2020-Q3), причина — «вартість / потужність».** Решта сім кварталів (2021-Q2, 2021-Q1, 2021-Q3, 2022-Q3, 2022-Q4, 2020-Q4, 2022-Q2) до вибірки не входять. Рішення залежить лише від лічильників без цін, заборону пропускати окремі квартали не порушено.

**Стійкість рішення до правок рев'ю B і до відповіді Q-20261118-2** (перераховано `bc_20q3_weeks.py` після правок тегів):
