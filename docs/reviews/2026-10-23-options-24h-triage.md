# Тріаж: три картки про опціони до 24 год (23.10.2026)

Режим A. Перевірено самостійно: три картки, розділи «Ширше» і «Тріаж критика» картки `IDEA-20261022-catalyst-option-scalp`, звіт event-day-straddle (відношення 0.90, `entry_quote`, кеш `trades24`/`quotes_v1`), наявність Bybit-опціонів у коді (їх немає, лише згадки в документах). Арифметику усереднення розрахунку (дисперсія σ²(τ − 1/3)) перерахував вручну: сходиться. Правило 8 жодна картка не змінює.

## Вердикти

| Картка | Вердикт | Імовірність / вартість |
|---|---|---|
| `daily-iv-vs-intraday-vol-forecast` | accepted з умовами 1–6 (шлюз спершу) | ≈ 4 %, ≈ $50/рік за 7 год: довгий шанс, єдиний у трійці |

Правило «не більше одного довгого шансу»: accepted лише перша; третя йде як форвард.

## 1. daily-iv-vs-intraday-vol-forecast (accepted)

1. **Серйозно (виправлено в умові 1).** Шлюз як записаний: нахил ln(|r|/премія) на g = ln(IV/σ̂). Премія стоїть і в залежній змінній, і в g, тому шум у принтовій IV дає нахил ≈ −1 без жодного сигналу: шлюз пройшов би помилково. Замінити на інкрементальну регресію ln|r| ~ ln IV + ln σ̂ (c > 0). Помилка вимірювання IV зміщує c вгору: усереднення принтів [07:00; 09:00] і чутливість.
2. **Середньо.** Основний зріз «верхній проти нижнього терцилів» має MDE 0.41–0.5 % при очікуваному +0.4 %: `inconclusive` майже напевно. Замінено на верхній проти решти (MDE ≈ 0.36 %), нижній терциль — описово.
3. **Середньо.** Крила 1 % при премії денного стреддла 2.2 % з'їдають приблизно половину кредиту. Торгова частина слабка навіть якщо шлюз пройдено; цінність виправлено до ≈ $50/рік. Купівля крил = виняток із правила 8, рішення власника.
4. **Дрібно.** Перекриття коду й даних із прийнятою карткою weekend-vol-discount: вихідні виключити або показати окремо.
5. Відмінність від відхилених (weekly-straddle-vrp, vrp-real-marks, high-dvol, event-day) підтверджую: умова тут — розрив IV та прогнозу на наступні 24 год, ризик обмежений.
6. Kill-критерій придатний; додано: c = 0 на IS або протилежний знак на OOS → `rejected`.

## 2. deribit-twap-settlement-last-hours (rejected)

1. Механізм правильний (Deribit delivery = 30-хв TWAP), але це публічна контрактна механіка: мейкери експірованих контрактів її закладають. Картка сама ставить імовірність 5 %.
2. Економіка за картки: валова надбавка ≈ $8 на 0.1 BTC, комісія 7 % премії + півспред 4–6 % + крила: чисто $0–2 на угоду, $0–600/рік. Розмір не перекриває витрат, ємність ≈ 50 BTC. Це причина відмови, не «мало подій».
3. Потужність: чистий ефект ≈ 3 % < MDE 7.6 % (OOS 10.7 %) — вердикт про торгівлю `inconclusive` до початку.
4. Дефект дизайну: R = середнє|S_T−K| / середнє(премія) на ATM ±1 страйк змішує відстань страйка від спота (≈ 0.5–1 % спота) з ціною при премії 0.4 % спота. Потрібна парна оцінка на принт.
5. Питання про ціну хвоста життя опціону лишається цікавим: закрити його дешево як побічний продукт форвард-колектора (картка 3), без окремого тесту.

## 3. bybit-deribit-daily-option-dislocation-forward (forward)

1. Тест на історії неможливий (немає bid/ask) → `forward`, не `rejected`. Колектор корисний і сам по собі.
2. **Серйозно.** Гіпотеза вимагає медіанного життя розриву ≥ 10 хв, а колектор погодинний: життя не вимірюється. Умова: щохвилини ±30 хв після появи розриву.
3. **Невідомі до реєстрації:** чи існують денні BTC/ETH-опціони Bybit, чи доступні через ccxt, індекс розрахунку й комісія, доступність для резидента, чи є опціони на демо-рахунку. У коді Bybit-опціонів немає.
4. Картка не враховує виходу: ще два спреди до 06:00 UTC; паперовий результат обов'язково рахувати з ними.
5. Імовірність ≈ 5 % (картка 8 %); ефект $0.5–1.5 тис./рік до проковзування.
6. Форвард-розділ дописано у картку: тригер, папір, записи, n (30 днів для кіллу, 90 для висновку), kill. Запису в `docs/knowledge/setups.md` не робив: це вимір, а не сетап для плану.
