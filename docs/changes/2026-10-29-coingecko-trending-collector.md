- Нове завдання колектора `coingecko_trending` (`src/tradedesk/collector/coingecko_trending.py`) для картки [`IDEA-20261028-coingecko-trending-attention-fade-forward`](../ideas/IDEA-20261028-coingecko-trending-attention-fade-forward.md) (`forward`, крок 0). Щогодини один публічний запит `GET /search/trending` через наявний провайдер `rt.coingecko` (новий метод `search_trending`, `core.http.Http`: ліміт, ретраї, health); провайдер перевіряє лише верхню форму (`coins` — список), інакше `backend_error`.
- Таблиця `coingecko_trending` (схема 34, `WITHOUT ROWID`, ключ `(ts, rank)`): `ts` — початок години UTC, `rank` — позиція в списку з 1, `coin_id` (API-id CoinGecko), `coin_num`, `symbol`, `name`, `market_cap_rank`, `score` (як дає CoinGecko), `price_usd`, `price_btc`, `change_24h` (відсоток USD / 100, десятковий дріб), `market_cap_usd`, `volume_usd` (розібрані рядки на кшталт `"$12,734,601,288"`), `fetched_ts` — час отримання відповіді. Без чистки: історії trending в API немає, ця таблиця — єдина.
- Чиста функція `src/tradedesk/analytics/coingecko_trending.py`: `hour_ts(now)`, `snapshot_rows(payload)`. Розбір обережний: поле іншого типу → NULL; монета без придатного `id` пропускається (її позиція лишається порожньою); повтор `id` — лише перша позиція; не більше 50 позицій. Назви й символи — недовірений текст: керівні й форматні символи (bidi, zero-width) прибрано, довжину обрізано (40/100).
- Одна година — один знімок: тік раз на 10 хв (`TRADEDESK_COLLECT_COINGECKO_TRENDING_SECONDS=600`), запит лише поки година не записана; вставка `INSERT OR IGNORE`, перший знімок години зберігається. Збій запиту, змінена форма чи список без жодної придатної монети: нічого не пишеться, у лог `coingecko_trending: hour … not recorded` з причиною, без винятку; наступний тік пробує знову.
- Завдання **вимкнене** (`TRADEDESK_COLLECT_COINGECKO_TRENDING_ENABLED=1`; назва проходить білий список `deploy/features.env` за префіксом `TRADEDESK_COLLECT_`, тест є). У `deploy/features.env` не додано. Приклад — у `deploy/env.example`.
- **Живого зразка немає.** Фікстура `tests/fixtures/coingecko_trending_sample_2026-10-29.json` складена вручну за документованою формою відповіді (позначено в `_source`; id монет справжні, числа ілюстративні). Перед увімкненням координатор/власник має зняти живу відповідь на сервері (через `build_server()`/`rt.coingecko.search_trending()`), звірити форму (зокрема, що `data.price` — число, а не HTML-рядок) і замінити фікстуру.
