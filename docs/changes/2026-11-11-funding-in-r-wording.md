Лише документація, `docs/verification/2026-11-11-funding-in-r.md`; числа не перераховувалися, кожне змінене число звірено з таблицями звіту. Джерело: зауваження 1–3 [рев'ю](../reviews/2026-11-11-funding-in-r.md), пункт 320 [IDEA-20261102](../ideas/IDEA-20261102-standing-improvements.md).

- «Межі включно» зсувають середнє не більше ніж на **0.0023R (S38)** (було 0.002R; S38: −0.0049 → −0.0072); «решта» без топ-10 монет — **≤ 0.0031R** за модулем (було 0.003R; S12 v4 −0.0031).

- Непокриті угоди: слово «межа» замінено на «оцінка при типовій ставці ±0.01 % / 8 год» (у заголовках таблиць, методі й підсумку); додано, що для зміни рішення кожна непокрита угода мала б дати ≈ −3R (S40) … −5R (S28).
