## Тези

**SMC**
1. **SMT:** два обличчя — Raid Reversal на одному активі, Mitigation Reversal на корельованому; Micro SMT на молодшому ТФ; для EUR/GBP DXY має зняти ліквідність; **слабший актив дає більшу амплітуду** (кількісна, без чисел; визначення «слабшого» в уроці непослідовне).
2. **MMXM:** Original Consolidation → Re-Acc / Re-Dist → SMR у HTF POI → ціль за початковою консолідацією; SMR — вхід від брейкера після bos, стоп за свінгом; «MMXM + SMR — найвище матожидання» (без даних).
3. **IPDA:** DO / WO / MO — «високоліквідні рівні»; чотири режими (дистрибуція над, акумуляція під, свип, фліп); NYM / Judas Swing; шість профілів дня (відомі лише постфактум); «Classic Buy/Sell Day найчастіше у вт/ср» (кількісна, без даних). Час NYM у тексті неузгоджений з DST.
4. **AMD:** консолідація → маніпуляція (спершу за трендом, потім проти) → distribution (≠ Wyckoff); інтрадей прив'язано до сесій.
5. **SnD:** свіжа зона зі свипом, поглинанням, дисбалансом після неї, у discount / premium; підзони DP і Origin, порядок реакцій (якісна).
6. **Wyckoff Type 3:** без зовнішнього проколу, shakeout усередині; «з найбільшою ймовірністю» не тренд, а мітигація й потім агресивне зняття залишеної ліквідності (кількісна, без чисел).

**Нові версії уроків «Робота з чартом»:** текст і картинки збігаються з версіями 16.10; з «Ліквідності» прибрано вступ про механізм (навіщо великому гравцю стопи), з «Range» — абзац про «штучну рівновагу». Нових тверджень нема.

**Ринки**
7. **FX:** таблиця сесій у GMT+3 без DST (AR 03:00–07:00, LOKZ 09–12, NYKZ 14–17, LCKZ 17–18); дві маніпуляції — Франкфурт 09:00 і Лондон 10:00; «Pre-Frankfurt — пастка»; Лондон працює з AR, Нью-Йорк — з хаєм/лоєм Лондона; на новинах не торгувати.
8. **Фандинг і F&G:** лише визначення й посилання (Coinglass, alternative.me), правил нема.
9. **Наративи он-чейн:** градація капу (< 1 / 1–10 / 10–50 / 50+ млн), ліквідність / MC ≈ 1 : 10; first mover вигідніший за послідовників (частково суперечить тезі 2 з [LIB-20261016-course-gem3](LIB-20261016-course-gem3.md)); вихід — тіло на ×2–×4, 10–20 % залишку на кожному пампі; на хаях чекати −30–40 %; win rate смарт-гаманців 26–38 % при одному ×10 (кількісні, з кейсів).
10. **Degen:** high conviction проти інтенсиву за ліквідністю он-чейн (обсяг DEX мережі $0.8 млрд — слабко, $4–5 млрд/добу — сильно); мінімум 0.5–1 ETH на угоду; автор доходив до ≈ 70 % депозиту в он-чейні (кількісні). **Обидва останні суперечать правилам власника 1–3** — не імпортувати.

**Ресерч і безпека**
11. **ICO / IDO / IEO:** арифметика сейлів (CRDS, 5ire — сходиться); «вихід тіла» = 1 / частка TGE (Public 20 % → 5x); головне на Bybit — кількість акаунтів (мультиакаунтинг — не для проєкту).
12. **Чек-листи:** 7 блоків (наратив, фундамент, токеноміка, конкуренти, соцмережі, тригери, безпека), без числових порогів; у таблиці токеноміки bitsCrunch підсумок TGE 61.642 млн проти суми рядків 66.29 млн (не враховано два рядки); «Public ROI» тірів фондів — без джерела.
13. **Twitter-скори:** Moni і TwitterScore мають різні шкали (той самий $WEN — 480 і 39), порогу нема.
14. **Смарт-мані:** сигнал SMW — привід для ресерчу, не копіювання; на RLB 24-годинний тригер «5 купили, 1 продав» проти 7-денного чистого продажу −$388k.
15. **Безпека токена:** шукати за адресою; honeypot — стоп; податок ≤ 5 %; ліквідність ≥ 10 % капу; LP залочена; 2–3 чекери (на AEGIS чекери розходяться: «low risk» проти 73/100, топ-10 12.6 % проти кластера деплоєра 13.3 %); burner-гаманець.

## Як це може дати гроші

- **Правило вибору активу:** якщо слабший після SMT справді рухається більше (H1), дискреційний розворот торгувати в ньому — дешеве покращення угод, які власник і так відкриває.
- **Форвард-оцінка дискреційних сетапів:** теги `setup:S31…S35`, `S16`, `S28`, `tp:liquidity` у планах асистента дають власну статистику кожного сетапу без бектесту, який для них неможливий.
- **Захист капіталу:** фільтр безпеки токена (`contract_risk`) прибирає найгірші угоди он-чейн; пороги курсу (honeypot, податок, LP lock, ліквідність / кап) — конкретні й перевірювані на поточних даних.
- **Чого не брати:** розміри позицій з degen-уроку (0.5–1 ETH на угоду, 70 % депозиту) — суперечать правилам власника.

## Перевірювані гіпотези

- **H1 (SMT, слабший актив):** після SMT BTC/ETH на 1h залишкова (після 30-денної бети) дохідність «слабшого» в бік розвороту за 12 год > 0; плацебо — випадкові години й підтверджені свипи. Дані в кеші кроку 10. Картка — `IDEA-20261021-smt-weaker-asset-amplitude`.
- **H2 (DO / WO / MO):** перший дотик відкриття доби / тижня після відходу ≥ 1 ATR дає реакцію (+1 ATR раніше −1 ATR) частіше за випадковий рівень на тій самій відстані на ≥ 3 п. п. Дані — годинні свічки топ-30 перпів у кеші. Картка — `IDEA-20261021-open-levels-dowomo`.
- **H3 (сесії FX без DST):** S25 на EURUSD / GBPUSD з фіксованими вікнами курсу (GMT+3 цілий рік) замість локальних. Свій параметр, не помилка лектора; пріоритет низький, бо gross ≈ 0 на основному прогоні. Картки нема — доповнення до `IDEA-20261016-session-stop-hunt-fx`, якщо агенти повернуться до FX.
- **Не перевіряти:** профілі дня, AMD на старшому ТФ, Wyckoff 3, DP → Origin, MMXM (лише форвард), чек-листи, Twitter-скори, ICO (немає даних або механізму).
