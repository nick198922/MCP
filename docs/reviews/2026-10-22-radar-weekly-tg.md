# Рев'ю: недільний радар у Telegram (scripts/radar_weekly_tg.py)

Режим C. Дата: 2026-10-22. Вердикт: **approve** (блокерів немає, є два зауваження low).

Перевірено сам: `make lint` — чисто; `uv run pytest -q tests/test_radar_weekly_tg.py` — 10 passed. Прочитано скрипт, обидва юніти, крок 25 і тест. Документи (AGENTS, BACKLOG, HANDOFF, картка, changes) переглянуто лише за змінами в `git status`, не вичитувалися построково. `git diff --stat` не запускався (заборонено середовищем).

## Перевірено

1. Інваріанти: скрипт офлайн і read-only, читає лише файл знімка. Мережі немає, `analytics/` не чіпається. Відправлення йде через `tg_send.send`, токен у скрипті не читається. Ордерного коду немає.
2. Екранування: усі рядки знімка проходять `_h` (`ab._h`); тест `test_radar_escapes_snapshot_text_and_survives_odd_data` перевіряє, що ін'єкція `<a href=...>` стає `&lt;a ...&gt;`. Рядки з `db.radar_situation` екрануються при складанні. Помилки `err` теж екрануються (тест із `<x>`).
3. Ніколи не кидає: дві вкладені `try/except`, відсутній знімок, секція чи актив дають короткий текст. Застарілий знімок (>30 хв) додає попередження, (>6 год) показує лише його. Тести це покривають.
4. Чесність: у кінці завжди `CAVEAT` (не порада, H1 відхилено, ризик-нейтральність). Радар BTC/ETH бере рядки з дашборду, а не переписує їх, тому розбіжності з вкладкою немає.
5. Кнопки: URL будується з `ab.panel_base` лише для https, без URL повідомлення йде без кнопок (тест). Мережі й секретів, крім ключа дашборду, немає.
6. Крок 25: без sudo, перевірка `id -un == tradedesk`, `set -euo pipefail`, `rm -f` лише власного прапора. Порядок: pull, превʼю (`--print`, нічого не шле), створення прапора, синхронізація юнітів, одна відправка. Юніт: `ConditionPathExists` на той самий прапор (тест `test_flag_path_matches...` звіряє шлях), `NoNewPrivileges`, `Persistent=false` (без доганяння в понеділок).
7. Прапор: лежить у каталозі `tradedesk`, тож будь-який його процес може його створити чи зняти. Це не захист, а перемикач; це чесно сказано в коментарях юніта й кроку (як у кроці 22, Q-20261021-1). Прийнятно.

## Зауваження

1. **low.** Кнопки несуть ключ дашборду в `?k=` (так само, як `assistant_brief_tg.py`). Ключ потрапляє в історію групи Telegram і у прев'ю `--print` у терміналі. Це наявне рішення проєкту (група лише власника, ключ стає річною кукою), тому не блокер. Фікс на майбутнє: ротація ключа при виході когось із групи, окремий ключ тільки для читання `/radar`.
2. **low.** `systemd OnCalendar=... Europe/Kyiv` з назвою часової зони потребує нормальної підтримки в systemd (є з v235). Крок 25 лише друкує `list-timers`; варто глянути, що `NEXT` показує неділю 19:30 за Києвом. Якщо ні, замінити на локальний час. Перевірити власнику після запуску.
