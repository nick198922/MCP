# Панель: рядок дії під «Частка в плюсі» читає саму частку (пункт 311)

Джерело: зауваження 1–2 критика до пункту 295, [рев'ю](../reviews/2026-11-10-panel-demo-journal-actions.md) («не блокують»). Картка: [IDEA-20261102-standing-improvements](../ideas/IDEA-20261102-standing-improvements.md), пункт 311.

- Було: `j_winrate_act` дивився лише на середнє на угоду. За будь-якого середнього нижче 0 радив «тримай стоп, дай плюсу дійти», хоча підказка каже це тільки про **високу** частку при мінусовому середньому. За високої частки й середнього ≥ 0 писав «низька частка не біда».
- Стало: рядок залежить від частки й середнього. Поріг «висока» — 50 % (`JR_HIGH_WINRATE`), його тепер названо в підказці («Низька (до 50 %)», «Від 50 %, а середнє нижче 0»). Висока й мінус → «тримай стоп»; низька й мінус → «низька частка й мінус: дивись середнє на угоду»; висока й не мінус → «частка сама мало каже: дивись середнє»; низька й не мінус → як було; частка невідома → вказівник на середнє.
- Тести (`tests/test_dashboard.py`): межа 49 % / 50 %, усі чотири комбінації й невідома частка, звірка 50 % з текстом підказки, плитка на журналі з двома дрібними виграшами й одним великим збитком (2 з 3 у плюсі, середнє в мінусі → «тримай стоп»). Плитка з одним збитком тепер показує «низька частка й мінус».
- Перевірка: `make lint` чисто; `tests/test_dashboard.py` і `tests/test_dashboard_positions.py` — 152 passed. Мережа не потрібна, `execution/` не змінено.
