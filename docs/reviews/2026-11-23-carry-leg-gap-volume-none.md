1. Невідомий обсяг лишається `None`: `_vol()` у `analytics/carry_leg_gap.py` не перетворює його на 0. Скрипт `bars()` теж зберігає `None` для обсягу. «R1 zero volume» дає лише явний `0` (`is not None and == 0`).

3. Вердикти повних даних і порядок прапорців не змінилися: `_frozen` і `_units` є дослівним винесенням старих умов; порядок усередині циклу той самий (frozen, zero volume, foreign bar по ногах, потім R4). У ранньому виході порядок (frozen a, frozen b, R4) узгоджений із повним.
4. Тести впали б на старому коді: у `row_checks` старий `float(ba[4])` на `None` кидає `TypeError`; у «no data» старий код повертав `flags == []`, а тест чекає `["R1 frozen a"]` і `["R4 units"]`. Явний `0` покритий окремо.
5. `analytics/` лишається чистим: без I/O, час не потрібен, нових імпортів немає. Файл `docs/changes/` є.
