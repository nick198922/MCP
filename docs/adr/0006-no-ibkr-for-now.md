# 0006 — IBKR відкладено на невизначену перспективу

**Статус:** прийнято, 2026-10-12.
**Контекст:** початковий BACKLOG містив Фазу 5 (IBKR + уніфікований шар
`instrument_id`), сподіваючись на доступ до CME-ф'ючерсів і американських
опціонів через `ib_async` + IB Gateway. Власник підтвердив, що найближчим
часом IBKR додавати не планує; можливо, повернемось у далекій перспективі.

## Рішення

- Пункт **5.1** (IBKR через `ib_async`) переносимо у статус *deferred —
  revisit on explicit request*. Його реалізація вимагає окремого рішення
  власника про тип рахунку, підписку на market-data і 24/7 IB Gateway на
  VPS; поки все це не підтверджено, код не додаємо.
- Пункт **5.2** (єдиний шар інструментів `instrument_id`, мультибіржові
  символи, нормалізація ф'ючерсних серій) мав сенс передусім як міст між
  crypto venues і IBKR. Без IBKR ccxt-символів і Deribit-назв достатньо,
  тож пункт перенесений в "ідеї без пріоритету" до появи другого шару
  (традиційні ринки).
- Пункти **5.3** (on-chain-паритет з DOUBLETOP: DefiLlama, DexScreener,
  Etherscan V2, Helius, mempool, Pendle) і **5.4** (Pendle окремо)
  **залишаються активними** — вони не залежать від IBKR.

## Наслідки

- Фаза 4 (виконання ордерів через `ExecutionGuard`) стартує лише з крипто-
  біржами (Deribit testnet, Binance/Bybit testnet через ccxt). CME-рука
  додається тільки після рішення по IBKR.
- `docs/BACKLOG.md` і `docs/HANDOFF.md` оновлено: IBKR-пункти позначено як
  deferred і прибрано зі списку "відкритих питань до власника".
- Якщо IBKR колись знадобиться — повернутися до цього ADR, зняти deferred,
  узгодити з власником: тип рахунку (margin/portfolio), market-data
  subscription (US stocks, options, CME), чи VPS готовий тримати IB Gateway
  24/7 (IBC + Xvfb або Docker `gnzsnz/ib-gateway`).
