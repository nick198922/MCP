### 2026-11-03 — Панель: дрібниці після вкладки «Потоки»

- Картка [standing-improvements](../ideas/IDEA-20261102-standing-improvements.md), пункт 31; зауваження з [рев'ю пункту 22](../reviews/2026-11-03-panel-flows-tab.md). Усі три в коді ще були, жодне не виявилось неактуальним.
- (а) Розгорнуті згортки більше не закриваються з новим знімком. `KEEP_OPEN_JS` брав ключ з id самого `<details>` (порожній) або з тексту заголовка, де є живі числа. Тепер ключ — id секції згортки (`_fold(..., sid=...)`), а текст лише запасний варіант. Діє на «Радарі» (`r-*`) і «Потоках» (`f-*`); «Ринок» (`b-*`) і Polymarket (`pm-near`, `pm-paper`) отримали id, бо згортки там їх не мали. «Опціони» й «Позиції» вже зберігали стан за id секції у власному JS, їх не змінено.
- (б) (i) для «CVD спот і ф'ючерси» у випадку «ф'ючерси купують, спот продає»: «рух на плечі: лише контекст (розбіжність як сигнал не підтвердилась)». Раніше було «у лонгу — менший розмір», хоча `spot-vs-perp-flow-divergence` у нас ✗.
- (в) Лід «Потоків» без речення інструмента (або без секції): якщо до події з високим впливом менше 48 год, у «Що робити» тепер порада на подію. «Причина — нижче» лишилась тільки тоді, коли нижче справді показано збої джерел. Докстрінг `flow_summaries` тепер правильно описує рядок «немає даних».
- Тести: `test_keep_open_keys_folds_by_section_id_not_by_live_summary` порівнює ключі JS (повторені на Python), коли числа в заголовках змінюються. Також додано `test_flow_cvd_info_takes_no_side_on_the_rejected_divergence` і `test_flows_lead_without_a_sentence_or_section`, а асерти розмітки «Ринку» й Polymarket оновлено під id.
- Живий знімок 03.11 (лише читання): на «Потоках» BTC/ETH по 8 згорток з id `f-*`, без жодного «Блок не вдалося»; на «Ринку» 7 згорток з id `b-*`.
