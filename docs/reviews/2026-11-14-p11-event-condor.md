## Зауваження

1. **(інфо) H1 на межі між ◯ і ≈.** IS = −0.00024: ≈ не виконано на четвертому знаку. Мітка P11 від цього не залежить (`playbook_labels` дає ◯ і для ≈, і для ◯), але звіт варто доповнити одним реченням: «≈ не виконано лише через IS −0.0002; змісту це не змінює, бо CI H1 широкий навколо нуля».
2. **(інфо) Кластеризація H2 консервативна** (див. вище). Якщо колись ≈ H2 захочуть зробити ✓, різницю слід рахувати парним ресемплом блоків (подія і контроль з одного блоку разом), але це нова реєстрація, не правка цієї.
3. **(мінор, текст) Хибне обґрунтування «не ✗» у картці й плейбуку.** Картка 4.6 «Результат»: «MDE 0.073 > EDGE_R 0.045 (тому не ✗)»; плейбук P11: «MDE 0.073 R більша за поріг переваги 0.045 R, тому не ✗». За `straddle_p5.verdict` MDE у правилі ✗ не бере участі: ✗ неможливий, бо середнє +0.008 > 0 і верхня межа +0.057 > 0 (і > EDGE_R). Звіт (рядок «P11 …») пише правильно. **Правка:** замінити на «середнє > 0 і верхня межа CI +0.057 > EDGE_R 0.045, тож ✗ неможливий; MDE 0.073 > EDGE_R — тест не мав потужності виявити перевагу розміру EDGE_R».
4. **(мінор, текст) «Усі варіанти чутливості з CI нижче нуля» для H3 — не зовсім так.** Зареєстрована робастність «одна угода на блок» дає −0.128 [−0.318; +0.107] (CI містить 0; звіт це чесно показує нижче). Твердження стоїть у звіті («Коротко», P9: «у всіх варіантах чутливості CI нижче нуля») і в картці. **Правка:** «у всіх варіантах чутливості (спред 0 / 3 в.п., «сторона», пропуск дня, T − 1, лише FOMC + CPI) CI нижче нуля; одна угода на блок −0.128 [−0.318; +0.107] (n = 75) — CI містить 0».
5. **(мінор, інтерпретація) H3 не відокремлює подію від звичайного дня.** Для стреддла контролю нема (не зареєстровано), а контроль кондора показує, що 1-денні опціони з витратами Bybit збиткові для покупця й без події (VRP + спред). Отже ✗ H3 доводить «купівля денного стреддла в день події збиткова після витрат», але не те, що збиток спричинений саме подієвим crush (механізм у P9: «IV обвалюється після події»). Мітка «✓ як правило ризику» коректна як правило; **правка:** у висновку P9 і в «Застереженнях» звіту додати: «контролю для стреддла нема, тож невідомо, чи подія гірша за звичайний день для покупця; ймовірно, денні стреддли збиткові для покупця взагалі». Описовий контроль стреддла (без вердикту) можна додати пізніше розвідувально.
6. **(мінор, текст) Розбіжність CI контролю.** Звіт «Коротко», H2: контроль [−0.073; −0.029] (кластерний), таблиця H2 і картка: [−0.075; −0.029] (об'єднаний). **Правка:** узгодити (взяти об'єднаний, як у таблиці).
