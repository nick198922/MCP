# 2026-11-08 · `dex.num` без `OverflowError`, ціни mark / index у `perps_funding_compare` без NaN / inf (пункт 260)

Пункт 260 [постійної картки](../ideas/IDEA-20261102-standing-improvements.md), лишки BACKLOG 6.52 після пункту 257.

- **`dex.num`** (`analytics/dex.py`): ціле, завелике для float (`10**400` з JSON-літерала на 300+ цифр), тепер дає `None`, як `option_xvenue.num`, а не `OverflowError`. Тест, що фіксував виняток, замінено тестом на `None`; `10**300` і знак зберігаються ([рев'ю](../reviews/2026-11-07-analytics-direct-tests-15.md)).
- **`perps_funding_compare`**: `mark` / `index` ccxt-бірж, Hyperliquid і Deribit проходять через `finite_float`. NaN / ±inf, нечисловий рядок або bool дають `null` і попередження з біржею й символом («bybit BTC/USDT:USDT: index price not a finite number; shown as null»); рядок біржі з funding лишається в порівнянні. Відсутня ціна (OKX) — `null` без попередження, як і раніше. Числовий рядок тепер повертається як число. В описі інструмента сказано, що `mark` / `index` можуть бути `null`.
- **`OverflowError` у `perps.py`** (за [рев'ю](../reviews/2026-11-08-review-leftovers-3.md)): `_finite_price` і давній `_finite_rate` ловили лише `TypeError` / `ValueError`, а `float(10**400)` кидає `OverflowError`, тож завелике ціле в ціні чи ставці funding виходило винятком назовні. Тепер ціна — `null` з попередженням, біржа з такою ставкою — поза порівнянням з попередженням, як для NaN.
- Тести: `tests/test_funding_compare_prices.py` (21: чиста відповідь, NaN / ±inf для кожної біржі й поля, помічник ціни з `10**400`, помічник ставки з `10**400`), новий тест у `test_analytics_direct_15.py`. Живий виклик 08.11 з сервера: `perps_funding_compare` BTC дав усі 5 бірж з числовими mark / index (OKX `null`, як завжди), нових попереджень немає.
