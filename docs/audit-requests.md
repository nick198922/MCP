# Доручення власника наступному тижневому аудиту

Відкриті пункти (`- [ ]`) `scripts/agents_audit.sh` дописує до промпту аудитора; аудитор відповідає на кожен окремим розділом звіту і ставить `- [x]` з датою й посиланням. Нові доручення — сюди, по одному пункту.

- [x] (2026-11-14: [звіт аудиту, розділ «Доручення власника»](reviews/2026-11-14-weekly-audit.md#доручення-власника-ревізія-нашого-mcp-і-порівняння-з-doubletop), [таблиця інструментів](reviews/2026-11-14-mcp-inventory.md), питання [Q-20261114-1](QUESTIONS.md), кандидати — BACKLOG «З тижневого аудиту 2026-11-14») **Ревізія нашого MCP і нове порівняння з MCP DOUBLETOP** (власник 14.11, тема «💬 Claude»: «варто щоб аудитор глянув наш МСР, може варто вдосконалити щось чи прибрати і порівняв ще раз 2топ МСР»). Що зробити:
  1. **Інвентар усіх інструментів** (`uv run python scripts/mcp_call.py --list` або `mcp__tradedesk__*` напряму): для кожного — чи ним користуються (виклики `mcp__tradedesk__<tool>` у транскриптах сесій Claude `~/.claude/projects/*/*.jsonl` за 30 днів; імпорти тієї ж логіки в `scripts/`, колекторі, панелі; з 14.11 — агенти через `scripts/mcp_call.py`), чи дублює інший, чи опис зрозумілий моделі (одиниці, застереження, коли обирати саме його), розмір типової відповіді (символи / токени: великі відповіді з'їдають ліміт).
  2. **Рекомендації таблицею:** прибрати / злити / вдосконалити (що саме) / лишити, з причиною. У цьому прогоні нічого не видаляти: видалення й злиття — питанням у `docs/QUESTIONS.md` (варіанти + рекомендація); дрібні безпечні правки описів — можна (за правилами розділу 3 інструкції аудиту).
  3. **Порівняння з DOUBLETOP:** живі інструменти `mcp__claude_ai_DOUBLETOP__*` (якщо підключення недоступне — каталог `docs/reference/doubletop-catalog.md`) проти наших, `docs/PARITY.md` оновити. Головне питання: чого в них є корисного для наших поточних напрямів (опціонні ідеї й плейбук, демо-трейдер, X-трейдери, carry, Polymarket) і чого в нас нема; де наш інструмент кращий або гірший за їхній аналог. Кандидати на нові інструменти — рядками в `docs/BACKLOG.md` з посиланням на звіт.
  4. **Що не вимірюється:** умови з плейбуку опціонів (картка [options-playbook](ideas/IDEA-20261114-options-playbook.md), якщо плейбук уже є) та з карток власника, яких жоден наш інструмент не міряє.
