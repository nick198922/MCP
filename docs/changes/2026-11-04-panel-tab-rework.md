# 2026-11-04 — панель: вкладка «Система» за design/PANEL.md

Постійна картка `IDEA-20261102-standing-improvements`, п. 65; правила — [`design/PANEL.md`](../design/PANEL.md). «Система» (`/`) — єдина з трьох головних вкладок, яку ще не переробляли (решта вкладок — 28.10–03.11).

- **Угорі «що зараз / що робити»** (`system_lead`): перше, що стосується: служба стоїть → дані колектора відстають (таблиця старша за норму або серії з дірами в «Здоров'ї колекторів») → чекають PR чи питання → ліміт тижня ≥ 97 % (пауза) / ≥ 80 % (лише твої картки) → «усе працює, нічого робити не треба».
- **4 плитки з рядком дії** (`block_system_tiles`, ≤ 8 слів): «Чекають тебе» (PR + питання), «Ліміт тижня», «Дані колектора» (свіжі / з нормою), «Диск сервера» (пам'ять і бекап під ним). Числа рахує `system_status` з того самого знімка сторінки.
- **(i) — інструкції:** для всіх заголовків вкладки (`p_*`) додано рядки «мало → що робити / багато → що робити» в `ACT`; новий ключ `p_waiting`.
- **Згорнуто з підсумком у заголовку** (правило 7: плитки замість відкритих блоків): «Ліміт Claude», «Прогрес проєкту», «Черга», «Результати перевірок», «Кроки агентів», «Колектор даних», «Сервер», «Останні зміни в main»; у кожної згортки — `id`, тож автооновлення щохвилини не закриває відкрите. Відкритими лишились «Агенти зараз», «Питання агентів до тебе» (піднято вище) і «Здоров'я колекторів».
- **Застереження один раз унизу** (`SYSTEM_CAVEATS`): «сторінка не про ринок», «кожен крок важить однаково / дні — грубо», пороги ліміту, «вердикт — про минуле»; з блоків ці примітки прибрано.
- **Тести** (`tests/test_dashboard.py`): `test_system_tab_follows_panel_rules` (лід перед плитками, 4 рядки дії ≤ 8 слів, жодного «Для угоди:», 8 згорток із підсумками й без `open`, питання над згортками, «Застереження» один раз після `</main>`), `test_system_lead_and_tiles_name_the_first_thing_that_needs_the_owner` (порядок пріоритетів, ліміт не прочитано, повний диск); вкладку додано до перевірки стабільних ключів згорток.
