## Як це може дати гроші

- Процедура «довгий колл на відскок → на першому опорі продати тижневий OTM-колл (+4k) → далі ще один (+6k)» — це правило управління, яке можна перевірити на історичних ланцюжках. Якщо воно краще за «закрити на 2.5×» і «тримати до експірації», вийде готовий сценарій для демо-трейдера (опціони Bybit).
- Фільтр IV-режиму для стренґлів (IV < 35 %) — дешевий фільтр для наших опціонних ідей.
- Пре-FOMC памп / пост-FOMC спад у BTC: якщо ефект є, це календарний сетап (8 подій на рік).
