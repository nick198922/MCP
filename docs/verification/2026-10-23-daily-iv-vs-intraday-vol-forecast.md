## Коротко

**Вердикт: `rejected`.** Зареєстрований шлюз не пройдено: значущого c > 0 немає ні в одній версії. Прогноз HAR понад IV нічого помітного не додає: c ≈ 0.

- **Основна регресія (зареєстрована)** ln|r| = a + b·ln IV + c·ln σ̂ (SE кластеризовані за ISO-тижнями):
  - IS 2021–2023: c = **−0.36** (SE 0.19, 95 % CI [−0.72; +0.01]), p = 0.055, n = 1 087;
  - OOS 2024–2026: c = **−0.39** (SE 0.16, CI [−0.70; −0.09]), n = 1 000;
  - зареєстровано: c > 0 з p < 0.01 на IS і c > 0 на OOS.
- **Від'ємний c на всіх днях дають вихідні, це не властивість ринку.** IV знає день тижня (вихідний дисконт), HAR — ні. Перерахунок критика з фіктивними змінними дня тижня (дослідницьке, не зареєстроване): c = +0.15 [−0.23; +0.52] IS, +0.03 [−0.42; +0.47] OOS. На будніх входах (зареєстрована версія) c = +0.16 IS, −0.12 OOS, обидва незначущі. Отже, c ≈ 0: c ≳ 0.5 виключено, менший c — ні. Kill-правило (c ≤ 0 або p ≥ 0.01 на IS) виконується в обох специфікаціях (з днями тижня p(c) IS ≈ 0.44).
- **Жодна з 14 звітних версій не дає значущого c > 0.** Хубер, r², |r|, IV з однієї печатки, trade IV, IV з `entry_quote`, лише будні входи: c від −0.56 до +0.16.
- **IV денної експірації сама прогнозує наступну 23-годинну RV краще за HAR.** На OOS: IV із замороженим IS-відображенням R² 0.634, прогноз HAR (заморожений) 0.36. Обидва регресори разом: коефіцієнт HAR +0.12, R² 0.675 проти 0.671 в однієї IV (підгонка на OOS). HAR понад IV майже нічого не додає; механізм картки («повільна поверхня») на даних не видно.
- **Основний зріз (терцилі g, X стреддла) і крила не рахувались**, як передбачає kill-критерій. Правило 8 без змін.

## Метод

Повністю — у реєстрації в картці. Коротко:
- **Вибірка.** Дні входу D з 2021-01-01 по 2026-09-30, вхід о 09:00 UTC на добову експірацію D+1 08:00. r = ln(S_T/S0), де S_T — delivery price Deribit, S0 — індекс на вході (`entry_quote`, кеш `event_straddle/quotes_v1.json`).
- **IV (основна).** Середнє mark IV усіх принтів на ATM-страйку обох ніг за [07:00; 09:00]: медіана 49 принтів на день, днів з одним принтом 0 %. Mark IV інвертовано з `mark_price` угоди на форварді `ratio × index`.
- **HAR-RV.** Лог-HAR на RV з 5-хвилинних барів BTCUSDT Binance perp. Вікна 1, 7 і 30 діб; у прогноз ідуть лише бари, закриті до 09:00. МНК на IS, коефіцієнти заморожено. σ̂ — річна вола прогнозу на вікно 23 год з лог-нормальною поправкою s²/2.
- **Шлюз.** Коефіцієнт c при ln σ̂ за наявності ln IV. Кластерні SE CR1 за ISO-тижнями, двосторонні нормальні p.

## Потужність

- **До даних** у реєстрації: SE(c) ≈ 0.22, MDE ≈ 0.75. **Фактично:** SE(c) на IS 0.186, MDE (p < 0.01, потужність 80 %) ≈ 0.63.
- **Що виключено.** У моделі з днями тижня (перерахунок критика, дослідницьке) верхні межі 95 % CI для c: +0.52 на IS і +0.47 на OOS; лише будні, IS і OOS разом (обернені дисперсії): c = +0.08 [−0.24; +0.40]. Отже, c ≳ 0.5 виключено. Верхні межі зареєстрованої моделі на всіх днях (+0.01 / −0.09) занижені вихідними, тож мірою того, що виключено, вони не є.
- **Чого тест не розрізняє.** c від 0 до ≈ 0.4–0.5 не виключено: на будніх входах (зареєстрована версія) верхні межі +0.53 і +0.49. Який c потрібен для торгівлі, тут не виведено (попередня теза «c ≈ 0.4 потрібно» ні на чому не ґрунтувалась і прибрана). Груба оцінка критика через стару форму шлюзу (застереження 2): для ΔX ≈ +0.4 % спота між верхнім терцилем і рештою потрібен нахил ≈ −0.43; на будніх входах виміряно −0.16 (IS, CI [−0.52; +0.20]) і +0.02 (OOS). IS-CI цю межу ледь зачіпає, OOS-оцінка ≈ 0: торгівлі потрібен ефект, значно більший за точкові оцінки.

## Застереження

1. **Від'ємний c на всіх днях дають вихідні (виміряно).** Ринок знає день тижня (вихідний дисконт IV; фіктивна змінна входу в суботу ≈ −1.05 у ln|r| на IS), а HAR — ні, і в реєстрації дня тижня в HAR немає. Перерахунок критика з фіктивними змінними дня тижня на всіх днях (дослідницьке, не зареєстроване): c = +0.15 (SE 0.19) [−0.23; +0.52] IS, +0.03 (0.23) [−0.42; +0.47] OOS; p(c) IS ≈ 0.44. Зареєстрована версія «лише будні»: +0.16 / −0.12. Тобто c ≈ 0, а не від'ємний. Це не рятує ідею: значущого c > 0 немає в жодній специфікації, і kill-правило виконується. HAR із днями тижня як основна модель — нова гіпотеза для нової картки; очікувана цінність низька, бо IV вже кращий прогноз.
2. **Стара форма шлюзу (ілюстрація, без висновку).** Нахил ln(|r|/премія) на g на всіх днях +0.44 (IS) і +0.31 (OOS), а не ≈ −1, як побоювався критик тріажу: усереднення mark IV за 2 год прибрало більшу частину шуму вимірювання. Ці нахили на всіх днях теж здебільшого дають вихідні. На будніх входах (перерахунок критика, дослідницьке): IS −0.16 (SE 0.18), OOS +0.02 (0.28), тобто ≈ 0. Висновку про знак відносно тези продавця з цього не випливає; для торгівлі потрібен нахил ≈ −0.43 (див. «Потужність»), і шум IV зсуває нахил униз, тобто на користь тези.
3. **Mark IV — це модельна марка Deribit, а не ціна виконання.** Версія з trade IV (ціни угод) дає той самий висновок (c = −0.56 / −0.37).
4. **Відхилення від реєстрації (не залежить від результату).** Реєстрація називала кінець періоду 2026-10-13, але кеш 5-хвилинних барів закінчується 2026-09-30 23:55. Тому останній день входу — 2026-09-30 (−13 днів OOS).
5. **Еталон 0.90 відтворено приблизно (0.947), а не точно.** Причина — інший склад вибірки (усі будні проти днів подій і підібраних контрольних днів).
6. **Правило 8 (< 24 год до експірації — не купувати) не змінюється.** Питання про купівлю крил до власника не виносилось: шлюз не пройдено.
