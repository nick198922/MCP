Ряд заповнювачів `'?' * n` тепер має точну довжину, коли `n` складено зі сталих, `+` і `len(<сталий список>)` (`'?' * (len(cols) + 1)`), тож SQLite перевіряє й відповідність кількості колонок і значень; з `len(параметр)` лишається один повтор, як раніше. `cols *= …` та інші зміни на місці — «не перевіряється» з причиною.
