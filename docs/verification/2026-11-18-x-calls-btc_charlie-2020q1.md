## Критерії
Нових правил нема. Застосовано правила попередніх партій btc_charlie:
- розкриття з ціною → рядок;
- одне джерело на рядок (BTC 01-21: поля з боксу, виконання 9,050 з тексту лише в `note`);
- числа інструмента позиції — числа підписів: вхід = стоп ± підписана відстань, ціль перевірено тим самим способом;
- сетап (бокс при ціні ≈ входу) → рядок;
- дату рядка визначає перша публічна поява позиції з ціною;
- різні входи → різні рядки;
- пізніші твіти про ту саму позицію → продовження;
- погляди без власного наміру → (б) або (в);
- закриті угоди, видимі лише при виході → не рядки, окремий лічильник;
- умовний тригер «above X» → відкрита зона з позначкою «не проганяти».

Рішення цього кварталу (ухвалені до будь-яких цін ринку):
- **Ціна з тексту для лімітних намірів** («heading to $8.5k where I'll be adding to short», «Looking for a pullback to around $0.27 to add», «Top-up buys set between $210-$250», «Sub $8k… I'll be loading up», «Looking to short $5.2k~») → рядки з `zone` = названа ціна. Модель зони `calls.py` для лімітного входу (лонг нижче ринку, шорт вище) рахує правильно. Окремо названо строгий лічильник власних позицій (без намірів).
- **Пари до BTC** (ONE, REN ×2, RVN, ATOM): ціни в BTC, `symbol` = `binance:XXX/BTC`. `calls_check.py` спот-пари бере (`candidates()` повертає `symbol` як є, `fetch_bars` працює з будь-якою біржею ccxt), **але лише пари, що торгуються зараз**: символ відсіюється через поточний `load_markets()`. Пари, яких на Binance зараз нема (імовірно REN/BTC), і TOMO / NANO без `symbol` (перпів `TOMO/USDT:USDT`, `NANO/USDT:USDT` нема) дадуть `no_data` мовчки. Це упередження вцілілих у бік лістингу на сьогодні: у пункті 3 показати число `no_data` і не тлумачити його як відсутність результату (рев'ю 18.11, знахідка 5).
- **ATOM 02-23** — вимірювальна стрілка від поточної ціни, а не бокс: вхід = основа стрілки = закриття графіка (ex ante, вхід = ринок). Ціль = основа + підписана відстань.
- **RVN 02-21** — синя лінія 0.00000300 («300 sat buys»), але бокс має вхід 0.00000298 (= 0.00001410 / 4.7313; стоп 0.00000298 − 0.00000047 = 0.00000251). Поля — за боксом.
- **BTC 03-13 «add to some spot positions here» при «$5k $BTC?»** — рядок спот за рівнем ринку з тексту (5 000). Це не ціна виконання, тому рядок межовий.
- **BTC 03-15 «Target: $0»** — жарт, у поле цілі не записано. **BTC 03-18 «moved stop to breakeven»** — стоп = вхід у поле не записано (`calls.py` закрив би угоду в день входу).
- **TOMO 01-21 «reentered $0.46~»** — вхід раніше за твіт (дата невідома), а ринку на 21.01 я не знаю. Тому ні «ex ante», ні «показано вже в плюсі»: окрема мітка «стан невідомий».
