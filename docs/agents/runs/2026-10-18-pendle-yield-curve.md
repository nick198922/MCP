# Pendle: крива дохідності (`pendle_yield_curve`)

- **Крок:** p — картка власника `doubletop-to-ours` (Порядок 5), пункт 6b. Бюджет плану 88 %, тож взято лише крок p; картки з меншим `Порядок` або закриті, або чекають на власника/час.
- **Зроблено:** інструмент `pendle_yield_curve` (лише читання): терм-структура implied APY по активних ринках Pendle за експірацією, без інтерполяції. Чиста функція `build_yield_curve`, провайдер і ліміт `pendle` ті самі.
- **Після рев'ю критика:** одна репрезентативна точка на експірацію (найбільша ліквідність) для зміни й форми кривої; `thin=null` при невідомій ліквідності; ясна помилка при `min_days > max_days`; тести фільтрів.
- **Перевірки:** `make lint` чисто, `make test` — 1250 passed.
- **Критик (режим C):** раунд 1 — request changes (залежність від порядку точок), раунд 2 — **approve**. Дві дрібниці лишились: одне твердження в новому тесті не ловить стару помилку (інші ловлять); запис у `docs/changes/` оновлено.
- **Не перевірено:** збіг із відповіддю DoubleTop і жива відповідь Pendle (немає зразка DT). У картці додано пункт 6c; зразок знімає Claude в інтерактивній сесії.
- **Доставка:** `owner` — крок завершено, на рев'ю.
